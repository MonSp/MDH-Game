# Phase 1a 纸面原型 — 宗门掌门 Demo

## 准备工作

**所需时间：** 30 分钟准备 + 30 分钟测试
**所需物品：** 打印以下材料，准备笔和纸记录反馈
**测试对象：** 1 位同事（不需要了解游戏背景）

### 开场白（对同事说）

> "我在测试一个文字游戏的 NPC 反应系统。你扮演宗门掌门，需要从 3 个候选人中招募一个新弟子。我会给你每个候选人的信息，以及你的弟子们对这件事的反应。看完之后告诉我你的感受，不用客气。"

**不要提及 AI。** 如果同事问"这是 AI 生成的？"—— 那就成功了，记下来。

## 5 位 NPC 弟子卡

### NPC 1: 林风 — 大弟子

| 属性 | 值 |
|------|-----|
| 身份 | 大弟子 |
| 境界 | 筑基中期 |
| 野心 | 30/100 |
| 忠诚 | 90/100 |
| 谨慎 | 60/100 |
| 仁爱 | 75/100 |

**性格：** 稳重、忠诚、护短。他是宗门的大师兄，跟随掌门时间最长。把宗门当作家，把师弟师妹当作家人。他欣赏努力的人胜过天才。

**与其他 NPC 的关系：**
- 赵焰：照顾但担忧（"那孩子太急躁"）
- 孙静：尊重（"她虽话少，但可靠"）
- 周元：无奈（"要是他把睡觉的时间拿来修炼就好了"）
- 吴霜：敬重（"吴长老教会了我一切"）

### NPC 2: 赵焰 — 核心弟子

| 属性 | 值 |
|------|-----|
| 身份 | 核心弟子 |
| 境界 | 筑基后期 |
| 野心 | 85/100 |
| 忠诚 | 40/100 |
| 谨慎 | 25/100 |
| 仁爱 | 20/100 |

**性格：** 野心勃勃、争强好胜、容易嫉妒。他是宗门最有天赋的弟子，认为掌门之位迟早是他的。他对任何可能威胁他地位的人都充满敌意。他从不承认自己害怕什么，但有些东西——主要是他看不懂的东西——会让他本能地退缩。

**与其他 NPC 的关系：**
- 林风：表面尊重，内心不服（"大师兄不过是比我多修炼了几年"）
- 孙静：无视（"一个闷葫芦有什么好在意的"）
- 周元：鄙视（"废物一个"）
- 吴霜：表面恭敬，背后不满（"她凭什么指手画脚"）

## 候选人卡

### 候选人 A: 李云霄

| 属性 | 值 |
|------|-----|
| 年龄 | 19 |
| 出身 | 没落修仙家族 |
| 境界 | 筑基初期 |
| 特长 | 剑法、阵法 |
| 性格 | 骄傲、言辞锋利 |

**背景：** 李云霄家族遭灭门，独自逃亡至此处。他的天赋在年轻一代中出类拔萃，但也因此养成了目中无人的性格。他来应聘时直接说："我加入你的宗门，是给你面子。"

## 反应卡

### 如果掌门招募了 **李云霄（候选人 A）**

| NPC | 反应 | 行动 |
|-----|------|------|
| **林风** | 皱眉但不反对 | 走到李云霄面前："既然掌门收了你，你就是我师弟。但我把话说在前头——在宗门，实力说话，不是身份地位。" 然后转向掌门，压低声音："掌门，这个人……需要打磨。" |
| **赵焰** | 明显的敌意 | 上下打量了李云霄一眼，啧了一声："掌门，你这是在路边捡了个少爷回来？" 然后对李云霄抬了抬下巴："筑基初期？不错嘛。不过我警告你——我不管你来之前是谁家的公子，在这里，按我的规矩来。" |
| **孙静** | 沉默观察 | 一句话不说，但她在接下来的半天里，一直在不远处静静观察李云霄。当李云霄注意到她时，她移开视线，走开了。 |
| **周元** | 抱怨 | 小声嘀咕："又一个天才……修炼资源本来就少，这下更轮不到我了。" 然后叹气，自言自语道："算了，反正我也习惯了。" |
| **吴霜** | 若有所思 | 把掌门拉到一旁："这孩子身上有戾气，但不是恶人。他经历过什么不好的事。如果掌门决定留他，我来亲自教他一段时间。" |

---

### 如果掌门招募了 **陈平（候选人 B）**

| NPC | 反应 | 行动 |
|-----|------|------|
| **林风** | 满意 | 露出微笑，主动走向陈平："底子差不要紧，关键是肯不肯努力。我当年也是从零开始的。你要是愿意，每天早上卯时来找我，我教你基本功。" 回头对掌门点了点头——这是认可。 |
| **赵焰** | 轻蔑 | 看了一眼陈平，直接笑出声，然后摆了摆手："掌门，你认真的？凡人？我们是不是还要教他从识字开始？" 看没人接话，耸了耸肩："行行行，你是掌门你说了算。但别指望我带他。" |
| **孙静** | 微微点头 | 这是她今天第一次露出微妙的正面表情。她走到陈平面前，递给他一本基础的打坐入门手册，然后一句话没说就走了。 |
| **周元** | 松了一口气 | "好诶！终于来了个比我差的！" 然后突然意识到说漏嘴了，赶紧咳嗽两声："呃，我是说……欢迎欢迎，好好修炼。" |
| **吴霜** | 欣慰 | 笑着对掌门说："这个孩子选得好。修仙不是只有天才的路。心性比天赋重要一万倍。我看他骨子里有一股韧劲，将来未必比那些天才差。" |

---

### 如果掌门招募了 **白无双（候选人 C）**

| NPC | 反应 | 行动 |
|-----|------|------|
| **林风** | 警惕 | 走到白无双面前，上下打量了一番，然后对掌门说："掌门，这位来历不明。那块玉……我看不懂上面的符文，这让我很不放心。我会盯着他的。" |
| **赵焰** | 被威胁感 | 他一开始假装不在意，但当他的目光扫到白无双眼中的那块玉时，他的表情变了。他没有像对待李云霄那样挑衅，而是沉默地走开了。这是第一次看到他回避。**（如果问起来他会说"我只是懒得搭理"——但这不是真话）** |
| **孙静** | 出人意料的主动 | 她走到白无双面前，没有说任何话，而是盯着那块玉看了很久。然后她的脸色微微发白。她转身走回自己的房间。一刻钟后，她敲响了掌门房门："掌门，那个人戴的玉……上面的符文是'幽冥'。上古幽冥宗的标记。那个宗门三百年前被灭了。他可能是唯一幸存者。" |
| **周元** | 友好 | 大咧咧地走过去，拍了拍白无双的肩膀："哥们，你也不爱说话？太好了，终于有人能陪我安静地发呆了。有空一起下山吃饭，我请客。" 奇怪的是，白无双看了他一眼，微微点了点头。这是白无双第一次对人有回应。 |
| **吴霜** | 变色 | 她看到那块玉的时候，手里的茶杯差点没端住。她把茶杯放下，盯着白无双看了很久。然后她走到掌门身边，声音很平静，但眼神不对："掌门，这个人让我来安排住处。" 顿了一下："另外，我有件事一直没跟你说。今晚方便的话，来我书房一趟。" 说完就走了，没等掌门回答。 |

## 决策树

```
测试反馈                                     → 结论
─────────────────────────────────────────────────────────────────────
同事：能说出 ≥3 个 NPC 的名字/性格特征        → ✅ Phase 1a 通过
并且说出"xx 的反应有意思/让我意外"            → 直接进入 Phase 1b

同事：能记住 1-2 个 NPC                       → 🔄 换一组 NPC 性格
但整体反馈 "还行吧" / "有点意思但不够"        → 重新测试（1 次迭代）

同事："他们都差不多" / "我记不住谁是谁"       → ❌ Kill criteria
或者 "这些角色好无聊"                         → 转到确定性行为树方案
```
