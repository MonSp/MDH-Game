# Tasks

## Task 1: 情绪冷却机制 ✅
为情绪触发的行为引入冷却期，防止"暴怒卡死"循环。
- [x] **1.1** 在 `SocialComponent.h` 中新增 `EmotionCooldown` 结构体（target_id, emotion_type, trigger_behavior, cooldown_until_frame）
- [x] **1.2** 实现冷却数据结构：每个 NPC 维护一个最多 8 条的情绪冷却记录（环形缓冲），覆盖愤怒→决斗、恐惧→逃跑等组合
- [x] **1.3** 在 `BehaviorTree_Emotion.h` 的情绪打断函数中，触发前先查询冷却记录：若同一目标+同一原因+同一行为在冷却期内，跳过触发
- [x] **1.4** 冷却期内愤怒值溢出逻辑：当愤怒超过阈值但被冷却阻止时，溢出量按比例转化为恐惧（模拟"打不过→害怕"的心理转换）
- [x] **1.5** 情绪行为结束时写入冷却记录：愤怒决斗结束后（无论胜负），对目标 NPC 写入 72 帧冷却
- [x] **1.6** 编写 4 个 C++ 单元测试 ✅：冷却阻止重复决斗、冷却期间可对不同目标发起、冷却期满恢复、恐惧与愤怒冷却独立

- [x] **2.7** 队列最大容量由 witnessed 环形缓冲自然限制（30条）

## Task 3: 反思遗忘因子 ✅
为反思降权引入自然恢复机制，防止概率性失败导致行为永久偏离。
- [x] **3.1** 在 `BehaviorComponent.h` 的 `ReflectionData` 中新增字段：`penaltyCount`（该行为被降权次数）、`lastPenaltyFrame`（最近一次降权时间）
- [x] **3.2** 实现遗忘恢复函数 `getWeightWithDecay()`：权重向 1.0 渐进恢复，恢复半衰期为 500 帧
- [x] **3.3** 遗忘恢复速率受性格影响：勤奋≥70 恢复速率 ×1.5，勤奋≤30 恢复速率 ×0.5
- [x] **3.4** 实现饱和效应：降权次数越多，恢复速率越低（第 N 次恢复速率 = 基准 × max(0.2, 0.8^(N-1))）
- [x] **3.5** 替代行为成功时的快速恢复逻辑保持不变：直接恢复至 1.0，并重置 `penaltyCount`
- [x] **3.6** 在 `applyReflection()` 中调用 `getWeightWithDecay()`，传递 `currentFrame` 和 `personality`
- [x] **3.7** 编写 4 个 C++ 单元测试 ✅：遗忘半衰恢复、替代成功快速恢复、性格影响恢复速率、饱和效应
