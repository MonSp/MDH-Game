- [x] `gameStore.ts` 中的 `NPC` 接口已包含 `hp`, `mp`, `personality` (野心、谨慎等) 和 `resources` 等新属性。
- [x] 在游戏运行时，点击查看 NPC 的属性面板或气泡，可以看到他们具有不同的个性或生命值（可通过日志或 UI 验证）。
- [x] 当 NPC 受到攻击血量过低时，其行为状态会切换为“逃跑”或“疗伤”，不再主动靠近玩家。
- [x] 担任“长老”或“家主”的 NPC 会执行与其身份相符的行为（如巡逻、发布指令），而普通子弟会执行打坐、后勤等日常行为。
- [x] 当地图上生成资源点时，附近的 NPC 会有概率被吸引过去并改变状态为“争夺机缘”或“采集”。
- [x] `updateNPCs` 函数已完全使用基于优先级和国家特色的行为树逻辑来驱动 NPC 的坐标和状态更新。
