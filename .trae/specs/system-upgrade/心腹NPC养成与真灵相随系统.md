# 太古纪元：心腹NPC养成与真灵相随系统

## 设计理念：仙途孤寂，得一知己足矣

修仙路漫，若能得一二忠心耿耿之士辅佐，无论是经营家族、征战沙场还是探索秘境，都将事半功倍。本系统让玩家在游戏过程中，通过机缘、恩义或实力，将部分NPC收为“心腹”。这些心腹不仅能在本纪元为玩家提供实质性帮助，更能在纪元重启时，以“真灵相随”的形式随玩家一同转世，成为跨越轮回的羁绊。

---

## 1. 心腹NPC收服机制

### 1.1 可收服对象

并非所有NPC都可收服，需满足以下条件之一：

| 收服条件 | 说明 | 典型场景 |
|:---|:---|:---|
| **救命之恩** | 在NPC生命垂危时（血量<10%）出手相救 | 野外遇袭、战场负伤 |
| **知遇之恩** | 玩家为NPC提供了突破瓶颈的关键资源（如赠送突破丹药） | 坊市交易、完成任务 |
| **志同道合** | 玩家与NPC人格参数高度契合（如双方野心均>0.8） | 长期共事、多次合作 |
| **击败臣服** | 在切磋或战斗中以绝对优势击败NPC，且选择“招降”选项 | 家族战、秘境争夺 |
| **特殊道具** | 使用“缚灵索”“心魔誓约”等稀有道具强制收服 | 遗迹掉落、纪元精华兑换 |

### 1.2 收服流程

```text
满足收服条件
      │
      ▼
触发“心悦诚服”交互事件 ──→ 玩家选择“招揽”
      │
      ▼
进行说服检定（基于玩家魅力/境界/NPC好感度）
      │
   ┌──┴──┐
   ▼     ▼
 成功   失败
   │     │
   ▼     └──→ NPC好感度下降，短期内无法再次招揽
心腹契约成立
   │
   ▼
NPC加入玩家“心腹团”，解除与原家族/势力的隶属关系
（原家族好感度可能下降）
```

### 1.3 心腹团容量与限制

| 项目 | 规则 |
|:---|:---|
| **初始容量** | 3名 |
| **扩容方式** | 每突破一个大境界+1名额；使用“神魂玉”道具+1名额（稀有） |
| **最大容量** | 10名 |
| **心腹释放** | 可主动解除契约，NPC回归原势力，好感度归零 |
| **心腹死亡** | 若本纪元内心腹战死，其真灵仍可保留，但在下一纪元重生时初始忠诚度-20 |

## 2. 心腹NPC的多元定位与养成方向

### 2.1 心腹类型与定位

玩家可根据自身需求，将心腹培养为不同方向：

| 类型 | 核心作用 | 适合玩家 | 养成侧重 |
|:---|:---|:---|:---|
| **战将** | 随玩家出征，提供战力加成或直接参战 | 主战派 | 战力、技能、装备 |
| **管家** | 自动打理家族产业、收取资源、完成日常任务 | 经营派 | 经营、管理、忠诚 |
| **谋士** | 提供战略建议、外交斡旋、情报刺探 | 策略派 | 智谋、话术、人脉 |
| **丹师/器师** | 专职炼丹、炼器，为玩家提供后勤保障 | 发育派 | 技艺、专注、耐心 |
| **死士** | 执行刺杀、破坏等高危任务，不计生死 | 激进派 | 隐匿、爆发、忠诚 |

### 2.2 养成维度与成长路径

每个心腹拥有独立的属性面板，可通过以下方式培养：

| 养成维度 | 成长方式 | 效果 |
|:---|:---|:---|
| **修为境界** | 赐予丹药、带其历练、共同修炼 | 提升基础战力与血量 |
| **专属技能** | 传授功法残卷、实战磨砺 | 解锁/升级心腹专属技能 |
| **装备法器** | 为其配备法器、防具 | 大幅提升战斗表现 |
| **忠诚度** | 赏赐、谈心、并肩作战 | 影响任务执行成功率与跨纪元保留完整度 |
| **特长专精** | 指派特定任务（如长期炼丹） | 提升对应方向的效率与品质 |

### 2.3 心腹交互与指令系统

玩家可随时向心腹下达指令，指令类型因心腹定位而异：

| 指令类别 | 示例指令 | 消耗 | 产出/效果 |
|:---|:---|:---|:---|
| **采集类** | “前往灵田采集修为精华” | 时间 | 修为精华×N，有概率获稀有材料 |
| **征战类** | “随我出征”、“驻守据点” | 时间/体力 | 参与战斗，提供战力加成 |
| **经营类** | “管理灵植园”、“巡视坊市” | 时间 | 提升产业产出效率，自动收取资源 |
| **外交类** | “出使某家族改善关系” | 灵石+时间 | 提升目标家族好感度 |
| **特殊类** | “刺杀目标”、“盗取情报” | 高消耗+高风险 | 达成战略目标，但可能死亡 |

## 3. 真灵相随：跨纪元心腹保留机制

### 3.1 真灵保留条件

纪元重启时，心腹NPC不会完全消失，其“真灵”将根据**忠诚度**和**本纪元贡献**决定保留程度：

| 忠诚度阈值 | 保留内容 | 下一纪元初始状态 |
|:---|:---|:---|
| **≥90（生死相随）** | 全部记忆、技能等级、修为感悟（折算为潜力） | 重生后快速恢复至原境界80% |
| **70-89（忠心耿耿）** | 大部分记忆、核心技能、部分修为感悟 | 重生后恢复至原境界60% |
| **50-69（恪尽职守）** | 基本记忆、技能框架 | 重生后恢复至原境界40% |
| **<50（貌合神离）** | 仅保留姓名与模糊记忆 | 重生后为凡人，需重新培养 |

### 3.2 跨纪元重生规则

- **降生方式**：新纪元开始后，玩家可选择是否消耗“轮回引”（纪元精华兑换）来主动唤醒心腹真灵。若不唤醒，心腹将以普通NPC身份随机降生，玩家需重新寻找并收服。
- **唤醒消耗**：每唤醒一名心腹，消耗纪元精华×200 + 灵石×5000。
- **出生地点**：唤醒后的心腹将直接出现在玩家新角色的家族领地内，并自动加入家族。
- **修为恢复**：心腹在新纪元拥有“宿慧”Buff，修炼速度+50%，直至恢复至前世修为的相应比例。
- **记忆保留**：心腹会记得与玩家在前世的重大事件（如共同击杀仇敌、经历生死），并体现在对话与行为中。

### 3.3 真灵进化的可能性

经历多个纪元的心腹，其真灵可发生质变：

| 相随纪元数 | 心腹称号 | 额外加成 |
|:---|:---|:---|
| 2个纪元 | 轮回旧部 | 初始忠诚度+10，全属性+5% |
| 3个纪元 | 百战英魂 | 解锁专属“英魂技”，战斗中有概率触发免死 |
| 5个纪元 | 不灭道兵 | 可消耗真灵为玩家抵挡一次致命伤害（CD极长） |
| 7个纪元以上 | 混元道侣（最高） | 心腹可突破修为上限，与玩家一同飞升仙界，并参与最终混元道果争夺 |

## 4. 心腹与国家/家族系统的联动

### 4.1 心腹在家族中的角色

- **代理家主**：若玩家为家主，可任命心腹为“总管”，代为处理家族日常事务（自动批准入族申请、分配资源等）。
- **家族战将**：心腹可率领家族NPC小队参与家族战，其战术能力直接影响战局。
- **家族科技**：特定心腹类型（如丹师）入驻家族建筑后，可提升该建筑产出效率。

### 4.2 心腹在国家层面的贡献

- **担任官职**：若玩家成为国家君主或高官，可举荐心腹担任实职（如将军、司农），心腹的相应属性将影响国家发展。
- **执行国家任务**：心腹可被派遣执行外交、间谍、平叛等国家任务，成功率与心腹能力挂钩。

### 4.3 心腹与玩家飞升

- 玩家飞升时，心腹可选择**随同飞升**（消耗额外的飞升令），或**留守下界**（成为玩家道统的守护者）。
- 随同飞升的心腹，在高层世界保留其真灵记忆与部分实力，继续辅佐玩家。

## 5. 经济与平衡设计

### 5.1 心腹培养的资源消耗

| 养成行为 | 消耗资源 | 目的（回收经济） |
|:---|:---|:---|
| 赐予丹药 | 修为丹、突破丹 | 加速心腹成长 |
| 传授功法 | 功法残卷、灵石 | 赋予心腹新技能 |
| 赏赐 | 灵石、稀有道具 | 提升忠诚度 |
| 装备打造 | 材料+灵石 | 提升心腹战力 |
| 唤醒真灵 | 纪元精华+灵石 | 跨纪元保留 |

### 5.2 心腹产出与资源获取

| 心腹类型 | 主要产出 | 效率（相对玩家手动） |
|:---|:---|:---|
| 管家 | 自动收取家族产业分红 | 80%（但无需玩家在线） |
| 丹师 | 每日炼制修为丹×2-5 | 消耗材料自备 |
| 战将 | 随玩家击杀额外掉落 | +15%灵石掉落 |
| 谋士 | 坊市交易有概率获得折扣 | 5%-15% |

### 5.3 防止心腹过强的限制

- **指令冷却**：每个心腹执行指令后需休息（游戏时间），避免无限制刷资源。
- **心腹疲劳**：连续征战会导致忠诚度暂时下降。
- **数量限制**：最多10名，且唤醒真灵成本递增（第二名唤醒消耗+50%，以此类推）。

## 6. 玩家体验示例

> **第一纪元**：玩家“秦昊”在野外救下被妖兽围攻的散修“叶霜”，将其收为心腹，培养为战将。叶霜随秦昊南征北战，最终助其成为秦国皇族。纪元寂灭时，叶霜忠诚度达95，真灵完整保留。

> **第二纪元**：秦昊选择剑道重生，消耗资源唤醒叶霜真灵。叶霜以“宿慧”状态降生，迅速恢复至金丹期实力，再次成为秦昊的左膀右臂。二人联手推翻楚国皇族，统一三国。

> **第三纪元**：叶霜历经三世，进化为“不灭道兵”，在伐周之战中为秦昊挡下周天子致命一击。最终，二人一同飞升仙界，叶霜的真灵已与秦昊的道途密不可分。

---

这套心腹NPC养成系统，将玩家与NPC的羁绊从“一世的利用”升华为“万古的相伴”。心腹不仅是战力与资源的延伸，更是玩家在漫漫仙途中情感的锚点。当纪元重启、万物归零时，唯有真灵相随的他们，证明着玩家曾经走过的路、战过的敌、守过的诺。这，便是《太古纪元》最动人的修仙史诗。
