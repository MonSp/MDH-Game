# 太古纪元：深化机制——预组家族、大周皇朝与分层体验设计

## 设计理念：缘法天定，份在人争

修仙之路，既要顺应天道给予的出身，也要把握人道的机缘。本次深化围绕四大方向展开：**出生自由选择**让现实社交提前介入，**大周皇朝**作为超然势力重塑世界格局，**第9层新手保护**确保入门体验平滑，**第8层以上家族国家统一落地**则将SLG的军团对抗推向高潮。

---

### 1.2 预组家族系统（现实社交落地）

**创建预组家族**：
- **条件**：需要至少5名玩家共同申请，缴纳创建费用100灵石（可由成员众筹）。
- **流程**：
  1. 族长在游戏官网/启动器创建家族档案，设定家族名、徽章、宣言。
  2. 生成唯一**家族邀请码**，分发给成员。
  3. 开区后，成员在创建角色时输入邀请码，自动分配到该家族。
- **限制**：
  - 每个预组家族在单个区服的人数上限为**家族总容量的30%**（第9层三级家族最多容纳30名预组玩家），其余名额留给散人随机分配，防止完全垄断。
  - 预组家族只能创建在**三级家族**（最低级）位置，需通过游戏内发展晋升。

**预组家族优势**：
- 开区即拥有稳定的核心团队，沟通成本低。
- 族长可提前规划家族分工（战斗、生产、外交）。
- 家族内部有专属聊天频道（跨游戏内/外）。

### 1.3 散人玩家匹配机制

未加入预组家族的玩家，系统按以下优先级分配：
1. 所选国家内，**人数最少的家族**。
2. 若多个家族人数相同，**随机分配**。
3. 玩家可在游戏内通过消耗灵石**更换家族**（需当前家族同意或强制叛逃，有惩罚）。

## 2. 大周皇朝：超然于七国之外

### 2.1 地理与定位

- **位置**：每层世界地图正中央，占据约15%的地图面积，不与任何国家直接接壤（有天然屏障：山脉、大泽、禁制）。
- **性质**：**中立·不可占领·不可出生**的超级势力。
- **象征意义**：代表“天道秩序”，是飞升台、纪元终末事件的核心舞台。

### 2.2 大周皇朝的内部结构

| 构成 | 说明 |
|:---|:---|
| **周天子（NPC）** | 化神期以上，由系统生成，无实权但象征天道。纪元重启时会被新天子取代。 |
| **六部天官（NPC）** | 分别掌管飞升、刑罚、资源、情报、外交、传承，均为T1级LLM规划NPC。 |
| **天策府** | 大周皇朝的精锐武力，由“天策上将”统领，负责维护中立区秩序。 |
| **飞升台** | 位于皇城中央，是玩家飞升至上层世界的**唯一通道**。 |
| **天道碑** | 记录本层世界所有玩家的纪元评分、飞升次序、大道领悟情况。 |
| **轮回殿** | 纪元重启时，所有玩家灵魂汇聚之处，选择下一世大道。 |

### 2.3 玩家与大周皇朝的交互

| 交互行为 | 说明 | 代价/收益 |
|:---|:---|:---|
| **飞升** | 满足条件后，需前往大周皇城飞升台 | 缴纳飞升令+灵石 |
| **觐见天官** | 可接取大周皇朝发布的“天道任务” | 完成获得功德值、稀有道具 |
| **查询天道碑** | 查看排行榜、前世因果线索 | 消耗少量灵石 |
| **申请仲裁** | 若家族被灭门，可向刑部天官申诉，获得一次“复兴任务” | 任务极难，但成功后可重建家族 |
| **挑衅大周** | 攻击大周NPC或破坏飞升台 | 立刻被天策府追杀，且全服通报，视为“逆天者”，所有国家好感度归零 |

### 2.4 大周皇朝的战略意义（第8层以上凸显）

- **飞升垄断**：因飞升台唯一，高层世界的大周皇城将成为**兵家必争之地**。强国可派兵封锁飞升台，阻止敌国玩家飞升。
- **天官更替**：在第5层以上，玩家势力若足够强大，可发动“清君侧”事件，击杀现有六部天官，扶持己方NPC上位，从而影响天道任务发布倾向与飞升税收。
- **天子禅让**：在第3层以上，最强国家的君主可挑战周天子，胜者成为新一代天子，获得命名纪元、修改世界规则（限一次）的权力。

## 3. 第9层：凡界·新手试炼场

### 3.1 定位：学习、积累、试错

第9层是唯一允许**新建角色**直接降生的世界，设计上强调**低惩罚、高引导、快反馈**。

### 3.2 新手保护机制

| 保护项 | 具体规则 |
|:---|:---|
| **安全期** | 创建角色后7天内（现实时间），无法被其他玩家强制PK。主动攻击他人则安全期提前结束。 |
| **死亡惩罚减免** | 新手期内死亡不掉落物品，仅损失少量修为（可忽略）。 |
| **引导任务** | 强制完成“家族初见”、“首次修炼”、“资源采集”、“坊市交易”、“初识战斗”五大引导任务，每完成一项奖励基础资源包。 |
| **NPC友好度锁定** | 新手期内，本家族NPC对玩家好感度不会下降至中立以下。 |
| **飞升缓冲** | 满足飞升条件后，可自由选择是否立即飞升。若留在第9层，修炼速度逐渐降低（-5%/周），鼓励飞升但给足准备时间。 |

### 3.3 资源与玩法倾斜

| 倾斜方向 | 具体表现 |
|:---|:---|
| **资源点刷新加快** | 灵田、矿脉刷新频率是上层世界的1.5倍，竞争压力小。 |
| **NPC强度温和** | 同级NPC战力为上层世界的80%，便于玩家熟悉战斗节奏。 |
| **洗髓丹掉率提升** | 遗迹采集洗髓丹概率从30%提升至40%，帮助玩家快速体验体质突破。 |
| **家族战限制** | 三级家族之间宣战需满足“双方家主同意”或“一方友好度低于-500”，防止恶意屠幼。 |
| **国战延迟开放** | 国战系统在开服第8天才解锁，确保新手期世界和平。 |

### 3.4 飞升推荐

- 系统会在玩家达到化神大圆满时，弹出**飞升推荐信**，列举第8层世界列表及其当前局势（如“秦国强势”、“家族混战”），供玩家选择。
- 第9层飞升至第8层时，玩家可获得一次**免费更改国家/家族**的机会（重新选择出身），以适配新的世界格局。

## 4. 第8层及以上：家族与国家统一落地

### 4.1 从“个人”到“军团”的转变

第8层开始，游戏核心从**个人成长**转为**势力对抗**。SLG要素全面激活。

### 4.2 家族/国家落地规则

**飞升玩家的安置**：
- 飞升至第8层时，玩家面临选择：
  1. **投靠现有家族**：选择一个已存在的家族加入，成为其成员。若该家族有预组团队，可申请并入。
  2. **创建飞升家族**：消耗飞升令×1 + 灵石×50000，创建属于自己（及队友）的**二级家族**。
     - 创建者自动成为家主。
     - 可设定家族名、徽章，并生成家族邀请码，供同批次或后续飞升的同伴加入。
     - 新建飞升家族初始拥有基础建筑和100名NPC（与预设家族相同）。

**预组军团的跨层集结**：
- 现实中预组的团队，可通过**同步飞升**（约好时间一起飞升）在第8层汇合，共同创建或加入同一个飞升家族。
- 系统提供“军团飞升”功能：由团长发起，团员响应后，可整批飞升至同一第8层世界，并自动分配到同一家族。

### 4.3 第8层以上家族/国家的SLG要素强化

| SLG要素 | 第9层（基础版） | 第8层以上（完整版） |
|:---|:---|:---|
| **家族科技树** | 仅开放修炼系前3级 | 全系开放，可研发至顶级 |
| **家族建筑** | 仅可升至3级 | 可升至5级，解锁特殊建筑（战争工坊、间谍营） |
| **家族外交** | 仅支持结盟/中立/敌对 | 支持附庸、联姻、合并、渗透 |
| **国家官职** | 无实权，仅称号 | 玩家可担任国家官职（将军、丞相），指挥NPC军队 |
| **国战** | 边境小规模冲突 | 全面战争，可占领敌国城池，改变版图 |
| **大周皇朝互动** | 仅飞升功能 | 可参与天官更替、天子禅让事件 |

### 4.4 第8层以上的国家统一奖励

若某一国家的玩家势力成功**统一本层七国**（占领所有边境据点或使其他六国附庸），则该国全体玩家获得：
- **国号冠名权**：可将国家名改为自定义名称（如“大秦”改为“祖龙”）。
- **飞升税减免**：从该国飞升的玩家，大周皇朝抽取的飞升税降低50%。
- **专属秘境**：解锁一个仅本国玩家可进入的“祖地秘境”，产出唯一外观和稀有资源。
- **世界公告**：全服通报统一成就，并在天道碑上刻下统一者家族名。

## 6. 新增内容与已有系统的衔接

### 6.1 与纪元轮回（30天赛季）的融合

- **预组家族的跨纪元传承**：家族族长可将“家族名号”与“徽章”通过消耗纪元精华保留至下一纪元，成员重新创建角色时输入家族邀请码即可回归，维持家族品牌。
- **大周皇朝的纪元更替**：纪元重启时，大周皇朝的六部天官与周天子同样会被新NPC替换，上一纪元的天官若未被玩家击杀，可能以散修身份出现在民间，成为彩蛋NPC。
- **第9层新手与赛季制**：新玩家可在赛季任何时间加入，若在赛季后半段加入，系统会提供“修为加速”Buff，帮助其快速追赶，但飞升仍需满足条件。

### 6.2 与LLM高阶NPC决策的联动

- **大周皇朝的六部天官**全部为T0/T1级LLM NPC，他们的决策直接影响飞升名额分配、天罚执行、天道任务发布。玩家可通过影响天官（贿赂、威胁、扶持）来间接操控规则。
- **国家统一后的君主**（玩家或NPC）若达到T1资格，其LLM规划将自动升级为“国家战略级”，考虑跨层飞升者接收、附庸国管理等宏观事务。

### 6.3 与经济系统的循环

- **预组家族创建费**：100灵石/家族，由系统回收，防止通胀。
- **飞升家族创建费**：50000灵石+飞升令，大量回收资源，维护高层世界经济平衡。
- **大周皇朝税收**：飞升税、天道碑查询费等，构成灵石回收的重要渠道。
- **国家统一奖励中的飞升税减免**：鼓励玩家追求统一，同时不影响总体回收率（因统一难度极高）。

通过以上深化，《太古纪元》的玩家从“进入游戏”的那一刻起，就有了清晰的目标路径：与好友结盟落地、在安全的新手层成长、飞升后组建军团、最终挑战大周皇朝乃至统一世界。大周皇朝作为横跨九重天的超然存在，既是秩序的维护者，也是野心家最终的绊脚石。至此，游戏的社会结构已从“七国争雄”升格为“七国+大周”的复杂格局，玩家的每一份努力，都将在这个宏大舞台上留下印记。
