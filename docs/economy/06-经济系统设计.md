# 战争经济系统设计

## 1. 系统概述

《太古纪元：霸业》的经济系统围绕**战争**这一核心展开。所有经济活动都服务于战争需求：资源采集为了维持军队，贸易往来为了获取战略物资，科技发展为了提升军事实力。经济是战争的基础，战争是经济的延伸。

### 1.1 核心设计理念

- **战争驱动经济**：经济活动围绕战争需求展开
- **资源即战略**：资源分布和控制在战略层面至关重要
- **经济即武器**：经济制裁、贸易战是战争的重要形式
- **动态平衡**：战争消耗资源，资源限制战争规模

## 2. 资源经济

### 2.1 战略资源

| 资源 | 战争用途 | 日常用途 | 稀缺度 | 贸易价值 |
|:---|:---|:---|:---|:---|
| **灵石** | 法术消耗、装备打造 | 修炼、交易 | 中等 | 高 |
| **粮食** | 维持军队 | 维持人口 | 低 | 低 |
| **铁矿** | 打造武器、铠甲 | 建造建筑 | 中等 | 中 |
| **木材** | 建造器械、战船 | 建造建筑 | 低 | 低 |
| **药材** | 炼制丹药、医疗 | 修炼辅助 | 高 | 高 |
| **火晶** | 火属性法术、法器 | 炼丹 | 高 | 很高 |
| **水灵** | 水属性法术、法器 | 炼丹 | 高 | 很高 |

### 2.3 资源控制与战争

资源控制是战争的核心目标：

| 资源控制 | 战略意义 | 战争影响 |
|:---|:---|:---|
| **控制灵石矿** | 控制法术能力 | 可支撑更大规模战争 |
| **控制粮食产地** | 控制军队维持 | 可维持更长期战争 |
| **控制铁矿** | 控制武器生产 | 可装备更多军队 |
| **控制药材** | 控制医疗能力 | 可减少战争损失 |

## 3. 军费系统

### 3.1 军费构成

| 军费项目 | 说明 | 占比 | 影响因素 |
|:---|:---|:---|:---|
| **人员俸禄** | 军队人员工资 | 40% | 军队规模、境界等级 |
| **装备维护** | 武器、铠甲维护 | 25% | 装备等级、战斗频率 |
| **丹药消耗** | 战斗丹药、医疗丹药 | 20% | 战斗频率、伤亡率 |
| **阵法维持** | 军团阵法维持 | 10% | 阵法等级、军队规模 |
| **其他** | 训练、侦察等 | 5% | 军队活动频率 |

### 3.2 军费与军队规模

| 军队规模 | 月军费 | 维护要求 |
|:---|:---|:---|
| **1000人** | 10万灵石 | 无特殊要求 |
| **10000人** | 150万灵石 | 需要稳定收入来源 |
| **50000人** | 1000万灵石 | 需要控制多个资源点 |
| **100000人** | 2500万灵石 | 需要国家级别经济支撑 |

## 4. 贸易系统

### 4.1 贸易类型

| 贸易类型 | 说明 | 风险 | 收益 |
|:---|:---|:---|:---|
| **国内贸易** | 国内城市间贸易 | 低 | 低 |
| **国际贸易** | 国家间贸易 | 中 | 中 |
| **走私贸易** | 绕过关税的非法贸易 | 高 | 高 |
| **战争贸易** | 向交战方出售物资 | 很高 | 很高 |

### 4.2 贸易路线

贸易路线是战略要地，控制贸易路线可获得巨大收益：

| 贸易路线 | 连接 | 年贸易额 | 战略价值 |
|:---|:---|:---|:---|
| **丝绸之路** | 秦国-西域 | 1000万灵石 | 极高 |
| **海上商路** | 齐国-海外 | 800万灵石 | 高 |
| **南北通道** | 赵国-楚国 | 600万灵石 | 中 |

## 5. 经济制裁与贸易战

### 5.1 制裁类型

| 制裁类型 | 效果 | 代价 |
|:---|:---|:---|
| **贸易禁运** | 禁止与目标国贸易 | 损失贸易收入 |
| **资源封锁** | 阻止目标国获取特定资源 | 需要海军/边境控制 |
| **金融制裁** | 冻结目标国资产 | 需要金融体系控制 |
| **技术封锁** | 禁止出口关键技术 | 损失技术出口收入 |

### 5.2 制裁AI决策

```json
{
  "sanction_ai_decision": {
    "ai_id": "QIN_DIPLOMATIC_AI",
    "target": "楚国",
    "sanction_type": "贸易禁运",
    "reason": "楚国发动侵略战争",
    "expected_impact": {
      "target_economy": -0.3,  // 目标经济下降30%
      "self_economy": -0.1     // 自身经济下降10%
    },
    "duration": "直到楚国撤军"
  }
}
```

## 6. 战争经济

### 6.1 战争成本

| 战争类型 | 直接成本 | 间接成本 | 总成本 |
|:---|:---|:---|:---|
| **边境冲突** | 100万灵石 | 50万灵石 | 150万灵石 |
| **局部战争** | 1000万灵石 | 500万灵石 | 1500万灵石 |
| **国家战争** | 1亿灵石 | 5000万灵石 | 1.5亿灵石 |
| **全面战争** | 10亿灵石 | 5亿灵石 | 15亿灵石 |

### 6.2 战争收益

| 战争结果 | 直接收益 | 长期收益 |
|:---|:---|:---|
| **占领城市** | 城市资源 | 税收收入 |
| **控制资源点** | 资源产出 | 战略优势 |
| **击败敌军** | 战利品 | 士气提升 |
| **迫使投降** | 赔款 | 政治影响力 |

## 7. 经济AI系统

### 7.1 经济AI层级

| AI层级 | 职责 | 决策范围 |
|:---|:---|:---|
| **国家战略AI** | 国家经济战略 | 全国经济政策 |
| **区域经济AI** | 区域经济管理 | 特定区域资源分配 |
| **城市经济AI** | 城市经济管理 | 城市内部经济 |

### 7.2 经济AI决策流程

```
收集经济数据

  ↓

  ↓

  ↓

```

## 8. 玩家与经济系统

### 8.1 玩家经济活动

| 活动 | 说明 | 收益 |
|:---|:---|:---|
| **资源采集** | 采集地图资源 | 直接获得资源 |
| **贸易经商** | 进行商品贸易 | 贸易利润 |
| **任务完成** | 完成经济任务 | 任务奖励 |
| **战争掠夺** | 战争中掠夺资源 | 战利品 |
| **投资建设** | 建设经济建筑 | 长期收益 |

### 8.2 玩家经济策略

| 策略 | 说明 | 风险 | 收益 |
|:---|:---|:---|:---|
| **囤积居奇** | 低价买入高价卖出 | 市场波动 | 高利润 |
| **垄断市场** | 控制特定资源 | 引发战争 | 垄断利润 |
| **投资战争** | 向交战方出售物资 | 道德风险 | 暴利 |
| **发展生产** | 建设生产设施 | 投资周期长 | 稳定收益 |

---

通过以上设计，经济系统与战争系统深度绑定，经济活动直接服务于战争需求，战争结果又反过来影响经济状况。这种设计让经济成为战争的重要组成部分，为玩家提供丰富的战略选择。
