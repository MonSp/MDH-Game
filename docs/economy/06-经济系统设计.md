# 经济系统设计

## 1. 系统概述

游戏经济系统围绕灵石（核心货币）构建，涵盖资源获取、市场交易、价格波动、家族经济等多个维度，形成一个动态平衡的经济网络。

## 2. 货币体系

### 2.1 灵石

- **用途**: 境界突破、坊市交易、购买丹药法器、飞升消耗
- **获取途径**:
  - 采集矿脉：50灵石/次（受资源倍率影响）
  - 采集遗迹：100灵石/次（受资源倍率影响）
  - 杀人夺宝：继承NPC携带的灵石
  - NPC交易/打工收益

### 2.2 珍贵道具

| 道具 | 基础价格 | 用途 |
|------|----------|------|
| 洗髓丹 | 500灵石 | 体质突破关键道具 |
| 低级法器 | 200灵石 | 基础战斗装备 |
| 回血丹 | 50灵石 | 恢复生命值 |
| 聚气散 | 100灵石 | 恢复灵力 |
| **飞升令** | 10000灵石 | 飞升上界的必要道具 |
| **转世灵童印记** | 非卖品 | 真灵转世后获得的天赋道具 |

## 3. 坊市交易系统

### 3.1 坊市机制

- 坊市设在魏国中州，是全局交易市场
- 提供动态物价系统，价格随供需关系波动
- 玩家可进行买卖操作

### 3.2 价格波动算法

```
价格波动 = 基础价格 × (1 + 随机波动) × 库存修正

随机波动: -5% ~ +5%
库存修正:
  - 库存 < 20: +5%
  - 库存 > 100: -5%

价格区间: 基础价格的 50% ~ 200%
```

### 3.3 跨国关税

| 交易方 | 购买关税 | 出售关税 |
|--------|----------|----------|
| 本国玩家 | 0% | 0% |
| 其他国家玩家 | +15% | -15%（利润扣除） |

关税设计旨在鼓励玩家进行跨国贸易策略考量。

### 3.4 买卖规则

- **购买**: 按当前价格全额支付（含关税）
- **出售**: 按当前价格的80%计算（扣除关税后）
- **大规模交易**: 单次≥10个物品会触发市场价格重新计算

## 4. NPC商队跑商系统

### 4.1 触发条件

- 仅限**家主**和**长老**职位的NPC
- 需要高贪婪值（>70）和高野心值
- 10%概率触发跑商任务

### 4.2 跑商流程

1. 选择随机外国都城作为贸易目标
2. NPC向目标都城移动
3. 到达目的地后完成交易
4. 获得利润（500+灵石）
5. 返回家族或取消状态继续巡逻

### 4.3 跑商经济影响

- NPC跑商利润的10%上缴家族库房
- 大规模NPC贸易会平抑两地物价
- 击杀跑商NPC可获得巨额灵石收益（额外100-300灵石）
- 击杀跑商NPC会导致更严重的好感度损失（-20 vs -10）

## 5. 家族经济系统

### 5.1 家族库房

每个家族拥有独立的资金池（受层级倍率影响）：

| 家族层级 | 第9层初始资金 | 其他层级倍率 |
|----------|---------------|--------------|
| 皇族 | 100,000 | ×资源倍率 |
| 一级家族 | 50,000 | ×资源倍率 |
| 二级家族 | 10,000 | ×资源倍率 |
| 三级家族 | 5,000 | ×资源倍率 |

### 5.2 资金来源

- NPC跑商利润上缴
- 家族成员贡献（预留）
- 家族任务奖励（预留）
- 飞升者道统传承

### 5.3 资金用途（规划中）

- 家族成员税收减免
- 兑换家族专属物资
- 请长老护法（降低突破失败惩罚）
- 家族建设与发展

## 6. 飞升经济

### 6.1 飞升消耗

| 消耗项目 | 数量 | 说明 |
|----------|------|------|
| 飞升令 | ×1 | 必消耗 |
| 灵石 | ×100,000 | 经济回收机制 |
| 境界 | 重置为化神 | 属性保留50% |

### 6.2 飞升收益

- 进入更高灵气倍率的层级
- 属性受新层级加成重新计算
- 可创建飞升家族
- 解锁新玩法内容

## 7. 资源获取途径对比

| 途径 | 收益类型 | 风险等级 | 收益稳定性 | 受层级影响 |
|------|----------|----------|------------|------------|
| 采集灵田 | 修为 | 低 | 稳定 | 灵气倍率 |
| 采集矿脉 | 灵石 | 低 | 稳定 | 资源倍率 |
| 采集遗迹 | 灵石+洗髓丹 | 中 | 不稳定（30%稀有掉落） | 资源倍率 |
| 杀人夺宝 | 修为+灵石 | 高 | 不稳定（受战力影响） | 无 |
| 坊市交易 | 道具 | 低 | 稳定（受物价影响） | 无 |

## 8. 经济循环设计

```
资源产出
  ├─ 采集 → 灵石/修为（受层级倍率影响）
  └─ 遗迹 → 洗髓丹
  ↓
资源消耗
  ├─ 境界突破 → 消耗灵石
  ├─ 体质突破 → 消耗洗髓丹
  ├─ 飞升消耗 → 飞升令+灵石
  └─ 坊市购买 → 消耗灵石
  ↓
市场调节
  ├─ NPC跑商 → 平衡物价
  └─ 价格波动 → 供需反映
  ↓
家族经济
  ├─ 利润上缴 → 家族资金
  └─ 家族贡献 → 玩家回报
  ↓
飞升循环
  ├─ 低层资源汇聚 → 高层
  └─ 合道反哺 → 下层增益
```

## 9. 经济平衡策略

1. **灵石消耗大于产出**: 境界突破需要大量灵石，鼓励玩家持续参与经济活动
2. **飞升经济回收**: 飞升消耗大量灵石，防止通货膨胀
3. **价格波动区间限制**: 防止通货膨胀或通货紧缩
4. **跨国关税**: 增加跨国交易成本，促进战略选择
5. **NPC跑商平抑物价**: 自动调节市场供需

## 10. LLM决策入口：经济战略层

### 10.1 LLM适用场景

在经济系统层面，以下决策场景适合引入LLM进行战略规划：

| 场景 | LLM决策对象 | 规划周期 | 影响范围 |
|:---|:---|:---|:---|
| **家族经济规划** | T1级NPC（家主） | 周/次 | 库房资金、跑商策略 |
| **市场囤货策略** | T2级NPC（长老） | 日/次 | 物价波动、资源囤积 |
| **跨国贸易路线** | T2级NPC（长老） | 周/次 | 关税规避、利润最大化 |
| **资源分配决策** | T1/T2级NPC（家主/长老） | 日/次 | 家族资源优先级 |

### 10.4 与LLM规划系统的衔接

经济战略LLM规划与[NPC的AI决策系统](../npc/12-NPC的AI决策.md)的衔接方式：
- 经济战略计划中的`MARKET_SELL` → 注入到跑商NPC行为树，执行市场操作
- 经济战略计划中的`TRADE_CARAVAN` → 触发NPC跑商系统，增加市场流通
- 经济战略计划中的`FAMILY_SUBSIDY` → 修改家族成员行为权重，提升忠诚度
