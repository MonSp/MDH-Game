# 军团与门派势力体系

## 1. 系统概述

在《太古纪元：霸业》中，**军团**是军事行动的基本单位，**门派**是修仙传承的组织形式。两者相互交织：门派提供修仙者和功法，军团将这些修仙者组织成战斗力量。每个国家包含多个门派，每个门派可以组建自己的军团，也可以为国家提供修仙者充实国家军团。

### 1.1 核心设计理念

- **军团为骨**：军团是战争的基本单位，决定军事力量的组织形式
- **门派为血**：门派提供修仙者、功法和资源，是军团的实力来源
- **AI驱动**：军团指挥官和门派掌门都由独立的AI Agent控制
- **动态关系**：军团和门派之间的关系会随局势变化

## 2. 军团系统

### 2.1 军团类型

| 军团类型 | 规模 | 组成 | 特性 | 适用战术 |
|:---|:---|:---|:---|:---|
| **禁卫军团** | 10000-20000人 | 高阶修仙者（元婴以上） | 最高战力、绝对忠诚、消耗巨大 | 决战、护卫国君、斩首行动 |
| **主力军团** | 50000-100000人 | 中阶修仙者（金丹-元婴）+ 凡人精锐 | 均衡战力、适应性强 | 常规作战、攻城略地 |
| **特殊军团** | 5000-10000人 | 特殊功法修炼者 | 特殊能力、战术独特 | 特殊战术、奇袭、防御 |
| **边境军团** | 20000-50000人 | 低阶修仙者（筑基-金丹）+ 凡人军队 | 防御专长、成本低廉 | 边境防御、游击骚扰 |
| **修仙者军团** | 1000-5000人 | 纯修仙者组成 | 高机动性、高破坏力、数量稀少 | 快速突袭、战略打击 |

### 2.2 军团编制结构

```
军团（50000人）
  ├── 军团长（AI指挥官，化神期）
  ├── 副军团长（AI指挥官，元婴后期）
  ├── 参谋部（AI谋士团队）
  │   ├── 战略参谋（负责战术规划）
  │   ├── 情报参谋（负责情报收集）
  │   └── 后勤参谋（负责资源调配）
  ├── 第一师（10000人）
  │   ├── 师长（AI指挥官，元婴期）
  │   ├── 第一团（3000人）
  │   │   ├── 剑修营（1000人）
  │   │   ├── 法修营（1000人）
  │   │   └── 体修营（1000人）
  │   └── 第二团（3000人）...
  ├── 第二师（10000人）...
  └── 特殊部队（5000人）
      ├── 阵法师团（1000人）
      ├── 炼丹师团（500人）
      └── 情报部队（500人）
```

## 3. 门派系统

### 3.1 门派类型

| 门派类型 | 核心功法 | 军事作用 | 经济作用 |
|:---|:---|:---|:---|
| **剑修门派** | 剑道功法 | 高攻击力军团 | 武器锻造 |
| **法修门派** | 五行法术 | 远程法术支援 | 灵石开采 |
| **体修门派** | 炼体功法 | 高防御军团 | 资源采集 |
| **丹修门派** | 炼丹术 | 战场医疗支援 | 丹药生产 |
| **阵修门派** | 阵法之道 | 战场阵法布置 | 防御工事 |
| **器修门派** | 炼器术 | 法器装备支援 | 法器生产 |
| **符修门派** | 符箓之道 | 符箓战术支援 | 符箓生产 |

### 3.2 门派结构

```
门派
  ├── 掌门（AI Agent，最高决策者）
  ├── 长老会（AI Agent团队，决策辅助）
  ├── 内门弟子（核心修仙者）
  ├── 外门弟子（普通修仙者）
  ├── 杂役弟子（凡人，负责日常事务）
  └── 附属机构
      ├── 藏经阁（功法存储）
      ├── 炼丹房（丹药生产）
      ├── 炼器室（法器生产）
      └── 演武场（修炼场所）
```

## 4. 军团与门派的互动

### 4.1 门派支援军团

门派可以向军团提供支援：

| 支援类型 | 说明 | 效果 |
|:---|:---|:---|
| **修仙者支援** | 派遣弟子加入军团 | 提升军团战力 |
| **功法支援** | 提供军团功法 | 提升军团特性 |
| **丹药支援** | 提供战斗丹药 | 提升军团持续作战能力 |
| **法器支援** | 提供战斗法器 | 提升军团装备水平 |
| **阵法支援** | 提供阵法师 | 提升军团阵法能力 |

### 4.2 军团保护门派

军团可以为门派提供保护：

| 保护类型 | 说明 | 效果 |
|:---|:---|:---|
| **边境保护** | 保护门派边境安全 | 防止外敌入侵 |
| **资源保护** | 保护门派资源点 | 确保资源安全 |
| **弟子保护** | 保护门派弟子安全 | 防止弟子被击杀 |
| **声誉保护** | 维护门派声誉 | 提升门派影响力 |

## 5. 玩家与军团/门派的互动

### 5.1 玩家角色

| 角色 | 说明 | 互动方式 |
|:---|:---|:---|
| **军团长** | 直接指挥军团 | 制定战术、指挥战斗 |
| **门派掌门** | 管理门派 | 决定门派发展方向 |
| **军团成员** | 作为士兵参与战斗 | 执行命令、提升实力 |
| **门派弟子** | 在门派中修炼 | 学习功法、提升境界 |
| **独立修仙者** | 自由行动 | 可选择加入军团或门派 |

### 5.2 玩家创建军团/门派

#### 5.2.1 创建军团条件

- 境界要求：元婴期以上
- 资源要求：灵石100万
- 人员要求：至少1000名修仙者
- 国家许可：需要国家AI批准

#### 5.2.2 创建门派条件

- 境界要求：化神期以上
- 资源要求：灵石500万
- 功法要求：至少3套完整功法
- 地点要求：需要占领灵脉

### 5.3 玩家影响AI决策

玩家可以通过以下方式影响军团/门派AI：

- **直接命令**（军团长/掌门角色）：直接修改AI的决策目标
- **建议影响**（参谋/长老角色）：通过对话影响AI的决策倾向
- **行动影响**（成员/弟子角色）：通过实际行动改变组织状态

## 6. 军团战斗系统

### 6.1 战斗触发

战斗可以通过以下方式触发：

| 触发方式 | 说明 | 参与方 |
|:---|:---|:---|
| **宣战** | 国家AI正式宣战 | 两国军团 |
| **边境冲突** | 边境巡逻队相遇 | 边境军团 |
| **资源争夺** | 争夺资源点 | 附近军团 |
| **任务触发** | 完成特定任务 | 指定军团 |
| **玩家触发** | 玩家主动攻击 | 玩家所在军团 |

### 6.2 战斗流程

```
战斗触发
  ↓
进入战场实例（200×200格）
  ↓
双方部署军队
  ↓
战术AI制定战斗计划
  ↓
实时战斗（玩家可介入指挥）
  ↓
战斗结束
  ↓
计算战果
  ↓
更新世界状态
  ↓
触发后续事件
```

### 6.3 战斗结果影响

| 结果 | 影响 |
|:---|:---|
| **胜利** | 占领领土、获得资源、提升士气、增加经验 |
| **失败** | 损失军队、降低士气、失去领土、减少资源 |
| **平局** | 双方撤退、资源消耗、士气下降 |
| **惨胜** | 胜利但损失巨大、士气下降、需要休整 |

## 8. 军团与门派的AI协同

### 8.1 三层级AI协同

```
国家AI（战略层）
  ↓ 制定国家战略
军团AI（战术层）
  ↓ 制定战术计划
门派AI（角色层）
  ↓ 提供修仙者支援
实际战斗
```

### 8.2 AI信息共享

| 信息类型 | 共享方向 | 说明 |
|:---|:---|:---|
| **战略情报** | 国家AI → 军团AI | 国家战略、敌国动向 |
| **战术情报** | 军团AI → 门派AI | 战斗需求、人员需求 |
| **资源情报** | 门派AI → 军团AI | 资源状况、支援能力 |
| **人员情报** | 门派AI → 国家AI | 弟子状况、培养进度 |

### 8.3 AI冲突解决

当AI之间出现冲突时，按以下优先级解决：

1. **国家AI优先**：国家战略优先于军团战术
2. **军团AI优先**：军团战术优先于门派决策
3. **协商解决**：同级AI之间协商解决冲突
4. **玩家裁决**：玩家角色可以裁决AI冲突

---

通过以上设计，军团和门派不再是简单的数值集合，而是由具有真实决策能力的AI Agent驱动的动态组织。玩家与这些AI的互动将产生丰富多样的战略和战术体验。
