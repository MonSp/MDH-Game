# 战国七国设定

## 1. 国家详情

| 国家 | 修仙文化 | 特质加成 | 都城坐标 | 所属层级 |
|------|----------|----------|----------|----------|
| 秦国 | 法家、重农战 | 战斗经验获取+10% | (20, 50) 西部 | 凡界 |
| 楚国 | 巫楚文化 | 炼丹成功率+15% | (50, 80) 南部 | 凡界 |
| 齐国 | 稷下学宫 | 功法领悟速度+20% | (80, 50) 东部 | 凡界 |
| 燕国 | 苦寒之地 | 灵气吸收效率+10% | (70, 20) 东北 | 凡界 |
| 赵国 | 胡服骑射 | 移动速度+5% | (50, 30) 中北 | 凡界 |
| 韩国 | 中原正统 | 灵力上限+10% | (45, 50) 中部 | 凡界 |
| 魏国 | 纵横之术 | 制作成本-10% | (40, 60) 中南 | 凡界 |

## 2. 仙域体系（高层世界）

当玩家飞升至第3层天及以上时，七国体系演化为仙域体系：

| 仙域 | 修仙文化 | 特质加成 | 所属层级 |
|------|----------|----------|----------|
| 太虚仙域 | 太虚道统 | 全属性+15% | 第5层天 |
| 大罗仙域 | 大罗道统 | 修炼速度+25% | 第3层天 |
| 混元仙域 | 混元道统 | 资源获取+30% | 第1层天 |

## 3. 国家出生机制

玩家进入游戏时，可主动选择出生国家（皇族除外），并自动获得该国的特质增益。国家特质不仅影响玩家，也会影响该国NPC的基础人格倾向（如秦国NPC更具野心与忠诚）。

> **皇族禁生规则**：皇族（含大周皇朝及七国皇室）禁止玩家出生，皇族为NPC专属，是玩家的终极挑战目标。

## 4. 大周皇朝

### 4.1 大周皇朝定位（分层设计）

大周皇朝在不同世界层级有截然不同的定位：

| 层级 | 定位 | 特性 |
|:---|:---|:---|
| **第9层** | 绝对中立安全区 | 不可攻击、不可击杀、仅供交互、新手保护区 |
| **第8层及以上** | 可征服终极目标 | 可攻击、可占领、挑战周天子可登基为新天子 |

### 4.2 第9层大周皇朝特性

第9层的大周皇朝是绝对中立、不可攻击的新手保护区：

| 特性 | 具体规则 |
|:---|:---|
| **不可攻击** | 玩家无法对任何大周NPC发起攻击，攻击选项为灰色 |
| **不可击杀** | 大周NPC生命值不会降至1以下，若被强制扣血会触发"天道反噬"秒杀攻击者 |
| **交易开放** | 玩家可与大周皇城的"天工商肆"进行资源交易 |
| **任务发布** | 大周六部发布大量新手友好任务，奖励修为、基础功法、洗髓丹 |
| **安全区** | 大周皇城及周边区域为绝对安全区，禁止一切PK行为 |

### 4.3 天工商肆（第9层）

玩家可使用灵石在天工商肆兑换以下稀有物资（每日限购刷新）：

| 商品 | 价格 | 限购 | 说明 |
|:---|:---|:---|:---|
| 洗髓丹 | 500灵石 | 3/日 | 体质突破必需品 |
| 筑基丹 | 200灵石 | 5/日 | 练气→筑基必备 |
| 飞升令碎片 | 1000灵石 | 1/日 | 集齐10碎片合成飞升令 |
| 随机功法残卷 | 300灵石 | 2/日 | 可领悟新功法或提升现有功法 |
| 纪元精华（小） | 2000灵石 | 1/日 | 跨世货币 |

### 4.4 伐周机制（第8层及以上）

从第8层开始，皇族统一七国不再是终点，而是获得**挑战大周皇朝的资格**。大周皇朝变为可攻击、可征服的势力，成为所有玩家的最终Boss。

#### 挑战大周条件

| 条件 | 说明 |
|:---|:---|
| 国家统一 | 六国全部臣服或灭亡 |
| 飞升台控制权 | 尚未控制，需通过战争夺取 |
| 天子诏 | 消耗纪元精华×5000，向周天子递交"战书" |

#### 伐周战争（终极国战）

- **战争规模**：全层世界所有玩家均可参与，分为"勤王军"（保周）与"伐周军"（反周）
- **战场地图**：以大周皇城为中心的巨型战场，包含外郭、内城、皇城、飞升台四层
- **核心目标**：占领**飞升台**并坚守一定时间
- **大周军力**：
  - 周天子（炼虚期以上，每层不同）
  - 六部天官（化神大圆满）
  - 天策府精锐（元婴期以上，数量众多）
  - 护国大阵（需破坏阵眼才能削弱防御）

#### 占领飞升台后的变化

| 结果 | 影响 |
|:---|:---|
| **大周覆灭** | 该层世界大周皇朝势力被清除，飞升台由胜利国控制 |
| **飞升自主** | 胜利国可自主决定飞升规则（如只允许本国玩家飞升，或征收高额飞升税） |
| **新天子登基** | 伐周军领袖（玩家）可登基为新任周天子，获得命名纪元、修改本层部分世界规则的权限（限一次） |
| **天道震动** | 该事件将影响相邻下层世界，增加NPC野心值，促进下层世界皇族更替 |

#### 天子权柄

成为周天子后，玩家获得以下能力（持续至本纪元结束或下一位挑战者成功）：

| 权柄 | 效果 |
|:---|:---|
| **纪元命名** | 为本纪元命名（如"祖龙纪元"），载入天道碑 |
| **税率调整** | 调整飞升税（0%-30%）、坊市交易税（1%-10%） |
| **资源倾斜** | 指定一种资源的刷新率在本层提升20% |
| **天道赦令** | 可赦免本国玩家的一次死亡惩罚（每人限一次） |
| **天罚** | 消耗大量功德值，对指定区域降下天雷（大范围AOE，仅限国战时使用） |

> **注意**：周天子为玩家时，同样会被其他玩家挑战。权力越大，觊觎者越多。

## 5. 统一七国

### 5.1 统一路径

成为皇族后，家族目标升格为国家目标——统一六国。

| 统一阶段 | 条件 | 奖励 |
|:---|:---|:---|
| **吞并一国** | 占领该国全部边境据点，或使其成为附庸 | 该国资源产出30%上缴本国 |
| **统一三国** | 征服或附庸三个国家 | 解锁"霸主"称号，全族战力+10% |
| **统一六国** | 其余六国全部臣服 | 1. 国号可自定义<br>2. 飞升税永久减免50%<br>3. 获得挑战大周皇朝的资格（第8层起） |

## 6. 地理版图

### 凡界（第9-6层天）
七国并立（秦、楚、齐、燕、赵、魏、韩），各国拥有独特的修仙文化。

### 灵界（第8-6层天）
随着玩家飞升，七国格局逐渐演变：
- 强国愈强，弱国图存
- 可能形成2-3极格局
- 家族兼并战频繁
- **第8层起**：皇族可统一六国，进而挑战大周

### 太虚境（第5-3层天）
跨服联盟对抗，名额争夺激烈：
- 可能出现统一王朝
- 附庸体系形成
- 证道战决定飞升资格
- **天子可在此制定世界规则**

### 仙界（第2-1层天）
七国合一，转化为仙域体系：
- 第2层天：七国合一为"七仙域"
- 第1层天：九大仙门并立

## 7. 跨层影响机制

上层世界的事件会影响下层世界：

| 上层事件 | 下层影响 | 机制 |
|:---|:---|:---|
| 仙界玩家合道 | 其出身的凡界获得永久"天道祝福" | 该区服所有玩家修炼速度+5% |
| 太虚境国家统一 | 对应下层国家的NPC初始好感度提升 | 促进特定国家崛起 |
| 仙界仙门大战 | 下层对应国家的资源点刷新率波动 | 动态世界事件 |
| **伐周成功** | 天道震动，下层NPC野心值上升 | 促进下层世界皇族更替 |

## 8. 跨国交易与关税

| 交易方 | 购买关税 | 出售关税 |
|--------|----------|----------|
| 本国玩家 | 0% | 0% |
| 其他国家玩家 | +15% | -15%（利润扣除） |
| 仙域玩家 | 0% | 0% |

关税设计旨在鼓励玩家进行战略选择。

## 9. LLM决策入口：国家战略层

### 9.1 LLM适用场景

在国家层面，以下决策场景适合引入LLM进行战略规划：

| 场景 | LLM决策对象 | 规划周期 | 影响范围 |
|:---|:---|:---|:---|
| **国家战略制定** | T0级NPC（皇帝/君主） | 月/次 | 全国家庭、军事、外交 |
| **军事行动规划** | T1级NPC（大将军/统帅） | 周/次 | 军队调动、战场策略 |
| **外交策略制定** | T1级NPC（相国/外交官） | 周/次 | 联盟、贸易、情报 |
| **太子教育计划** | T1级NPC（太子/继承人） | 月/次 | 培养方向、人脉建立 |
| **周室防御** | T0级NPC（周天子） | 月/次 | 调兵布防、合纵连横、镇压反叛 |

### 9.4 与LLM规划系统的衔接

国家战略LLM规划与[NPC的AI决策系统](../npc/12-NPC的AI决策.md)的衔接方式：
- 国家战略计划中的`MILITARY_ORDER` → 注入到目标NPC（如大将军白起）的LLM规划模块
- 国家战略计划中的`DIPLOMACY` → 修改世界状态中的外交关系
- 国家战略计划中的`CULTURAL_STRATEGY` → 生成招募事件，影响NPC诞生率
