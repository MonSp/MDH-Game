# 游戏设计核心Prompt：境界驱动的修仙世界

## 核心设计理念

**"境界为本，万法归宗"** —— 修仙境界是所有系统联动的核心驱动力。

境界提升解锁新功能、新权限、新互动，形成"境界→系统功能→加速修炼"的良性循环。各系统不再孤立，而是相互支撑、有机整体。

---

## 境界体系

### 境界划分（从低到高）
**练气→筑基→金丹→元婴→化神→炼虚→合道→大乘→渡劫→真仙**

每提升一个大境界，自动解锁：
- 经济特权（免税、优先交易、专属拍卖）
- NPC互动权限（高阶NPC任务、信息访问）
- 社交地位（师徒传承效率、家族职位）
- 秘境准入（高阶秘境、专属奖励）
- 战争权限（指挥部队规模、神力干预）

### 境界差距计算
- `calculateRealmGap(player, npc)` 函数计算差距
- 差距影响：交易价格±15%、任务难度修正、NPC态度

## 核心系统联动设计

### 1. 经济系统 —— 道韵值生态

**双货币体系：**
- **灵石**：通用货币，各境界通用
- **道韵值**：金丹期及以上专属货币，用于功法升级、炼制丹药、秘境入场

**境界交易特权：**
| 境界 | 特权等级 | 解锁功能 |
|:---|:---|:---|
| 筑基 | Lv.1 | 基础拍卖参与权 |
| 金丹 | Lv.2 | 灵草拍卖参与权、坊市贵宾 |
| 元婴 | Lv.3 | 高级丹药交易、灵石免税10% |
| 化神 | Lv.4 | 法则碎片交易、优先交易权 |
| 炼虚+ | Lv.5 | 全域免税、家族供奉 |

**境界差距与交易：**
- 玩家境界比NPC高：交易价格×0.85（优惠）
- 玩家境界比NPC低：交易价格×1.15（溢价）

### 2. NPC态度系统

**NPC对玩家的态度（基于境界差距）：**
| 态度 | 境界差距 | 交易修正 | 任务发布 | 信息分享 |
|:---|:---|:---|:---|:---|
| 敬畏 | ≥3大境 | -20% | 核心任务 | 全部 |
| 敬重 | 2大境 | -10% | 高级任务 | 大部分 |
| 平等 | 同境界 | ±0% | 普通任务 | 基础 |
| 轻视 | 低2境 | +10% | 杂务任务 | 少部分 |
| 鄙视 | 低3境+ | +20% | 无 | 极少 |

**特殊NPC态度：**
- 执法堂长老：最低筑基期才可互动
- 皇族NPC：态度固定为"敬畏"
- 仙域NPC：最低元婴期才可见

### 3. 任务系统 —— 境界专属任务

**6种境界专属任务类型：**
- **道心任务**：筑基期突破前必修
- **感悟任务**：金丹期领悟功法前触发
- **资源任务**：元婴期获取突破材料
- **传承任务**：化神期创建功法传承
- **因果任务**：影响后续任务触发
- **心境任务**：影响战斗属性和NPC态度

**因果共鸣系统：**
- 共鸣等级：无缘→薄缘→有缘→深缘→天命
- 高共鸣：突破成功率+10%，任务奖励+20%

### 4. 家族系统 —— 境界权限体系

**境界-职位对应：**
| 境界 | 可担任职位 | 解锁权限 |
|:---|:---|:---|
| 练气 | 普通成员 | 基础资源采集 |
| 筑基 | 执事 | 家族商店折扣 |
| 金丹 | 长老 | 参与家族拍卖 |
| 元婴 | 副族长 | 调动家族资源 |
| 化神 | 族长 | 全部权限 |

**境界贡献双轨制：**
- 境界贡献：高境界成员自动提供"灵气聚集"加成
- 资源贡献：成员上缴资源

### 5. 师徒系统 —— 境界传承

**境界差距与传道效果：**
| 境界差距 | 传道效率加成 | 额外修为共享 |
|:---|:---|:---|
| 1大境 | +10% | 无 |
| 2大境 | +30% | 师父+5% |
| 3大境 | +60% | 师父+10% |
| 4大境+ | +100% | 师父+15% |

**师父心境等级：**
- 1级（心境平和）：额外+10%传道
- 2级（心境坚定）：额外+20%
- 3级（心境通明）：额外+35%
- 4级（心境圆满）：额外+50%

### 6. 秘境探索 —— 境界准入

**秘境等级与准入：**
| 秘境等级 | 最低境界 | 境界差距惩罚 |
|:---|:---|:---|
| 凡阶 | 练气 | 无 |
| 灵阶 | 筑基 | -1级：掉宝-10% |
| 玄阶 | 金丹 | -2级：掉宝-30%，难度+50% |
| 地阶 | 元婴 | -3级：无法进入 |
| 天阶 | 化神 | -4级：无法进入 |
| 仙阶 | 炼虚 | -5级：无法进入 |

**境界优势加成：**
- 高于准入1境：碾压效果，难度-20%，奖励+15%
- 高于准入2境：探索加速30%

**动态奖励公式：**
```
最终奖励 = 基础奖励 × 境界倍数 × 难度倍数 × (1+首通加成)
```

## 跨系统联动核心循环

```
境界提升
    ↓
解锁经济特权（道韵值、免税）→ 获得稀有资源
    ↓
解锁高级NPC互动（任务、态度）→ 获得传承任务
    ↓
提升家族地位（职位、资源）→ 支持更高阶修炼
    ↓
挑战更高秘境（准入、奖励）→ 加速下一个境界突破
```

**具体示例：**
- **金丹期**：解锁灵草拍卖→炼制突破丹→加速元婴突破
- **元婴期**：解锁高级NPC任务→获得功法传承→挑战地阶秘境
- **化神期**：获得家族长老地位→调动家族资源→准备飞升

## 设计原则总结

1. **境界驱动**：境界是解锁一切的核心钥匙
2. **非线性成长**：各系统相互支撑，非线性产出
3. **差异化体验**：不同境界有完全不同的游戏内容
4. **策略深度**：玩家需选择最优成长路径
5. **社交价值**：境界带来社交尊重和特权
6. **有机整体**：经济、任务、NPC、社交、家族、秘境六位一体
