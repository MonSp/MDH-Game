# 秘境探索系统设计

## 1. 设计理念：秘境藏造化，险地出机缘

修仙世界，除了明面上的七国争霸、家族争斗，更隐藏着无数上古遗迹、洞天福地、妖兽巢穴。这些秘境是玩家获取稀有资源、功法、法器的核心途径，也是检验玩家实力和策略的试炼场。

**核心循环**：
```
发现秘境 → 探索解谜 → 战斗挑战 → 获取奖励 → 提升实力 → 探索更高难度秘境
```

## 2. 秘境类型体系

### 2.1 秘境分类

| 秘境类型 | 特点 | 奖励偏向 | 难度 | 刷新周期 |
|:---|:---|:---|:---|:---|
| **遗迹** | 上古修士洞府，机关重重 | 功法、法器 | 中等 | 每周 |
| **洞天福地** | 灵气浓郁，适合修炼 | 修为、灵草 | 低 | 每日 |
| **妖兽巢穴** | 妖兽聚集，危险重重 | 材料、内丹 | 中高 | 每日 |
| **战场遗址** | 古战场，怨气弥漫 | 军功、残魂 | 高 | 每月 |
| **仙府** | 仙人遗留，禁制强大 | 仙阶物品 | 极高 | 每季 |
| **虚空裂缝** | 随机出现，不稳定 | 随机稀有 | 不定 | 随机 |

### 2.2 秘境等级

| 等级 | 名称 | 推荐境界 | 怪物强度 | 奖励品质 |
|:---|:---|:---|:---|:---|
| 1星 | **凡阶秘境** | 练气~筑基 | ×1.0 | 凡~灵阶 |
| 2星 | **灵阶秘境** | 筑基~金丹 | ×1.5 | 灵~玄阶 |
| 3星 | **玄阶秘境** | 金丹~元婴 | ×2.0 | 玄~地阶 |
| 4星 | **地阶秘境** | 元婴~化神 | ×3.0 | 地~天阶 |
| 5星 | **天阶秘境** | 化神~炼虚 | ×5.0 | 天~仙阶 |
| 6星 | **仙阶秘境** | 炼虚以上 | ×10.0 | 仙阶以上 |

### 2.3 境界准入机制

**核心设计：秘境是检验修士境界的试炼场，境界是进入秘境的门槛。**

#### 2.3.1 境界准入规则

| 秘境等级 | 最低境界要求 | 境界差距惩罚 | 说明 |
|:---|:---|:---|:---|
| 1星 | 练气期 | 禁止进入（境界过低） | 练气期修士禁区 |
| 2星 | 筑基期 | 境界>要求+1级：奖励-30% | 练气期强行进入会失败 |
| 3星 | 金丹期 | 境界>要求+1级：奖励-20% | 筑基期强行进入会失败 |
| 4星 | 元婴期 | 境界>要求+1级：奖励-10% | 金丹期强行进入会失败 |
| 5星 | 化神期 | 境界>要求+1级：无惩罚 | 炼虚期+进入有额外奖励 |
| 6星 | 炼虚期 | 无惩罚 | 大乘期+进入有额外奖励 |

#### 2.3.2 境界差距惩罚机制

```
境界差距 = 玩家境界 - 秘境推荐境界

| 境界差距 | 惩罚效果 |
|:---|:---|
| 低于最低要求 | 无法进入（系统阻止） |
| 境界=要求 | 无惩罚，标准奖励 |
| 境界>要求1级 | 奖励-10%~20%（根据秘境类型） |
| 境界>要求2级 | 奖励-30%，怪物难度不变 |
| 境界>要求3级 | 奖励-50%，怪物难度-20%（碾压） |
```

#### 2.3.3 境界优势加成

高境界玩家进入低境界秘境时，可获得以下优势：

| 境界优势 | 效果 |
|:---|:---|
| **碾压效果** | 怪物难度-20%，战斗更轻松 |
| **探索加速** | 机关解谜时间-30% |
| **资源独占** | 掉落归玩家一人，无需分配 |
| **时间缩短** | 秘境探索时间上限-50% |
| **额外奖励** | 境界每超1级，额外+5%灵石奖励 |

### 2.4 动态奖励机制

**核心设计：奖励应根据玩家境界和秘境表现动态调整。**

#### 2.4.1 基础奖励计算

```
最终奖励 = 基础奖励 × 境界匹配系数 × 探索评价系数 × 难度系数

境界匹配系数：
  完美匹配（境界=要求） → 1.0
  略高（境界>要求1级） → 0.9~1.0
  过高（境界>要求2级） → 0.7~0.9
  碾压（境界>要求3级） → 0.5~0.7

探索评价系数：
  S级评价（无伤+全清） → 1.5
  A级评价（轻伤+全清） → 1.2
  B级评价（完成+少量漏怪） → 1.0
  C级评价（完成+中量漏怪） → 0.8
  D级评价（完成+大量漏怪） → 0.6

难度系数：
  普通难度 → 1.0
  困难难度 → 1.5
  噩梦难度 → 2.0
```

#### 2.4.2 境界专属奖励

每个境界层级的玩家在秘境中有专属奖励掉落：

| 境界层级 | 专属掉落 | 稀有掉落 |
|:---|:---|:---|
| 练气~筑基 | 凡阶材料、基础灵石 | 洗髓丹（概率） |
| 金丹~元婴 | 灵阶材料、内丹 | 筑基丹/凝婴丹（概率） |
| 化神~炼虚 | 地阶材料、灵脉精华 | 化神丹（概率） |
| 大乘~渡劫 | 天阶材料、法则碎片 | 飞升令（概率） |
| 炼虚+ | 仙阶材料、仙晶 | 仙阶功法/法器（概率） |

#### 2.4.3 首通奖励与重复探索

```
首通奖励 = 基础奖励 × 3.0 + 境界专属首通礼包

重复探索奖励：
  第2-5次探索 → 基础奖励 × 1.0
  第6-10次探索 → 基础奖励 × 0.8
  10次以上 → 基础奖励 × 0.5（日常化）
```

### 2.5 秘境难度自适应

秘境的难度会根据进入玩家的平均境界进行自适应调整：

```
秘境难度调整 = f(玩家平均境界, 秘境推荐境界)

| 平均境界差距 | 怪物强度调整 | BOSS血量调整 | 机关难度调整 |
|:---|:---|:---|:---|
| 玩家>>秘境 | -20% | -15% | -30% |
| 玩家>秘境 | -10% | -5% | -10% |
| 玩家≈秘境 | 0% | 0% | 0% |
| 玩家<秘境 | +10% | +5% | +10% |
| 玩家<<秘境 | 禁止进入 | - | - |

## 3. 秘境生成机制

### 3.1 生成规则

```
秘境生成条件：
- 每日0点刷新普通秘境（1-3星）
- 每周一刷新高级秘境（3-4星）
- 每月1日刷新顶级秘境（4-5星）
- 随机事件触发特殊秘境（虚空裂缝等）

生成位置：
- 随机分布在地图边缘或特殊地形
- 每个国家境内至少保持2-3个活跃秘境
- 秘境位置对玩家隐藏，需通过探索发现
```

### 3.2 发现机制

| 发现方式 | 说明 | 效率 |
|:---|:---|:---|
| **随机遭遇** | 地图移动时低概率发现 | 极低 |
| **情报购买** | 坊市购买秘境情报 | 高 |
| **NPC告知** | 好感度高的NPC可能透露 | 中 |
| **推演测算** | 消耗修为进行推演 | 中 |
| **家族情报网** | 家族建筑"情报堂"提供 | 高 |
| **天道启示** | 高境界玩家随机获得感应 | 极高 |

## 4. 秘境探索流程

### 4.1 进入准备

```
发现秘境位置
  ↓
前往秘境入口
  ↓
满足进入条件？
  ├─ 境界要求
  ├─ 人数限制（单人/组队）
  ├─ 进入次数限制
  └─ 特殊道具要求
  ↓
选择探索模式
  ├─ 普通探索：标准难度，标准奖励
  ├─ 困难探索：难度+50%，奖励+100%
  └─ 噩梦探索：难度+100%，奖励+200%
```

### 4.2 秘境内部结构

#### 4.2.1 房间式结构

```
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 入口大厅 │ ──→ │ 机关走廊 │ ──→ │ 守卫厅堂 │
└────┬────┘     └────┬────┘     └────┬────┘
     │               │               │
     ▼               ▼               ▼
┌─────────┐     ┌─────────┐     ┌─────────┐
│ 藏宝室  │     │ 修炼室  │     │ BOSS殿  │
│ (支线)  │     │ (支线)  │     │ (主线)  │
└─────────┘     └─────────┘     └─────────┘
```

#### 4.2.2 房间类型

| 房间类型 | 内容 | 风险 | 奖励 |
|:---|:---|:---|:---|
| **普通厅** | 少量小怪 | 低 | 少量灵石 |
| **精英厅** | 精英怪 | 中 | 材料/残卷 |
| **机关厅** | 解谜机关 | 中 | 宝箱 |
| **陷阱厅** | 隐藏陷阱 | 高 | 大量灵石 |
| **藏宝室** | 无怪，纯奖励 | 无 | 稀有道具 |
| **修炼室** | 灵气浓郁 | 无 | 修为加成 |
| **BOSS殿** | 最终BOSS | 极高 | 核心奖励 |

### 4.3 探索机制

#### 4.3.1 迷雾系统

- 进入秘境后，地图被迷雾覆盖
- 每进入一个房间，揭示相邻房间
- 部分房间有特殊视野限制

#### 4.3.2 选择分支

```
到达岔路口：
├─ 左侧通道：感应到灵气波动（可能是藏宝室或陷阱）
├─ 右侧通道：听到妖兽嘶吼（战斗房间）
└─ 中间通道：通往下一层（继续前进）

玩家选择影响：
- 探索路线 → 遭遇顺序
- 房间选择 → 资源获取
- 隐藏房间 → 额外奖励
```

#### 4.3.3 疲劳与补给

| 机制 | 说明 |
|:---|:---|
| **探索疲劳** | 每战斗一场+10疲劳，影响属性 |
| **灵力消耗** | 战斗和机关消耗灵力，无法自然恢复 |
| **补给限制** | 秘境内使用丹药效果-50% |
| **撤退机制** | 可随时撤退，但损失50%已获奖励 |

## 6. 秘境BOSS设计

### 6.1 BOSS类型

| BOSS类型 | 特点 | 战斗机制 | 代表 |
|:---|:---|:---|:---|
| **上古傀儡** | 高防御，机械行动 | 阶段转换，弱点暴露 | 青铜守卫 |
| **妖兽王者** | 高攻击，狂暴机制 | HP降低后狂暴 | 赤焰虎王 |
| **残魂修士** | 法术型，召唤小弟 | 召唤+范围法术 | 幽冥道人 |
| **阵灵** | 控场型，环境利用 | 改变战场环境 | 八卦阵灵 |
| **守护者** | 均衡型，多阶段 | 多阶段，技能变化 | 仙府守护者 |

### 6.2 BOSS战机制

#### 6.2.1 阶段转换

```
BOSS战典型流程：

第一阶段（100%-70% HP）：
- 使用基础技能组合
- 攻击模式固定

第二阶段（70%-30% HP）：
- 解锁新技能
- 攻击模式变化
- 可能召唤小怪

第三阶段（30%-0% HP）：
- 进入狂暴/虚弱状态
- 使用终极技能
- 战斗节奏加快
```

#### 6.2.2 特殊机制

| 机制 | 说明 | 应对策略 |
|:---|:---|:---|
| **怒气系统** | BOSS受到伤害积累怒气，满怒气释放大招 | 控制输出节奏 |
| **护盾机制** | BOSS周期性获得护盾 | 保留爆发技能破盾 |
| **场地效果** | BOSS改变战场环境 | 利用环境或快速转移 |
| **分身术** | BOSS召唤分身 | 识别真身（伤害差异/特效） |
| **吸血机制** | BOSS攻击恢复生命 | 控制小怪数量，减少吸血来源 |

| BOSS等级 | 必掉 | 概率掉落 | 稀有掉落 |
|:---|:---|:---|:---|
| 1星 | 灵石×100 | 凡阶材料 | - |
| 2星 | 灵石×500 | 灵阶材料/残卷 | 灵阶功法 |

## 10. 与现有系统的联动

### 10.1 与功法系统的联动

- 秘境是高级功法的主要获取途径
- 部分秘境需要特定功法才能解开机关
- BOSS战考验功法搭配策略

### 10.2 与炼丹炼器的联动

- 秘境产出稀有炼丹/炼器材料
- 部分秘境环境需要丹药辅助探索
- 法器强化材料主要来自秘境

### 10.3 与家族系统的联动

- 家族可组织秘境探险队
- 家族建筑"情报堂"提升秘境发现率
- 家族共享秘境情报

### 11.2 LLM输入数据结构（秘境叙事）

```json
