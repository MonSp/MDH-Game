# 战略地图与资源系统

## 1. 系统概述

《太古纪元：霸业》采用**2.5D像素风格战略地图**，结合全战三国的战略视角和修仙世界的奇幻元素。地图不仅是战斗场所，更是国家战略的核心——资源分布、地形特征、灵脉走向都会影响国家发展和战争走向。

### 1.1 核心设计理念

- **战略地图为核心**：所有游戏活动都在战略地图上展开
- **地形影响战局**：不同地形对战斗、修炼、资源产出有不同影响
- **资源驱动战争**：资源分布不均是战争的主要诱因
- **灵脉决定修炼**：灵脉分布影响修炼效率和境界突破
- **动态变化**：地形可被战争改变，资源可被开采耗尽

## 2. 地图架构

### 2.1 地图层级

| 层级 | 说明 | 尺寸 | 显示内容 |
|:---|:---|:---|:---|
| **世界地图** | 显示整个世界格局 | 1000×1000格 | 国家边界、首都位置、主要地形 |
| **区域地图** | 显示单个国家 | 300×300格 | 城市、资源点、军队位置 |
| **战场地图** | 显示战斗区域 | 200×200格 | 地形细节、单位位置、法术效果 |
| **城市地图** | 显示城市内部 | 50×50格 | 建筑、NPC、资源建筑 |

### 2.2 地图生成

采用**AI生成+手动调整**的方式：

1. **AI生成初始地图**：战略AI根据世界设定生成初始地形
2. **灵脉自动分布**：根据地形和灵气浓度自动分布灵脉
3. **资源点生成**：根据地形和灵脉分布生成资源点
4. **国家边界划分**：根据地形和战略平衡划分国家边界
5. **手动调整**：开发者可手动调整关键位置

### 2.3 地图数据结构

```json
{
  "world_map": {
    "size": {"width": 1000, "height": 1000},
    "terrain_grid": [[...]],  // 1000×1000的地形数据
    "resource_points": [...],  // 资源点列表
    "spirit_veins": [...],     // 灵脉列表
    "countries": [...],        // 国家边界
    "cities": [...],           // 城市位置
    "armies": [...]            // 军队位置
  }
}
```

## 4. 资源系统

### 4.1 资源类型

| 资源 | 用途 | 产出地形 | 消耗速度 | 可再生 |
|:---|:---|:---|:---|:---|
| **灵石** | 修炼、交易、战争 | 灵脉、矿脉 | 快 | 是 |
| **粮食** | 维持军队、人口 | 平原、灵田 | 中 | 是 |
| **铁矿** | 打造武器、装备 | 山地、矿脉 | 中 | 是 |
| **木材** | 建造建筑、器械 | 森林 | 中 | 是 |
| **药材** | 炼丹、医疗 | 沼泽、森林 | 慢 | 是 |
| **火晶** | 火属性功法、法器 | 火山 | 慢 | 是 |
| **水灵** | 水属性功法、法器 | 河流、湖泊 | 慢 | 是 |
| **功法残卷** | 学习新功法 | 遗迹 | 极慢 | 否 |
| **天材地宝** | 突破境界、炼制丹药 | 随机 | 极慢 | 否 |

### 4.3 资源争夺

资源点是战争的主要诱因：

| 争夺方式 | 说明 | 成功率 | 后果 |
|:---|:---|:---|:---|
| **外交谈判** | 通过外交手段获得资源点 | 取决于外交关系 | 可能建立联盟 |
| **经济购买** | 用灵石购买资源点 | 取决于对方意愿 | 消耗灵石 |
| **军事占领** | 派军队占领资源点 | 取决于军事实力 | 引发战争 |
| **秘密窃取** | 派间谍窃取资源 | 取决于间谍能力 | 可能被发现 |
| **修炼争夺** | 高阶修士直接占领 | 取决于境界差距 | 引发修士战争 |

## 5. 灵脉系统

### 5.1 灵脉类型

| 灵脉类型 | 灵气浓度 | 修炼加成 | 特殊效果 | 稀有度 |
|:---|:---|:---|:---|:---|
| **普通灵脉** | 1× | +10% | 无 | 常见 |
| **高级灵脉** | 3× | +30% | 突破成功率+10% | 较少 |
| **极品灵脉** | 5× | +50% | 突破成功率+20% | 稀有 |

| **仙脉** | 20× | +200% | 可建立仙门 | 传说 |

灵脉是战略要地，控制灵脉意味着控制修炼资源：

| 灵脉控制 | 战略价值 | 战争影响 |
|:---|:---|:---|
| **控制普通灵脉** | 维持基本修炼 | 局部冲突 |
| **控制高级灵脉** | 提升修炼效率 | 区域战争 |
| **控制极品灵脉** | 培养高阶修士 | 国家战争 |
| **控制龙脉** | 建立都城资格 | 全面战争 |
| **控制仙脉** | 建立仙门资格 | 世界大战 |

## 9. 地图动态变化

### 9.1 战争影响

战争会永久改变地图：

| 战争影响 | 效果 | 恢复时间 |
|:---|:---|:---|
| **城市毁灭** | 城市变为废墟 | 不可恢复 |
| **地形破坏** | 平原变为焦土 | 10年 |
| **灵脉枯竭** | 灵脉灵气降低 | 100年 |
| **森林焚烧** | 森林变为荒地 | 50年 |
| **河流改道** | 河流位置改变 | 不可恢复 |

### 9.2 修炼影响

高阶修士修炼会影响地图：

| 修炼影响 | 效果 | 范围 |
|:---|:---|:---|
| **突破化神** | 周围灵气浓度提升 | 10格 |
| **渡劫成功** | 周围地形改变 | 100格 |
| **合道成功** | 整个世界灵气提升 | 全世界 |

## 10. 地图性能优化

### 10.1 渲染优化

- **LOD系统**：远处地形简化渲染
- **动态加载**：只加载视野范围内的地形
- **缓存机制**：缓存常用地形数据
- **批量渲染**：相同地形批量渲染

### 10.2 数据优化

- **分层存储**：不同层级地图分开存储
- **增量更新**：只更新变化的部分
- **压缩算法**：使用压缩算法减少存储空间
- **内存管理**：及时释放不用的地图数据
