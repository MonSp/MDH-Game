# 修仙境界体系

## 1. 九重天世界架构

游戏采用"金字塔式修仙宇宙"设计，共分为九重天世界：

```
                    ┌─────────────┐
                    │   第1层天   │  (唯一，混元仙界)
                    │  混元仙界   │  灵气×20.0
                    └──────┬──────┘
                           │ (N个第2层天飞升汇聚)
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌─────────┐  ┌─────────┐  ┌─────────┐
        │第2层天-1│  │第2层天-2│  │第2层天-N│  (仙界门槛)
        │ 仙界   │  │ 仙界   │  │ 仙界   │  灵气×10.0
        └─────────┘  └─────────┘  └─────────┘
              │            │            │

                         │
              ┌──────────┼──────────┐

        ┌─────────┐┌─────────┐┌─────────┐
```

## 3.5 修为获取途径

修为是突破境界的必要条件，玩家与NPC通过以下途径获取修为：

### 3.5.1 修为获取方式

| 途径 | 基础修为 | 说明 |
|:---|:---|:---|
| 打坐修炼 | 10×灵气倍率/次 | 日常修炼方式 |
| 采集灵田 | 30×灵气倍率/次 | 资源采集活动 |
| 击杀NPC | 50×灵气倍率/次 | 战斗收益 |

### 3.5.2 国家特质加成

不同国家的修仙者受国家特质影响，修炼效率有所差异：

| 国家 | 特质 | 加成效果 |
|:---|:---|:---|
| 齐国 | 学术修仙 | 打坐领悟速度+20% |
| 燕国 | 苦修之士 | 打坐灵气吸收效率+10% |
| 秦国 | 兵甲修仙 | 杀人夺宝修为+10% |

### 3.5.3 灵气倍率与修为关系

修为获取受世界层级灵气倍率影响，灵气倍率越高，同样的修炼行为获得的修为越多。

灵气倍率表（各层世界）：

| 层级 | 灵气倍率 | 打坐修为 | 采集修为 | 击杀修为 |
|:---|:---|:---|:---|:---|
| 第9层 | ×1.0 | 10 | 30 | 50 |
| 第8层 | ×1.5 | 15 | 45 | 75 |
| 第7层 | ×2.0 | 20 | 60 | 100 |
| 第6层 | ×3.0 | 30 | 90 | 150 |
| 第5层 | ×4.0 | 40 | 120 | 200 |

## 4. 突破机制

1. 通过修炼、采集资源或击杀NPC积累修为
2. 修为达到当前境界上限后，可尝试突破
3. 突破需要消耗对应数量的灵石
4. 突破成功后，血量、灵力、战力提升（受灵气倍率影响）
5. 达到"渡劫"境界后，将面临九天雷劫，准备飞升上界
6. 各层世界有最高境界限制，达到后需飞升才能继续突破

## 5. 飞升系统

### 5.1 飞升条件

| 条件类型 | 具体要求 | 设计意图 |
|:---|:---|:---|
| 境界要求 | 达到当前世界最高境界 | 硬性门槛 |
| 战力要求 | 战力值达到当前世界前10%均值 | 防止速成号飞升 |
| 功德要求 | 完成至少3次"天道任务" | 确保玩家体验过核心玩法 |
| 资源要求 | 缴纳飞升令×1 + 灵石×100000 | 经济回收 |
| 渡劫要求 | 成功渡过九重天劫 | 仪式感+风险 |

### 5.2 飞升流程

```
达到当前世界最高境界
         │
         ▼
前往本国皇城"飞升台"
         │
         ▼
验证飞升条件（飞升令、天道任务、灵石）
         │
         ▼
消耗资源，引动天劫
         │
         ▼
┌────────────────┐
│  90%成功率     │
│  10%失败-重伤  │
└────────────────┘
         │
         ▼
角色数据迁出当前区服
         │
         ▼
根据负载分配至目标世界
         │
         ▼
目标世界公告欢迎
         ▼
重置为化神境界，属性×0.5
```

### 5.3 飞升效果

- 境界重置为化神
- 属性大幅提升（受目标层灵气倍率影响）
- 可在新世界继续修炼至该层最高境界
- 飞升次数记录

## 6. 轮回转生系统

高天层的玩家（第6层及以上），可选择主动转生至低层世界：

| 转生类型 | 条件 | 效果 |
|:---|:---|:---|
| **神念投影** | 消耗"分神秘法"，CD 7天 | 在当前所在的下层世界创建一个临时分身，存在2小时 |
| **真灵转世** | 放弃当前角色大部分修为 | 在第9层新建角色，保留称号/外观/部分记忆，获得"转世灵童"天赋 |
| **道统传承** | 飞升时选择"留下道统" | 在原家族留下传承石碑，后人参悟可获得功法 |

### 6.1 转世灵童天赋

真灵转世后的新角色获得特殊天赋：

| 天赋名称 | 效果 |
|:---|:---|
| **宿慧** | 功法领悟速度+50% |
| **轮回印** | 每提升一个大境界，解锁一段前世记忆（获得资源/功法） |
| **因果缠身** | 与前世的仇敌/挚友产生特殊交互选项 |

### 6.2 降维打击的平衡

为防止高天层玩家无限碾压低层：
- **神念投影**有严格的CD和时长限制
- **真灵转世**需要放弃原角色，是重大决策
- 低层世界有境界压制：高境界转生者前期战力优势会被压缩

## 7. LLM决策入口：修炼与突破规划

### 7.1 LLM适用场景

在修炼境界层面，以下决策场景适合引入LLM进行战略规划：

| 场景 | LLM决策对象 | 规划周期 | 影响范围 |
|:---|:---|:---|:---|
| **突破时机决策** | T2级及以上NPC（长老/家主） | 实时 | 闭关资源、成功率 |
| **功法选择** | T2级及以上NPC（长老/家主） | 月/次 | 修炼效率、战斗风格 |
| **渡劫准备** | 即将渡劫的NPC | 实时 | 天道任务、护法安排 |

### 7.4 与LLM规划系统的衔接

修炼突破LLM规划与[NPC的AI决策系统](../npc/12-NPC的AI决策.md)的衔接方式：
- 修炼计划中的`CULTIVATE_BREAKTHROUGH` → 注入到NPC行为树，优先级1覆盖所有其他行为
- 修炼计划中的`STATE_AFFAIRS` → 修改NPC的日常活动状态
- 突破成功/失败事件 → 触发世界状态更新和相应NPC的LLM重新规划
