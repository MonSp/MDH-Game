# 阵法与符箓系统设计

## 1. 设计理念：阵借天地力，符凝一念间

修仙者除了自身修为，更可借天地之力为己用。阵法以天地为棋盘，以灵气为棋子，布下杀局或福地；符箓将神通凝于方寸之间，一念激发，瞬息千里。本系统为游戏增添策略深度，让战斗不止于拳脚功法，更有运筹帷幄之乐。

**核心循环**：
```
学习阵图/符纹 → 收集材料 → 布置/绘制 → 实战运用 → 精进领悟
```

## 2. 阵法系统

### 2.1 阵法分类

| 阵法类型 | 功能 | 适用场景 | 代表阵法 |
|:---|:---|:---|:---|
| **杀阵** | 攻击敌人 | 战斗、防守据点 | 诛仙剑阵、万剑阵 |
| **防阵** | 保护己方 | 洞府、营地防守 | 金刚阵、玄武阵 |
| **困阵** | 限制移动 | 抓捕、拖延 | 迷踪阵、八卦困阵 |
| **幻阵** | 迷惑感知 | 隐藏、诱敌 | 九曲黄河阵、蜃楼阵 |
| **聚灵阵** | 聚集灵气 | 修炼、恢复 | 聚灵阵、周天星斗阵 |
| **传送阵** | 空间转移 | 快速移动 | 缩地阵、跨界阵 |
| **封印阵** | 封印目标 | 镇压、封印 | 五行封印阵、锁龙阵 |

### 2.2 阵法品质

| 品质 | 范围 | 威力倍率 | 布置时间 | 维持消耗 |
|:---|:---|:---|:---|:---|
| **凡阵** | 1-3丈 | ×1.0 | 3秒 | 10灵石/小时 |
| **灵阵** | 3-10丈 | ×1.5 | 10秒 | 50灵石/小时 |
| **玄阵** | 10-30丈 | ×2.0 | 30秒 | 200灵石/小时 |
| **地阵** | 30-100丈 | ×3.0 | 2分钟 | 1000灵石/小时 |
| **天阵** | 100-300丈 | ×5.0 | 10分钟 | 5000灵石/小时 |
| **仙阵** | 300丈+ | ×10.0 | 1小时 | 20000灵石/小时 |

### 2.3 阵法构成

#### 2.3.1 阵基

阵法的物理载体，决定阵法规模：

| 阵基材料 | 品质上限 | 耐久 | 特殊效果 |
|:---|:---|:---|:---|
| **普通石块** | 凡阵 | 低 | 无 |
| **灵玉** | 灵阵 | 中 | 灵气传导+10% |
| **玄铁** | 玄阵 | 高 | 坚固，难破坏 |
| **星辰砂** | 地阵 | 极高 | 自动吸收星力 |
| **虚空石** | 天阵 | 近乎无限 | 可隐藏于虚空 |
| **混沌晶** | 仙阵 | 无限 | 自我演化 |

#### 2.3.2 阵眼

阵法核心，决定阵法类型和威力：

| 阵眼类型 | 作用 | 获取 |
|:---|:---|:---|
| **灵石阵眼** | 基础能量源 | 灵石镶嵌 |
| **法器阵眼** | 增强特定效果 | 法器置入 |
| **妖核阵眼** | 赋予妖兽特性 | 妖核镶嵌 |
| **修士阵眼** | 人为操控，灵活多变 | 修士坐镇 |
| **天地阵眼** | 借天地之力，威力最大 | 特殊地点 |

#### 2.3.3 阵纹

阵法的"程序代码"，决定具体效果：

```
阵纹复杂度：
- 简单阵纹：3-5笔，凡~灵阵
- 复杂阵纹：10-20笔，玄~地阵
- 繁复阵纹：50-100笔，天阵
- 大道阵纹：千笔以上，仙阵
```

### 2.4 阵法布置流程

```
选择阵图
  ↓
准备阵基材料
  ↓
选择布置地点
  ↓
安放阵基（按阵图位置）
  ↓
刻画阵纹
  ↓
置入阵眼
  ↓
激活阵法（消耗灵石）
  ↓
阵法运行（持续消耗）
```

### 2.5 阵法实战运用

#### 2.5.1 个人战斗

| 运用方式 | 说明 | 效果 |
|:---|:---|:---|
| **预设陷阱** | 提前布置，诱敌深入 | 敌人进入范围触发 |
| **即时布阵** | 战斗中快速布置小型阵法 | 3秒内布置凡阵 |
| **阵盘激发** | 使用预制的阵盘 | 瞬间激活，一次性 |
| **移动阵法** | 以自身为阵眼移动 | 跟随玩家的小型阵法 |

#### 2.5.2 家族/国家战争

| 运用方式 | 说明 | 战略价值 |
|:---|:---|:---|
| **护山大阵** | 保护家族领地 | 防御外敌入侵 |
| **战场阵法** | 大规模战争中布置 | 改变局部战局 |
| **封印阵** | 封印敌方强者 | 限制敌方高端战力 |
| **传送阵网** | 建立快速调动网络 | 战略机动 |

### 2.6 破阵机制

| 破阵方式 | 说明 | 效率 |
|:---|:---|:---|
| **蛮力破阵** | 以力破巧，攻击阵基 | 低，但通用 |
| **寻阵眼** | 找到并破坏阵眼 | 高，需要眼力 |
| **解阵纹** | 逆向破解阵纹 | 极高，需要阵法知识 |
| **以阵破阵** | 用相克阵法对冲 | 中，需要对应阵法 |
| **等待消散** | 阵法能量耗尽 | 极低，但安全 |

## 3. 符箓系统

### 3.1 符箓分类

| 符箓类型 | 功能 | 使用方式 | 代表符箓 |
|:---|:---|:---|:---|
| **攻击符** | 造成伤害 | 投掷/贴附 | 火球符、雷符 |
| **防御符** | 抵挡伤害 | 贴附/激发 | 金刚符、护盾符 |
| **辅助符** | 增益效果 | 贴附/服用 | 神行符、大力符 |
| **控制符** | 限制行动 | 投掷/贴附 | 定身符、迷魂符 |
| **传送符** | 空间移动 | 激发 | 遁地符、回城符 |
| **封印符** | 封印能力 | 贴附 | 封灵符、禁法符 |
| **召唤符** | 召唤助力 | 激发 | 唤兽符、请神符 |
| **特殊符** | 独特效果 | 各异 | 隐身符、变形符 |

### 3.2 符箓品质

| 品质 | 威力倍率 | 持续时间 | 绘制难度 | 材料要求 |
|:---|:---|:---|:---|:---|
| **凡符** | ×1.0 | 瞬间 | 极易 | 黄纸+朱砂 |
| **灵符** | ×1.5 | 1分钟 | 容易 | 灵纸+灵墨 |
| **玄符** | ×2.0 | 10分钟 | 中等 | 玄纸+妖血 |
| **地符** | ×3.0 | 1小时 | 困难 | 地皮+灵兽血 |
| **天符** | ×5.0 | 1天 | 极难 | 天蚕丝+龙血 |
| **仙符** | ×10.0 | 永久/特殊 | 传说 | 仙材+仙血 |

### 3.3 符箓材料

#### 3.3.1 符纸

| 符纸类型 | 品质上限 | 特性 | 来源 |
|:---|:---|:---|:---|
| **黄纸** | 凡符 | 无 | 坊市 |
| **灵纸** | 灵符 | 灵气传导+10% | 灵植制作 |
| **玄纸** | 玄符 | 可承载复杂符文 | 特殊工艺 |
| **兽皮纸** | 地符 | 自带妖兽属性 | 妖兽皮革 |
| **天蚕丝纸** | 天符 | 近乎不朽 | 天蚕产出 |
| **虚空纸** | 仙符 | 可承载法则 | 虚空采集 |

#### 3.3.2 符墨

| 符墨类型 | 效果加成 | 来源 |
|:---|:---|:---|
| **朱砂墨** | 无 | 矿物研磨 |
| **灵墨** | 威力+10% | 灵草汁液 |
| **妖血墨** | 威力+20%，附加妖兽特性 | 妖兽血液 |
| **灵兽血墨** | 威力+30% | 灵宠血液 |
| **龙血墨** | 威力+50% | 龙族血液（传说） |

### 3.4 符箓绘制流程

```
准备符纸 + 符墨 + 符笔
  ↓
选择符纹模板
  ↓
凝神静气（小游戏：保持专注度）
  ↓
绘制符纹（小游戏：跟随笔画）
  ↓
注入灵力（决定威力）
  ↓
成符判定
  ├─ 失败 → 材料损失
  ├─ 成功 → 获得符箓
  └─ 大成功 → 品质+1
```

### 3.5 绘制小游戏

#### 3.5.1 专注度保持

```
机制：
- 绘制过程中专注度会持续下降
- 玩家需点击"凝神"按钮维持
- 外界干扰（如战斗）会降低专注度
- 专注度<30%时绘制失败率大幅上升
```

#### 3.5.2 笔画跟随

```
机制：
- 屏幕上显示符纹虚线
- 玩家需用鼠标/手指跟随绘制
- 偏离度<10%为完美，<30%为合格
- 合格率>80%才能成符
```

### 3.6 符箓使用

| 使用方式 | 说明 | 适用符箓 |
|:---|:---|:---|
| **直接激发** | 撕碎/念咒，即时生效 | 攻击、防御、传送 |
| **贴附** | 贴在目标上，持续生效 | 辅助、封印、控制 |
| **埋设** | 埋在地下，触发生效 | 陷阱类 |
| **服用** | 特殊符箓可吞服 | 增益类（如大力符） |
| **组合** | 多张符箓组合使用 | 特殊效果 |

### 3.7 符箓存储

| 存储方式 | 容量 | 特性 |
|:---|:---|:---|
| **普通储物袋** | 100张 | 无特殊效果 |
| **符箓匣** | 500张 | 符箓威力保持100% |
| **养符盒** | 100张 | 符箓随时间缓慢增强 |
| **虚空符囊** | 无限 | 仙器级，符箓不会失效 |

> **注意**：符箓有保质期，凡符7天，灵符30天，玄符1年，地符10年，天符100年，仙符永久。

## 4. 阵法与符箓的配合

### 4.1 阵符结合

| 结合方式 | 效果 | 示例 |
|:---|:---|:---|
| **符阵** | 以符箓为阵基，快速布置 | 九九八十一道雷符组成雷阵 |
| **阵中符** | 阵法中预设符箓陷阱 | 迷踪阵中隐藏定身符 |
| **符启阵** | 以符箓激活预设阵法 | 遁地符激活地下传送阵 |
| **阵养符** | 在聚灵阵中绘制符箓 | 品质+1 |

### 4.2 典型组合

```
【困杀组合】
八卦困阵 + 万剑符×10
效果：困住敌人后，激发万剑符进行绞杀

【速攻组合】
神行符 + 缩地阵
效果：短距离瞬移，快速接近或脱离敌人

【持久战组合】
聚灵阵 + 回灵符
效果：在阵中灵力无限续航

【封印组合】
五行封印阵 + 封灵符
效果：多层封印，难以破解
```

## 6. 与现有系统的联动

### 6.1 与战斗系统的联动

- 阵法和符箓为战斗增添策略维度
- 功法+阵法+符箓的组合创造无限可能
- 战场环境可被阵法改变

### 6.2 与家族系统的联动

- 家族可建立护山大阵
- 家族战中阵法决定据点防守能力
- 家族可批量生产符箓供应成员

### 6.3 与秘境的联动

- 秘境中常有上古阵法需要破解
- 某些秘境需要特定符箓才能进入
- 秘境中可获得稀有阵图和符纹

### 6.4 与国家特质的联动

| 国家 | 阵法/符箓加成 |
|:---|:---|
| **齐国** | 阵法领悟速度+20% |
| **韩国** | 符箓绘制成功率+10% |
