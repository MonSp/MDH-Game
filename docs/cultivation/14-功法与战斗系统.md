# 功法与战斗系统设计

## 1. 设计理念：万法归宗，战无定式

修仙世界，功法为根，战斗为叶。本系统构建一个**"功法决定战斗风格，战斗反哺功法领悟"**的闭环体系。玩家不再只是数值对撞，而是通过功法搭配、技能释放时机、战场走位，创造出千变万化的战斗策略。

**核心循环**：
```
获取功法 → 修炼领悟 → 战斗中运用 → 获得实战经验 → 功法精进/创造新招
```

## 2. 功法体系架构

### 2.1 功法分类

功法分为六大类，每类决定不同的战斗定位：

| 功法类型 | 定位 | 核心机制 | 战争应用 | 代表功法 |
|:---|:---|:---|:---|:---|
| **剑诀** | 爆发输出 | 高单体伤害，暴击加成 | 斩将夺旗，快速击杀敌将 | 《太虚剑诀》《万剑归宗》 |
| **体术** | 坦克/控制 | 高生命，格挡反击 | 冲锋陷阵，吸引火力 | 《金刚不坏功》《八极崩》 |
| **法术** | 范围输出 | AOE伤害，元素效果 | 军团压制，地形改造 | 《九霄雷法》《三昧真火》 |
| **遁术** | 机动/闪避 | 位移，先手优势 | 快速机动，侧翼突袭 | 《缩地成寸》《逍遥游》 |
| **心法** | 辅助/续航 | 回血回蓝，增益Buff | 士气维持，军团治疗 | 《长生诀》《菩提心经》 |
| **阵诀** | 控场/策略 | 领域效果，改变战场 | 护国大阵，战场控制 | 《八卦阵图》《诛仙剑阵》 |

### 2.2 功法品质

| 品质 | 颜色 | 领悟难度 | 成长上限 | 获取途径 |
|:---|:---|:---|:---|:---|
| **凡阶** | 白色 | 极易 | 3层 | 坊市购买、基础任务 |
| **灵阶** | 绿色 | 容易 | 5层 | 遗迹探索、家族兑换 |
| **玄阶** | 蓝色 | 中等 | 7层 | 秘境掉落、NPC传授 |
| **地阶** | 紫色 | 困难 | 9层 | 高级秘境、国战奖励 |
| **天阶** | 橙色 | 极难 | 12层 | 飞升奖励、伐周掉落 |
| **仙阶** | 金色 | 传说 | 15层 | 仙界专属、合道传承 |

### 2.3 功法层数与效果

每层功法提供固定属性加成和技能效果提升：

```
功法层数效果公式：
基础效果 × (1 + 0.1 × 层数) × 品质系数

品质系数：凡0.8 / 灵1.0 / 玄1.2 / 地1.5 / 天2.0 / 仙3.0
```

**示例：《太虚剑诀》（玄阶剑诀）**

| 层数 | 属性加成 | 解锁技能 | 技能效果 |
|:---|:---|:---|:---|
| 1层 | 剑气伤害+12% | 太虚一剑 | 单体120%攻击力伤害 |
| 3层 | 剑气伤害+36% | 剑气纵横 | 对前方3格造成80%攻击力伤害 |
| 5层 | 剑气伤害+60% | 人剑合一 | 下3次攻击必暴击 |
| 7层 | 剑气伤害+84% | 万剑归宗 | 全场随机10道剑气，每道150%伤害 |

## 3. 功法获取途径

### 3.1 获取方式一览

| 途径 | 获取类型 | 品质范围 | 说明 |
|:---|:---|:---|:---|
| **坊市购买** | 功法残卷 | 凡~灵阶 | 基础功法来源 |
| **遗迹探索** | 完整功法/残卷 | 灵~玄阶 | 30%概率掉落 |
| **NPC传授** | 完整功法 | 凡~地阶 | 好感度≥80的NPC可能传授 |
| **秘境通关** | 完整功法 | 玄~天阶 | 核心获取途径 |
| **家族藏经阁** | 残卷/完整 | 灵~地阶 | 消耗贡献兑换 |
| **国战奖励** | 完整功法 | 地~天阶 | 军功兑换 |
| **飞升奖励** | 完整功法 | 天阶 | 每层飞升可选一本 |
| **自创功法** | 完整功法 | 玄~仙阶 | 高境界玩家自创 |

### 3.2 功法残卷合成

收集10张同类型同品质的残卷，可合成一本完整功法：

```
合成规则：
- 10张凡阶残卷 → 1本凡阶功法
- 10张灵阶残卷 → 1本灵阶功法
- 同类型残卷才可合成（剑诀残卷只能合成剑诀）
- 合成成功率：凡阶100%，每高一级-10%（天阶50%）
```

### 3.3 NPC传授机制

```
好感度≥60 → 可请教基础问题
好感度≥80 → 可能传授凡~灵阶功法
好感度≥90 → 可能传授玄阶功法
好感度=100 → 可能传授地阶功法（仅限一次）
```

## 4. 功法修炼与领悟

### 4.1 修炼条件

| 条件 | 要求 |
|:---|:---|
| **境界要求** | 功法有最低境界要求（如玄阶需金丹期） |
| **灵根契合** | 某些功法需要特定体质（如雷灵体修炼雷法+30%速度） |
| **前置功法** | 高阶功法可能需要先修炼低阶同类型功法至满层 |
| **修炼资源** | 消耗修为点和灵石进行修炼 |

### 4.2 修炼消耗

| 功法品质 | 每层修为消耗 | 每层灵石消耗 | 总层数 |
|:---|:---|:---|:---|
| 凡阶 | 100修为 | 50灵石 | 3层 |
| 灵阶 | 300修为 | 150灵石 | 5层 |
| 玄阶 | 1000修为 | 500灵石 | 7层 |
| 地阶 | 3000修为 | 1500灵石 | 9层 |
| 天阶 | 10000修为 | 5000灵石 | 12层 |
| 仙阶 | 30000修为 | 15000灵石 | 15层 |

### 4.3 领悟加速机制

| 加速方式 | 效果 | 条件 |
|:---|:---|:---|
| **实战领悟** | 战斗中使用该功法技能，战后获得额外领悟值 | 每次战斗+5% |
| **师徒传承** | 师父传授时，弟子领悟速度+50% | 需建立师徒关系 |
| **顿悟** | 随机触发，直接提升1层 | 低概率，境界突破时概率提升 |
| **悟道石** | 消耗道具，直接获得1000领悟值 | 遗迹稀有掉落 |
| **洞天福地** | 在特定地点修炼，速度+100% | 如齐国稷下学宫 |

## 5. 战斗系统重构

### 5.1 战斗基础机制

#### 5.1.1 战斗属性

| 属性 | 说明 | 计算公式 |
|:---|:---|:---|
| **攻击力** | 基础伤害 | 境界基础值 × 灵气倍率 × (1 + 功法加成) |
| **防御力** | 伤害减免 | 境界基础值 × 灵气倍率 × (1 + 体术加成) |
| **生命值** | 生存能力 | 境界基础值 × 灵气倍率 × (1 + 心法加成) |
| **灵力值** | 技能消耗 | 境界基础值 × 灵气倍率 × (1 + 心法加成) |
| **速度** | 行动顺序 | 基础值 + 遁术加成 + 装备加成 |
| **暴击率** | 暴击概率 | 基础5% + 剑诀加成 + 装备加成 |
| **暴击伤害** | 暴击倍率 | 基础150% + 功法加成 |
| **闪避率** | 闪避概率 | 基础5% + 遁术加成 |
| **命中值** | 命中修正 | 基础100% + 功法加成 |

#### 5.1.2 战斗公式

```
实际伤害 = (攻击力 - 防御力 × 0.5) × 技能倍率 × 暴击倍率 × 随机波动(0.9~1.1)

命中率 = 命中值 / (命中值 + 目标闪避值) × 100%

暴击判定：random() < 暴击率 → 触发暴击
```

### 5.2 战斗流程

```
进入战斗
  ↓
计算双方速度 → 确定行动顺序
  ↓
回合制战斗（玩家先手或速度高者先手）
  ├─ 玩家回合：选择技能/普攻/道具/逃跑
  │   ├─ 技能释放：消耗灵力，造成效果
  │   ├─ 普通攻击：不消耗灵力，基础伤害
  │   ├─ 使用道具：丹药/符箓
  │   └─ 逃跑：遁术越高成功率越高
  │
  └─ NPC回合：根据AI选择行动
  ↓
一方HP归零 → 战斗结束
```

### 5.3 技能系统

#### 5.3.1 技能类型

| 技能类型 | 说明 | 示例 |
|:---|:---|:---|
| **主动技能** | 战斗中主动释放 | 太虚一剑、九霄神雷 |
| **被动技能** | 常驻效果 | 剑气护体（受到伤害反弹10%） |
| **连招技能** | 特定顺序释放触发额外效果 | 剑诀三连 → 触发"剑意纵横" |
| **绝技** | 高消耗高伤害，有冷却 | 万剑归宗（冷却3回合） |
| **身法** | 影响移动和闪避 | 缩地成寸（本回合闪避+50%） |

#### 5.3.2 技能释放消耗

| 技能等级 | 灵力消耗 | 冷却回合 |
|:---|:---|:---|
| 普通技能 | 10-30灵力 | 0 |
| 进阶技能 | 50-100灵力 | 1 |
| 绝技 | 200-500灵力 | 3-5 |
| 禁术 | 500+灵力 + 生命值 | 10+ |

### 5.4 战斗策略要素

#### 5.4.1 功法搭配策略

```
典型搭配方案：

【剑修爆发流】
主修：天阶剑诀 + 地阶遁术
辅修：玄阶心法（续航）
战术：先手突进 → 绝技爆发 → 遁术脱离

【法坦控制流】
主修：天阶体术 + 地阶阵诀
辅修：玄阶法术
战术：阵法控场 → 体术抗伤 → 法术收割

【辅助续航流】
主修：天阶心法 + 地阶遁术
辅修：玄阶阵诀
战术：增益队友 → 治疗续航 → 关键时刻控场
```

## 6. 自创功法系统

### 6.1 自创条件

| 条件 | 要求 |
|:---|:---|
| **境界** | 化神期以上 |
| **前置功法** | 至少3本同类型功法修炼至满层 |
| **悟性** | 完成特定悟道任务 |
| **资源** | 消耗100000灵石 + 天道感悟×10 |

### 6.2 自创流程

```
满足条件
  ↓
选择功法类型（剑诀/体术/法术/遁术/心法/阵诀）
  ↓
选择2-3本已修炼满层的功法作为"素材"
  ↓
系统根据素材功法生成"功法雏形"
  ↓
玩家命名并选择特效偏向（伤害/控制/续航/机动）
  ↓
消耗资源 → 自创功法完成
  ↓
自创功法品质 = min(素材品质) + 随机(0~1)阶
```

### 6.3 自创功法特性

| 特性 | 说明 |
|:---|:---|
| **唯一性** | 全服唯一，其他玩家无法获得相同功法 |
| **传承** | 可传授给弟子/心腹，最多传授10人 |
| **进化** | 可通过后续修炼提升至更高品质 |
| **命名权** | 玩家自定义功法名称，载入天道碑 |

### 10.1 同境界战斗时长设计

| 场景 | 目标时长 | 说明 |
|:---|:---|:---|
| **普通NPC** | 3-5回合 | 快速战斗 |

### 10.2 功法强度曲线

```
设计原则：
- 低品质功法前期强，后期乏力（凡阶前3层性价比高）
- 高品质功法前期弱，后期爆炸（天阶5层后质变）
- 同品质不同功法强度差异<20%
- 跨1阶品质差距约30%
```
