# 炼丹与炼器系统设计

## 1. 设计理念：丹成九转，器炼千锤

修仙之路，外炼筋骨皮，内炼一口气。丹药与法器是修仙者最重要的外物辅助——丹药可洗髓伐骨、突破瓶颈、疗伤续命；法器可御敌防身、增幅神通、辅助修炼。本系统构建一个**"材料采集→配方研究→炼制实践→品质提升"**的完整生产循环。

**核心循环**：
```
采集灵草/矿石 → 学习配方 → 炼制丹药/法器 → 提升熟练度 → 解锁高级配方
```

## 2. 炼丹系统

### 2.1 丹药分类

| 丹药类型 | 功能 | 典型丹药 | 适用场景 |
|:---|:---|:---|:---|
| **突破丹** | 提升突破成功率 | 筑基丹、凝婴丹、化神丹 | 境界突破时 |
| **修为丹** | 直接增加修为 | 聚气丹、培元丹、大乘丹 | 日常修炼加速 |
| **疗伤丹** | 恢复生命值 | 回血丹、续命丹、九转还魂丹 | 战斗后恢复 |
| **回灵丹** | 恢复灵力值 | 聚气散、回灵丹、天灵丹 | 战斗中续航 |
| **体质丹** | 改变或强化体质 | 洗髓丹、淬体丹、造化丹 | 体质突破/强化 |
| **状态丹** | 临时增益Buff | 狂暴丹、隐身丹、神行丹 | 战斗/探索辅助 |
| **毒丹** | 对敌负面效果 | 化功散、噬魂丹、七步断肠 | PVP/暗杀 |

### 2.4 炼丹流程

```
准备丹炉 + 丹方 + 材料
  ↓
选择丹火（普通火/地火/天火/异火）
  ↓
按丹方顺序投入材料
  ↓
控制火候（文火/武火/温火）
  ↓
炼丹时长（实时小游戏/等待）
  ↓
成丹判定
  ├─ 失败 → 材料损失，丹炉耐久-1
  ├─ 成功 → 获得丹药（品质随机）
  └─ 炸炉 → 材料全损，可能受伤
```

### 2.5 炼丹成功率公式

```
基础成功率 = 丹方基础成功率（50%-80%）

修正因素：
+ 炼丹熟练度 × 0.1%
+ 丹火品质 × 5%
+ 丹炉品质 × 3%
+ 药王体加成 × 20%
+ 楚国特质加成 × 15%
- 丹药品阶惩罚 × 5%/阶

最终成功率 = min(基础成功率 + 总修正, 95%)
```

### 3.4 炼器流程

```
准备炼器炉 + 器方 + 主材料 + 辅材料
  ↓
选择器火（普通火/地火/天火/异火）
  ↓
熔炼主材料（矿石）
  ↓
加入辅材料（赋予特性）
  ↓
塑形（剑/甲/饰/盘）
  ↓
铭刻符文（附加词条）
  ↓
淬火定型
  ↓
成器判定
  ├─ 失败 → 材料损失，炉子耐久-1
  ├─ 成功 → 获得法器（品质随机）
  └─ 炸炉 → 材料全损，可能受伤
```

### 3.6 法器强化系统

```
强化规则：
- 消耗：同类型矿石 + 灵石
- 成功率：+1~+3 100%，+4~+6 80%，+7~+9 60%，+10~+12 40%，+13~+15 20%
- 失败惩罚：+7以下失败不降级，+7以上失败降1级
- 保护道具："天工符"可防止降级（稀有）
```

|:---|:---|:---|

## 4. 异火系统

### 4.1 异火概述

异火是天地间自然诞生的奇异火焰，用于炼丹炼器可大幅提升成功率和品质。

### 4.3 异火吞噬进化

```
异火可通过吞噬其他火焰进化：
- 吞噬同阶异火 → 经验+50
- 吞噬低阶异火 → 经验+20
- 吞噬高阶异火 → 经验+100（但可能反噬）

进化等级：
初生 → 成长 → 成熟 → 大成 → 圆满 → 化灵
每阶提升加成效果10%
```

## 6. 自创配方系统

### 6.1 自创条件

| 条件 | 要求 |
|:---|:---|
| **熟练度** | 达到"大宗师"级别 |
| **境界** | 化神期以上 |
| **材料学** | 收集50种以上不同材料 |
| **灵感** | 完成特定悟道任务 |

### 6.2 自创流程

```
满足条件
  ↓
选择配方类型（丹方/器方）
  ↓
选择2-4种主材料
  ↓
选择1-3种辅材料
  ↓
系统根据材料属性推演可能效果
  ↓
玩家调整比例和炼制参数
  ↓
首次试炼（消耗材料）
  ↓
根据试炼结果调整
  ↓
配方定型，可批量炼制
```

## 7. 经济循环设计

### 7.1 生产者-消费者关系

```
采集者（灵草/矿石）
    ↓ 出售原材料
炼丹师/炼器师
    ↓ 出售成品
战斗玩家
    ↓ 消耗丹药/法器
    ↓ 出售战利品/材料
采集者
```

### 7.2 生产收益估算

| 生产行为 | 成本 | 产出价值 | 利润率 |
|:---|:---|:---|:---|
| 炼制凡阶丹药 | 50灵石 | 80灵石 | 60% |
| 炼制灵阶丹药 | 200灵石 | 400灵石 | 100% |
| 炼制玄阶丹药 | 1000灵石 | 2500灵石 | 150% |
| 炼制凡器 | 100灵石 | 150灵石 | 50% |
| 炼制法器 | 2000灵石 | 5000灵石 | 150% |

> 注：以上未计算失败损失。实际利润率需乘以成功率。
