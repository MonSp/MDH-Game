# 太古纪元：战国修仙传 - 游戏机制设计文档

## 1. 游戏概述
《太古纪元》是一款基于Web的 2.5D 像素风玄幻修仙多人在线网络游戏（MMORPG）原型。游戏创新性地将“战国七雄”的宏观国家博弈、中层“修仙家族”的竞争与微观的“个人凡体修仙”相结合，辅以高度自治的 NPC 行为树演化系统，构建了一个动态、真实的修仙世界。

## 2. 核心系统：战国七雄与家族生态
### 2.1 分区分服机制
- 每个区服上限 100 人，旨在构建紧密的熟人社会。人数达到上限后将自动开启新区。

### 2.2 国家与特质加成
游戏设定了七大修仙国度，玩家出生时会**随机降生**于其中一国，并获得对应的国家特质增益：
- **秦国（兵甲修仙）**：战力计算+10%，杀人夺宝获取的修为+10%
- **楚国（巫祝修仙）**：炼丹成功率+15%（预留）
- **齐国（学术修仙）**：打坐领悟速度+20%（获取修为增加）
- **燕国（苦修之士）**：打坐灵气吸收效率+10%
- **赵国（游侠修仙）**：移动时有 20% 概率触发“游侠身法”，移动距离翻倍
- **魏国（王道修仙）**：角色初始灵力上限（MaxMp）+10%
- **韩国（奇技修仙）**：制作成本-10%（预留）

### 2.3 家族结构
每个国家固定包含 16 个修仙势力：
- **1个皇族 + 3个一级家族 + 5个二级家族 + 7个三级家族**
- 玩家初始身份为随机家族的**支脉子弟**。

## 3. 玩家成长：潜质觉醒与体质突破
### 3.1 凡体潜质觉醒
玩家出生均为“凡体”，但通过日常的**游戏行为**，会暗中累积隐藏计数器，最终触发相应的【潜质】觉醒：
- **剑心潜质**：累计击杀/攻击 NPC 满 5 次触发。
- **雷灵潜质**：累计打坐修炼满 10 次触发。
- **丹道潜质**：累计采集资源（灵田、矿脉、遗迹）满 5 次触发。
- *觉醒后，UI面板会展示当前潜质，且为后续洗髓突破指明方向。*

### 3.2 灵体突破试炼
- **获取道具**：玩家在探索“遗迹”或“杀人夺宝”时，有概率获得【洗髓丹】。
- **生死试炼**：拥有洗髓丹后，可进行“突破”。系统将**瞬间扣除玩家当前 80% 的最大生命值**：
  - 若当前血量不足 80%，突破失败，玩家重伤（保留 1 滴血）。
  - 若扛过伤害，突破成功。
- **蜕变结果**：
  - 根据已觉醒的潜质必定转化为对应体质（剑心→剑体，雷灵→雷灵体，丹道→药王体等）。
  - 若无潜质，则随机蜕变为【剑体】、【战体】、【雷灵体】或【药王体】。

### 3.3 体质特性
| 体质名称 | 描述 | 属性加成 |
| :--- | :--- | :--- |
| **凡体** | 芸芸众生，资质平平。 | 无特殊加成 |
| **剑体** | 天生剑骨，杀伐果断。 | 战力计算+30% |
| **战体** | 百战不殆，肉身成圣。 | 生命上限（MaxHp）+30% |
| **雷灵体** | 亲和雷电，法术狂暴。 | 雷系伤害+30%，施法速度+15% |
| **药王体** | 草木皆兵，丹心长存。 | 采集灵草双倍，炼丹成功率+20% |

## 4. 动态生态：NPC 行为树自治系统
游戏内拥有 100×7×16 名独立 NPC。他们在后台通过**四层优先级行为树**进行每秒一次的动态演化。

### 4.1 NPC 基础属性
每个 NPC 拥有独立的血量（HP）、灵力（MP）、战力（Power）以及随机生成的**人格参数**（野心、谨慎、忠诚、贪婪）。国家特质会在生成时影响其人格倾向（如秦国更好战）。

### 4.2 行为树逻辑（自上而下评估）
1. **优先级 1（生存应急）**：
   - 触发条件：NPC 生命值 < 30%。
   - 行为：状态切换为“重伤逃遁”，主动远离周围危险源（如玩家），并在安全时缓慢回血。
2. **优先级 2（家族职责）**：
   - 触发条件：根据职位身份。
   - 行为：【家主/长老】高概率执行“闭关突破”（提升战力）或“巡逻边界”；【支脉子弟/仆从】在灵石匮乏时倾向于去“坊市打工”或进行“后勤维护”。
3. **优先级 3（机缘竞争）**：
   - 触发条件：附近（视野内）刷新了无主资源点（灵田、遗迹等）。
   - 行为：“野心/贪婪”值高的 NPC 会被吸引，状态变为“争夺机缘”，主动向资源点移动并将其采空。
4. **优先级 4（日常自主）**：
   - 触发条件：无以上紧急事务。
   - 行为：在原地打坐修炼，或在地图上随机游走。

## 5. 交互系统：仇恨、悬赏与资源争夺
### 5.1 家族好感度与执法堂追杀
- **仇恨机制**：玩家可自由选择与 NPC“交谈”、“交易”或“攻击”。“杀人夺宝”可获取修为与灵石，但会扣除该 NPC 所属家族的**整体好感度**（Reputation）。
- **执法堂出动**：当某家族好感度降至 0 以下（敌对状态），系统会在玩家视野边缘（±10 格）动态生成一名**“执法堂长老”**。
- **无尽追杀**：执法长老战力极高，且处于“追杀中”状态。他会通过行为树寻路，每秒向玩家靠近。一旦双方接触，将自动强制触发高烈度战斗。

### 5.2 地图资源点
2.5D 等距视角地图上会定期随机刷新三种交互资源点，玩家与 NPC 均可采集：
- **灵田（绿色）**：采集获得大量修为经验。
- **矿脉（灰色）**：采集获得基础货币（灵石）。
- **遗迹（紫色）**：采集获得大量灵石，且有 30% 的极高概率掉落突破关键道具【洗髓丹】。

## 6. 修仙境界与飞升
- **境界划分**：凡人 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。
- **修为获取**：玩家通过点击 UI 上的【打坐修炼】、地图采集资源点或杀人夺宝来积攒修为（Exp）。
- **破境机制**：修为满后自动触发天地异象，突破至下一大境界，并获得血量、战力的翻倍提升。达到凡界巅峰后，将面临九天雷劫与飞升上界的终极挑战。
