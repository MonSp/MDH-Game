# 妖兽与心腹化形系统设计

## 1. 设计理念：万物有灵，妖亦可为心腹

修仙世界并非只有人类修士。山川草木、飞禽走兽，在灵气滋养下皆可成妖。本系统将妖兽养成与心腹养成合并为统一体系——玩家收服妖兽后培养至化形期，妖兽可选择化形为特定类型的心腹，成为修仙路上最忠实的伙伴。化形后的妖兽心腹与人类修士心腹各有优劣，为玩家提供策略选择空间。

**核心循环**：
```
遭遇妖兽 → 收服为灵宠 → 培养成长 → 达到化形期 → 选择化形方向 → 成为心腹
```

### 3.2 刷新机制

```
刷新规则：
- 普通妖兽：击杀后5-15分钟刷新
- 精英妖兽：击杀后1-3小时刷新
- 妖王：击杀后24小时刷新
- 妖皇及以上：击杀后72小时刷新

刷新数量：
- 受该区域"妖兽生态指数"影响
- 过度猎杀 → 生态指数下降 → 刷新减少
- 保护繁殖 → 生态指数上升 → 刷新增加
```

## 4. 收服与灵宠阶段

### 4.1 收服条件

| 条件 | 要求 |
|:---|:---|
| **妖兽等级** | 2-6阶（不超过玩家境界+1阶） |
| **妖兽状态** | HP<20%时方可尝试收服 |
| **收服道具** | 需要"灵宠契约"或"御兽环" |
| **灵宠上限** | 玩家最多同时拥有3只灵宠（未化形） |
| **妖王特殊** | 6阶妖王需完成"降服任务"后才可收服 |

### 4.2 收服流程

```
将妖兽HP降至20%以下
  ↓
使用收服道具
  ↓
进行收服判定
  ├─ 成功率 = 基础率(20%) + 道具加成 + 境界差加成 + 妖兽意志削弱
  │
  ├─ 成功 → 妖兽成为灵宠，进入灵宠阶段
  │
  └─ 失败 → 妖兽逃跑或狂暴
```

### 4.4 灵宠成长

#### 4.4.1 升级

- 灵宠参与战斗获得经验
- 使用"灵宠经验丹"直接提升
- 灵宠等级不能超过玩家境界

#### 4.4.2 进化

| 进化条件 | 效果 |
|:---|:---|
| **等级达标** | 达到当前阶段等级上限 |
| **材料满足** | 收集特定进化材料 |
| **亲密度达标** | 亲密度≥80 |

进化后：
- 外观变化
- 属性大幅提升
- 可能解锁新技能
- 化形进度+10%

#### 4.4.3 亲密度系统

| 亲密度 | 等级 | 效果 |
|:---|:---|:---|
| 0-20 | **陌生** | 可能不听从指令 |
| 21-40 | **熟悉** | 正常执行指令 |
| 41-60 | **亲近** | 属性+5% |
| 61-80 | **信赖** | 属性+10%，解锁合体技 |
| 81-100 | **生死相随** | 属性+20%，化形速度+50% |

**提升方式**：
- 共同战斗：每场+1
- 喂食喜好食物：每次+3
- 互动玩耍：每日+5（上限）
- 共同修炼：每次+2

## 5. 化形系统（核心机制）

### 5.1 化形条件

| 条件 | 要求 |
|:---|:---|
| **灵宠等级** | 达到5阶（天妖） |
| **亲密度** | ≥80（信赖以上） |
| **化形材料** | 收集"化形草"×10 + "天劫石"×1 |
| **玩家境界** | 元婴期以上 |
| **化形劫** | 需渡过化形天劫（成功率70%，亲密度每+1提升1%） |

### 5.2 化形流程

```
灵宠达到5阶 + 亲密度≥80
  ↓
收集化形材料
  ↓
选择化形方向（基于妖兽种族倾向）
  ↓
引动化形天劫
  ↓
渡过天劫
  ├─ 成功 → 妖兽化形为心腹
  └─ 失败 → 灵宠等级-1，保留灵宠状态，可再次尝试
  ↓
化形完成，选择心腹类型
```

### 5.3 化形方向选择

化形时，根据妖兽种族和玩家需求，选择心腹类型：

| 心腹类型 | 适合种族 | 核心作用 | 妖兽特性保留 |
|:---|:---|:---|:---|
| **战将（GENERAL）** | 走兽、飞禽、鳞甲 | 随玩家出征，提供战力加成或直接参战 | 本体战斗形态，可短暂恢复妖兽真身 |
| **管家（MANAGER）** | 鳞甲、灵植 | 自动打理家族产业、收取资源 | 感知敏锐，可发现隐藏资源 |
| **谋士（STRATEGIST）** | 飞禽、幻兽、元素 | 提供战略建议、外交斡旋、情报刺探 | 精神感知，可读取他人情绪 |
| **丹师/器师（ARTISAN）** | 灵植、元素、虫豸 | 专职炼丹、炼器 | 对材料有天然亲和力 |
| **死士（ASSASSIN）** | 虫豸、幻兽、走兽 | 执行刺杀、破坏等高危任务 | 可短暂恢复隐匿/毒素能力 |

### 5.4 妖兽心腹 vs 人类心腹

#### 5.4.1 属性对比

| 维度 | 妖兽化形心腹 | 人类修士心腹 |
|:---|:---|:---|
| **基础属性** | 生命值+20%，攻击力+15% | 灵力值+20%，修炼速度+20% |
| **成长速度** | 较慢（需适应人类形态） | 正常 |
| **技能多样性** | 保留妖兽本命神通+学习人类功法 | 可学习全部人类功法 |
| **装备适配** | 部分装备无法使用（如 footwear） | 全部装备可用 |
| **社交能力** | 较低（-30%），易被识破 | 正常 |
| **忠诚度上限** | 100（更纯粹） | 100 |
| **忠诚度成长** | 较快（妖兽本性忠诚） | 正常 |
| **特殊能力** | 可短暂恢复妖兽真身（战斗中） | 无 |
| **跨纪元保留** | 真灵更稳定，记忆保留+10% | 标准保留 |
| **飞升限制** | 需额外消耗"化形稳固丹" | 无 |

#### 5.4.2 真身恢复机制

妖兽化形心腹可在战斗中短暂恢复妖兽真身：

```
真身恢复：
- 触发条件：主动使用，CD 1天
- 持续时间：3回合
- 效果：恢复妖兽本体属性×150%
- 代价：化形不稳，战后需休息6小时
- 限制：连续使用会导致化形倒退（忠诚度-5）
```

#### 5.4.3 社交限制

| 场景 | 限制 | 说明 |
|:---|:---|:---|
| **担任家主** | ❌ 不可 | 人类家族不接受妖兽领导 |
| **担任长老** | ✅ 可以 | 需玩家强力推荐 |
| **外交任务** | ⚠️ 困难 | 好感度获取-30% |
| **坊市交易** | ⚠️ 困难 | 价格不利+20% |
| **与人类NPC交互** | ⚠️ 谨慎 | 有概率被识破，引发敌对 |

## 8. 真灵相随：跨纪元保留（统一）

### 8.1 真灵保留条件

纪元重启时，心腹真灵根据以下因素决定保留：

| 因素 | 人类心腹 | 妖兽化形心腹 |
|:---|:---|:---|
| **忠诚度阈值** | 相同 | 相同 |
| **保留内容** | 标准 | 额外保留妖兽本命神通 |
| **记忆完整度** | 标准 | +10%（妖兽记忆更纯粹） |
| **唤醒后状态** | 人类形态 | 可选择直接化形或从妖兽重新培养 |

### 8.2 妖兽心腹跨纪元特殊规则

```
纪元重启后：

选项1：直接唤醒化形形态
- 消耗：标准轮回引 + 化形稳固丹×1
- 效果：直接以化形心腹状态重生
- 适用：化形稳固度高的妖兽

选项2：唤醒妖兽本体
- 消耗：标准轮回引（无额外消耗）
- 效果：以灵宠状态重生，需重新达到化形条件
- 优势：可重新选择化形方向
- 适用：想改变心腹类型的玩家
```

### 8.3 真灵进化（统一）

| 相随纪元数 | 称号 | 人类心腹加成 | 妖兽心腹额外加成 |
|:---|:---|:---|:---|
| 2个纪元 | 轮回旧部 | 初始忠诚度+10，全属性+5% | 化形稳固+15 |
| 3个纪元 | 百战英魂 | 解锁"英魂技" | 真身恢复CD-50% |
| 5个纪元 | 不灭道兵 | 可抵挡致命伤害 | 真身恢复后保留部分化形加成 |

## 9. 妖兽潮事件

### 9.1 事件触发

| 触发条件 | 说明 |
|:---|:---|
| **周期性** | 每月随机1-2次 |
| **过度猎杀** | 某区域妖兽被大量击杀后报复 |
| **天象异变** | 特殊天象引发妖兽躁动 |
| **高阶妖兽召唤** | 妖王级以上妖兽主动召唤 |

### 9.2 事件流程

```
预警阶段（30分钟前）
  ↓ 全服公告：某区域妖兽异常躁动
  ↓
集结阶段
  ↓ 玩家可前往该区域准备
  ↓
爆发阶段
  ↓ 大量妖兽涌出，攻击一切目标
  ↓
抵御阶段
  ↓ 玩家合作击杀妖兽，保护城镇
  ↓ 拥有妖兽心腹的玩家可尝试"安抚"低阶妖兽
  ↓
平息阶段
  ↓ 妖兽退去，根据贡献发放奖励
```

### 9.3 妖兽心腹在妖兽潮中的特殊作用

| 作用 | 效果 | 限制 |
|:---|:---|:---|
| **安抚** | 有概率使同种族低阶妖兽撤退 | 仅限低于心腹3阶以下的妖兽 |
| **威慑** | 降低周围妖兽攻击力10% | 需展示妖兽真身 |
| **沟通** | 获取妖兽潮的触发原因情报 | 需谋士型妖兽心腹 |
| **引导** | 将妖兽潮引导至无人区域 | 成功率取决于亲密度 |

## 11. 经济与平衡设计

### 11.1 妖兽心腹培养成本

| 阶段 | 消耗资源 | 说明 |
|:---|:---|:---|
| **收服** | 灵宠契约×1（500灵石） | 一次性 |
| **培养至5阶** | 约50000灵石 + 大量材料 | 时间与资源投入 |
| **化形材料** | 化形草×10 + 天劫石×1（约20000灵石） | 一次性 |
| **渡劫辅助** | 渡劫丹×3（约15000灵石） | 提升成功率 |
| **化形稳固** | 化形丹×1/周（500灵石） | 持续消耗 |
| **装备适配** | 特殊装备+30%价格 | 妖兽专属装备更贵 |

### 11.2 人类心腹 vs 妖兽心腹总成本对比

| 维度 | 人类心腹 | 妖兽化形心腹 |
|:---|:---|:---|
| **获取成本** | 低（直接收服NPC） | 高（培养+化形） |
| **培养时间** | 短 | 长（需先养到5阶） |
| **持续消耗** | 低 | 中（化形稳固丹） |
| **战力上限** | 标准 | 更高（真身恢复） |
| **灵活性** | 高（全能） | 中（种族限制） |
| **情感价值** | 高 | 极高（共同成长） |

**设计意图**：妖兽心腹前期投入大、周期长，但后期战力更强、忠诚度更高、情感羁绊更深；人类心腹获取容易、培养灵活，适合快速成型。

## 12. 与现有系统的联动

### 12.1 与炼丹炼器的联动

- 妖兽材料是炼丹炼器的核心资源
- 灵植类妖兽心腹炼丹效率+20%
- 元素类妖兽心腹炼器时可附加元素属性

### 12.2 与秘境的联动

- 秘境中妖兽更强，掉落更好
- 拥有对应种族妖兽心腹可触发秘境隐藏路线
- 妖兽心腹可感知秘境中的妖兽陷阱

### 12.3 与家族的联动

- 家族可建立"御兽园"培养灵宠
- 妖兽心腹可担任家族战将（不可担任家主）
- 家族战中妖兽心腹可发挥真身优势

### 12.4 与心腹系统的联动

- 妖兽化形后完全融入心腹体系
- 共享心腹团容量、真灵空间、跨纪元保留
- 统一指令系统、疲劳机制、进化路线
