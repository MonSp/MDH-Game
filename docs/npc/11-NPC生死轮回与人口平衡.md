# NPC生死轮回与人口平衡

## 1. 设计理念：万物刍狗，天道自衡

修仙世界的残酷在于：修士如过江之鲫，能跃龙门者寥寥。NPC的批量死亡与新生，不仅是世界真实的体现，更是资源循环的**核心引擎**——每一个NPC都是一座移动的"资源矿"，他们的诞生消耗世界资源，他们的死亡返还世界资源。

---

## 2. 天道轮回池

世界维持一个**天道轮回池**，记录所有死亡NPC的"灵魂"数据。新NPC的诞生，本质是灵魂的重新投胎。

### 2.2 诞生触发条件（按优先级）

系统每隔**1小时（游戏内时间）**检查一次人口平衡，决定是否触发诞生：

| 触发条件 | 诞生数量 | 设计意图 |
|:---|:---|:---|
| 区服总NPC数 < 目标值的90% | 批量诞生5-10人 | 防止人口枯竭 |
| 某国家NPC数 < 该国目标值80% | 该国定向诞生3-5人 | 维持七国平衡 |
| 某家族NPC数 < 该家族下限值 | 该家族诞生1-2人 | 防止家族灭绝 |
| 连续3天无诞生 | 强制诞生1人 | 保底机制 |

**目标人口公式**：
```
国家目标NPC数 = 基础值11200（7国×16家族×100人）
               + 玩家飞升带来的额外名额（每飞升1人+5个NPC容量）
               - 长期战争损耗修正（-5% ~ -15%）
```

### 2.3 诞生时的资源注入

新NPC诞生时，系统会从其所属的**家族库房**或**天道回收池**中抽取资源，为其配备初始装备：
- 凡体：无初始资源，需从零积累
- 散修投靠：自带法器×1、丹药×2、灵石×50
- 妖兽化形：自带妖兽材料×3，但法器/丹药为空

## 3. NPC死亡系统：资源的释放

### 3.1 死亡原因与触发条件

详见 [07-NPC行为与生命周期.md](../npc/07-NPC行为与生命周期.md) 中的生命周期状态机。

| 死亡类型 | 触发条件 | 发生频率基准 | 是否可被玩家影响 |
|:---|:---|:---|:---|
| **国战阵亡** | 两国交战期间，参战NPC生命值归零 | 战争期间高频 | ✅ 玩家可参战、指挥 |
| **家族血斗** | 家族宣战后，双方NPC互相攻伐 | 家族战时高频 | ✅ 玩家可挑拨、参与 |
| **妖兽猎杀** | NPC外出历练/采集时遭遇妖兽 | 野外区域中频 | ✅ 玩家可引怪陷害 |
| **资源争夺** | 多个NPC争抢遗迹/灵矿时爆发冲突 | 资源刷新后中频 | ✅ 玩家可坐收渔利 |
| **执法追杀** | 家族好感度归零后，长老追杀玩家/敌对NPC | 触发后持续 | ✅ 玩家直接触发 |
| **渡劫失败** | NPC突破大境界时天劫致死 | 突破时概率触发 | ❌ 天道规则 |
| **寿元耗尽** | 修为境界对应的寿命上限到达 | 固定周期低频 | ❌ 天道规则 |
| **修炼走火** | 修炼时心魔反噬 | 打坐时极低概率 | ❌ 随机事件 |

### 3.2 死亡掉落与资源回收

NPC死亡时，其携带的资源不会凭空消失，而是按规则**重新分配**：

| 资源类型 | 掉落规则 | 回收/流通去向 |
|:---|:---|:---|
| **灵石** | 掉落携带量的40%-60% | 击杀者获得（玩家或NPC） |
| **丹药/材料** | 随机掉落1-3件，受背包容量影响 | 击杀者获得 |
| **法器** | 有30%概率损坏，否则可被掠夺 | 击杀者获得或毁坏消失 |
| **修为精华** | 不直接掉落 | 转化为"杀戮值"给击杀者（秦国有加成） |
| **家族贡献** | 清空 | 返还50%到家族库房（算作抚恤） |
| **储物袋内物品** | 全部掉落，但有10%概率被"空间乱流"摧毁 | 大部分进入流通 |

**关键设计：天道回收率**
- 每次NPC死亡，约**15%-20%**的资源会因"法器损坏""空间乱流"等原因**永久消失**。
- 这是游戏经济的**核心通货紧缩机制**，防止资源无限膨胀。

### 3.3 死亡的社会影响

NPC死亡不仅仅是资源事件，更会引发连锁反应：

| 影响维度 | 具体效果 |
|:---|:---|
| **家族实力** | 家族总战力下降，可能触发其他家族的觊觎 |
| **职位空缺** | 长老/家主死亡后，由家族内最高修为者继承 |
| **仇恨累积** | 击杀者及其所属势力被记入"家族世仇簿"，永久降低好感 |
| **悬赏触发** | 若死者身份重要（嫡系以上），家族自动发布对凶手的悬赏 |
| **资源点再分配** | 若死者是某矿脉/灵田的"占有者"，该资源点重新变为无主状态 |

## 4. 人口动态平衡的数学调控

### 4.1 稳态人口模型

设：
- **B** = 每小时诞生数
- **D** = 每小时死亡数
- **N** = 当前总人口
- **N_target** = 目标人口

系统通过PID控制器动态调整**诞生率**：

```
B(t) = B_base + Kp × (N_target - N) + Ki × ∫(N_target - N)dt
```

**各层世界的基准参数**：

| 层级 | N_target | B_base | D_base（和平） | D_peak（战争） |
|:---|:---|:---|:---|:---|
| 第9层 | 11200 | 8/小时 | 6/小时 | 25/小时 |
| 第8层 | 16800 | 12/小时 | 9/小时 | 35/小时 |
| 第7层 | 22400 | 16/小时 | 12/小时 | 45/小时 |
| 第6层 | 28000 | 20/小时 | 15/小时 | 55/小时 |
| 第5-3层 | 33600+ | 25+/小时 | 18+/小时 | 60+/小时 |

### 4.2 战争对人口的影响曲线

```
战争强度与NPC净损失关系：

战争持续天数    日净损失(死亡-诞生)    累计人口下降
─────────────────────────────────────────────
第1天           +50                      -50
第3天           +120                     -290
第7天           +80（损耗减缓）           -610
第14天          +40（厌战情绪）           -930
第30天          +20（僵持阶段）           -1150
```

**战争厌战机制**：
- 战争持续超过7天，参战国家的NPC"谨慎"值集体上升
- 家主会更倾向于求和/停战
- 若玩家强行继续战争，家族好感度会下降

### 4.3 妖兽生态的自我调节

野外妖兽数量与NPC死亡数形成**捕食者-猎物模型**：

```
妖兽数量 ↑ → NPC死亡 ↑ → 资源采集减少 → 妖兽食物减少 → 妖兽数量 ↓
                                                                │
                                                                ▼
NPC死亡 ↓ ← 资源采集恢复 ← 妖兽数量恢复 ← 妖兽食物恢复 ←────────┘
```

### 5.2 玩家在循环中的策略切入点

玩家的核心策略是：**识别并利用NPC生死循环中的"价值洼地"**。

| 策略类型 | 具体操作 | 收益逻辑 |
|:---|:---|:---|
| **趁火打劫** | 在两国交战时，游走战场边缘，补刀残血NPC | 低风险获得死亡掉落 |
| **鹬蚌相争** | 引妖兽攻击正在采集的NPC，待双方残血后收割 | 一鱼两吃，获取妖兽材料+NPC掉落 |
| **奇货可居** | 在战争期囤积丹药/法器，待战后NPC大量诞生时高价出售 | 赚取供需差价 |
| **扶持傀儡** | 刻意保护某弱小家族，助其诞生/成长，形成自己的资源供应地 | 长期稳定收益 |
| **斩首行动** | 刺杀敌对家族的长老/家主，引发其内部权力斗争和内耗 | 削弱对手，坐收渔利 |
| **人口贩运** | 诱使散修NPC叛逃至本方家族（需高魅力/特殊道具） | 增强己方，削弱敌方 |

## 8. 数值设计参考：一个NPC的一生

以第9层秦国某三级家族的支脉子弟"秦十七"为例，模拟其完整生命周期：

| 阶段 | 年龄 | 行为 | 资源消耗 | 资源产出 | 死亡概率 |
|:---|:---|:---|:---|:---|:---|
| 诞生 | 16岁 | 凡体，无修为 | 家族养育费100灵石 | 0 | 0% |
| 修炼期 | 17-25岁 | 打坐、领任务 | 月俸10灵石 | 偶尔采集上交 | 2%/年 |
| 历练期 | 26-40岁 | 外出采集、猎妖 | 丹药消耗、法器磨损 | 稳定上交资源 | 5%/年 |
| 壮年期 | 41-60岁 | 突破筑基、参与家族事务 | 突破消耗300灵石 | 产出峰值 | 8%/年 |
| 中年期 | 61-80岁 | 若未突破，转为后勤 | 消耗降低 | 产出下降 | 3%/年 |
| 老年期 | 81-100岁 | 寿元将尽 | 几乎不消耗 | 几乎无产出 | 逐年递增 |
| 死亡 | 100岁 | 寿元耗尽（若无突破） | — | 遗产返还家族 | 100% |

**生涯总账**（假设平均寿命65岁，未突破筑基）：
- **总消耗**：家族养育费100 + 49年俸禄≈500 + 丹药/法器≈400 = 约1000灵石
- **总产出**：49年采集/任务≈1500灵石 + 1次机缘≈300 = 约1800灵石
- **净贡献**：约800灵石（返还家族的资源）
- **死亡时掉落**：被击杀者掠夺约200-300灵石，损毁约50-100灵石

> **设计意义**：一个普通NPC的一生，为世界净贡献约800灵石的价值，而死亡时约15%-20%的资源永久消失。正是这千万个NPC的"碌碌一生"与"突然死亡"，维持着整个修仙世界的经济运转。

## 9. 总结：天道以万物为刍狗

这套NPC生死轮回系统的核心哲学是：**NPC不是玩家的背景板，而是世界经济的血液细胞**。

1. **出生即消耗**：每个新NPC的诞生，都需要家族/世界投入资源，形成资源需求端。
2. **一生即生产**：NPC通过采集、生产、战斗，将世界的基础资源转化为可用资源。
3. **死亡即释放**：NPC死亡时，其积累的资源被重新分配，一部分流向击杀者，一部分永久消失。
4. **轮回即平衡**：天道轮回池确保人口不会枯竭，资源不会无限膨胀，形成自洽的生态。

玩家在这个系统中，既是**掠食者**（直接收割NPC），也是**牧羊人**（经营家族、培育NPC），更是**棋手**（通过战争、外交、经济手段，影响整个NPC生态的走向）。

最终，玩家会深刻理解一个道理：**在太古纪元的世界里，每一个不起眼的NPC，都是你修仙路上的一块踏脚石——只是有些是垫脚的，有些是绊脚的，还有些，是能把你砸死的。**

### 10.1 普通NPC与心腹NPC的轮回差异

| 项目 | 普通NPC | 心腹NPC |
|:---|:---|:---|
| **死亡后归属** | 回归天道轮回池 | 暂存于玩家"真灵空间" |
| **灵魂保留** | 完全丢失前世记忆 | 根据忠诚度保留记忆与技能 |
| **复活方式** | 随机转生（不可控） | 消耗"轮回引"主动唤醒（可控） |
| **复活消耗** | 无 | 纪元精华×200 + 灵石×5000（递增） |
| **身份恢复** | 完全随机，无法定向 | 可唤醒至玩家家族 |

### 10.2 真灵空间

玩家拥有一个隐藏的"真灵空间"，用于存储已死亡心腹的真灵：

```
真灵空间状态：
┌────────────────────────────────────────────────┐
│ 心腹真灵：2/10                                  │
│                                                │
│ ├─ 叶霜（轮回旧部）                            │
│ │   ├─ 忠诚度：95                              │
│ │   ├─ 相随纪元：2                             │
│ │   ├─ 记忆完整度：95%                         │
│ │   └─ 状态：可唤醒                            │
│ │                                              │
│ └─ 赵云（百战英魂）                             │
│     ├─ 忠诚度：88                              │
│     ├─ 相随纪元：3                             │
│     ├─ 记忆完整度：80%                         │
│     └─ 状态：冷却中（还剩3纪元）                │
└────────────────────────────────────────────────┘
```

### 10.3 跨纪元保留条件

纪元重启时，心腹NPC的真灵根据**忠诚度**决定保留程度：

| 忠诚度阈值 | 保留内容 | 下一纪元初始状态 |
|:---|:---|:---|
| **≥90（生死相随）** | 全部记忆、技能等级、修为感悟 | 重生后快速恢复至原境界80% |
| **70-89（忠心耿耿）** | 大部分记忆、核心技能、部分修为 | 重生后恢复至原境界60% |
| **50-69（恪尽职守）** | 基本记忆、技能框架 | 重生后恢复至原境界40% |
| **<50（貌合神离）** | 仅保留姓名与模糊记忆 | 重生后为凡人，需重新培养 |

### 10.4 真灵唤醒流程

```
纪元重启
    │
    ▼
玩家进入新纪元
    │
    ├──► 选择"唤醒真灵" ──► 消耗轮回引+灵石
    │                          │
    │                          ▼
    │                     心腹降生于玩家家族
    │                     （拥有"宿慧"Buff）
    │
    └──► 不唤醒 ──► 心腹以普通NPC身份随机降生
                      （玩家需重新寻找并收服）
```

| 第2名 | 1.5× | 300 | 7,500 |
| 第3名 | 2× | 400 | 10,000 |
| 第4名 | 2.5× | 500 | 12,500 |
| ... | ... | ... | ... |

### 10.6 心腹进化与轮回

随着相随纪元数增加，心腹真灵可发生质变：

| 相随纪元数 | 称号 | 额外效果 |
|:---|:---|:---|
| 2个纪元 | 轮回旧部 | 初始忠诚度+10，全属性+5% |
| 3个纪元 | 百战英魂 | 解锁"英魂技"，战斗概率免死 |
| 5个纪元 | 不灭道兵 | 可为玩家抵挡致命伤害 |
| 7个纪元以上 | 混元道侣 | 可与玩家一同飞升，参与道果争夺 |

## 11. LLM决策入口：轮回与人口调控

### 11.1 LLM适用场景

在生死轮回与人口平衡层面，LLM可用于智能调控世界人口生态：

| 场景 | LLM决策对象 | 触发方式 | 影响范围 |
|:---|:---|:---|:---|
| **诞生策略优化** | 系统级（T0级模拟） | 定时/事件驱动 | 新NPC属性、人格、分配 |
| **死亡事件叙事** | 系统级（T0级模拟） | 死亡事件 | 遗言、遗愿、复仇触发 |
| **战争损耗评估** | T1级NPC（统帅） | 战争期间 | 兵力分配、战略调整 |
| **家族兴衰预测** | T1级NPC（家主） | 定时 | 家族发展建议 |

### 11.4 与LLM规划系统的衔接

轮回调控LLM决策与[NPC的AI决策系统](../npc/12-NPC的AI决策.md)的衔接方式：
- 诞生决策 → 影响新NPC的初始人格参数，为后续LLM规划埋下伏笔
- 死亡叙事 → 生成NPC遗言/遗愿，可能触发玩家任务或家族仇恨
- 战争损耗评估 → 辅助T1级NPC制定更合理的军事计划
- 家族兴衰预测 → 为家主级NPC提供LLM规划的参考信息
