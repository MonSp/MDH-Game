# NPC心腹养成与真灵相随系统设计

## 1. 设计理念：仙路漫漫，谁与共行

在《大周修仙志》的宏大世界中，玩家并非孤独的求道者。随着修为提升，玩家需要建立自己的势力，而心腹系统正是这一需求的核心载体。心腹是玩家最信任的追随者，他们随玩家征战四方、管理产业、出谋划策，是玩家在修仙世界中的左膀右臂。

**核心循环**：
```
收服/招募心腹 → 培养忠诚度 → 派遣执行任务 → 共同成长 → 跨纪元保留
```

**重要说明**：本系统与 [17-妖兽与心腹化形系统](17-妖兽与灵宠系统.md) 已合并为统一的心腹体系。玩家可通过两种途径获得心腹：
1. **直接收服人类NPC**（本系统所述）—— 快速成型，灵活全能
2. **培养妖兽化形**（见17号文档）—— 前期投入大，后期战力更强

两种心腹共享统一的心腹团容量、指令系统、跨纪元保留机制。

## 2. 心腹获取途径

### 2.1 人类心腹获取方式

| 获取途径 | 说明 | 成功率/条件 | 典型场景 |
|:---|:---|:---|:---|
| **战斗收服** | 击败NPC后选择"收服" | 忠诚度初始30-50 | 击败敌对家族修士 |
| **任务招募** | 完成NPC的专属任务链 | 忠诚度初始60-80 | 帮助散修解决困境 |
| **交易购买** | 在奴隶市场购买（道德争议） | 忠诚度初始10-20 | 燕国边境市场 |
| **家族指派** | 家族分配的低级修士 | 忠诚度初始40-60 | 家族内部调动 |
| **慕名投奔** | 高声望玩家自动吸引 | 忠诚度初始70-90 | 名震一方后 |
| **救命之恩** | 救助濒死NPC | 忠诚度初始80-100 | 战场救援 |

### 2.2 收服判定公式

```
收服成功率 = 基础成功率(40%) 
            + 玩家境界压制 × 10%
            + 玩家声望加成 × 5%
            + NPC当前状态修正（濒死+20%，满血-10%）
            + 特殊道具加成（如"御心丹"+15%）
```

## 3. 心腹属性与类型

### 3.1 心腹核心属性

| 属性 | 说明 | 影响 |
|:---|:---|:---|
| **忠诚度** | 0-100，心腹对玩家的忠诚程度 | 影响任务成功率、是否叛逃 |
| **修为境界** | 心腹的修仙境界 | 影响战斗力、可执行任务类型 |
| **战斗力** | 综合战斗能力 | 影响战斗类任务成功率 |
| **特长** | 心腹的专精方向 | 影响特定任务效率 |
| **疲劳度** | 0-100，心腹的疲劳状态 | 影响任务成功率，需休息恢复 |
| **潜力** | 心腹的成长上限 | 决定心腹最终能达到的高度 |

### 3.2 心腹类型（人类心腹）

| 类型 | 核心作用 | 适合任务 | 获取倾向 |
|:---|:---|:---|:---|
| **战将（GENERAL）** | 随玩家出征，提供战力加成或直接参战 | 征战、护送、剿匪 | 战斗收服 |
| **管家（MANAGER）** | 自动打理家族产业、收取资源 | 资源管理、产业经营 | 家族指派 |
| **谋士（STRATEGIST）** | 提供战略建议、外交斡旋、情报刺探 | 外交、情报、谈判 | 慕名投奔 |
| **丹师/器师（ARTISAN）** | 专职炼丹、炼器 | 生产、研发 | 任务招募 |
| **死士（ASSASSIN）** | 执行刺杀、破坏等高危任务 | 暗杀、破坏、潜入 | 特殊渠道 |

> 注：妖兽化形心腹的类型选择受其种族限制，详见 [17-妖兽与心腹化形系统](17-妖兽与灵宠系统.md)。

## 4. 忠诚度系统

### 4.1 忠诚度等级

| 忠诚度 | 等级 | 行为特征 | 叛逃风险 |
|:---|:---|:---|:---|
| 0-20 | **仇视** | 拒绝执行指令，可能主动攻击玩家 | 极高（已叛逃或即将叛逃） |
| 21-40 | **不满** | 消极执行，任务成功率-30% | 高 |
| 41-60 | **中立** | 正常执行，无加成 | 中 |
| 61-80 | **忠诚** | 积极执行，任务成功率+10% | 低 |
| 81-95 | **死忠** | 全力以赴，任务成功率+25% | 极低 |
| 96-100 | **殉道者** | 愿为玩家牺牲生命，解锁特殊能力 | 无 |

### 4.2 忠诚度变化因素

#### 提升方式

| 行为 | 忠诚度变化 | 说明 |
|:---|:---|:---|
| **赏赐资源** | +5至+20 | 给予灵石、丹药、功法等 |
| **共同战斗** | +2/场 | 与玩家并肩作战 |
| **授予功法** | +10至+30 | 传授高级功法 |
| **晋升职位** | +15 | 提升在家族中的地位 |
| **拯救生命** | +20至+50 | 在危急时刻救助心腹 |
| **实现愿望** | +10至+40 | 完成心腹的个人请求 |

#### 降低方式

| 行为 | 忠诚度变化 | 说明 |
|:---|:---|:---|
| **任务失败惩罚** | -5至-15 | 因玩家决策导致任务失败 |
| **资源克扣** | -10 | 承诺的赏赐未兑现 |
| **见死不救** | -20至-40 | 心腹遇险时玩家未救援 |
| **道德冲突** | -10至-30 | 被迫执行与价值观冲突的任务 |
| **长期冷落** | -2/天 | 超过7天未互动 |
| **虐待行为** | -30至-100 | 恶意伤害或羞辱 |

### 4.3 叛逃机制

```
叛逃判定：
- 忠诚度<20时，每日判定一次
- 叛逃概率 = (20 - 当前忠诚度) × 2%
- 叛逃后：
  - 心腹成为敌对NPC
  - 可能泄露玩家情报
  - 可能加入敌对势力
  - 玩家声望受损
```

## 5. 心腹培养系统

### 5.1 修为提升

| 培养方式 | 效果 | 消耗 | 限制 |
|:---|:---|:---|:---|
| **赐予丹药** | 直接提升修为 | 丹药 | 心腹境界不能超过玩家 |
| **共同修炼** | 缓慢提升，忠诚度+1/次 | 时间 | 需在同一地点 |
| **传授功法** | 解锁新技能 | 功法残卷 | 需忠诚度>60 |
| **实战历练** | 战斗后获得经验 | 风险 | 可能受伤或死亡 |

### 5.2 特长培养

| 特长类型 | 培养方式 | 效果 |
|:---|:---|:---|
| **战斗专精** | 频繁派遣战斗任务 | 战斗力成长+50% |
| **管理专精** | 管理产业 | 资源产出效率提升 |
| **外交专精** | 执行外交任务 | 谈判成功率提升 |
| **隐匿专精** | 执行潜入任务 | 被发现概率降低 |

### 5.3 人类心腹 vs 妖兽化形心腹培养差异

| 养成维度 | 人类心腹 | 妖兽化形心腹 | 差异说明 |
|:---|:---|:---|:---|
| **修为境界** | 赐予丹药、共同修炼 | 赐予丹药+妖兽内丹、共同修炼 | 妖兽需额外消耗内丹 |
| **专属技能** | 传授功法残卷 | 保留本命神通+传授功法 | 妖兽有独特神通 |
| **装备法器** | 全部装备 | 部分装备受限 | 妖兽某些部位无法装备 |
| **忠诚度** | 赏赐、谈心、并肩作战 | 喂食、共同战斗、保护 | 妖兽对"喂食"更敏感 |
| **特长专精** | 指派特定任务 | 指派特定任务 | 妖兽在对应种族领域有加成 |
| **化形稳固** | 无 | 消耗"化形丹"维持 | 妖兽独有维度 |

## 6. 心腹任务系统

### 6.1 任务类型

| 任务类型 | 说明 | 成功率影响因素 | 典型奖励 |
|:---|:---|:---|:---|
| **资源采集** | 采集灵草、矿石 | 修为、特长 | 原材料 |
| **护送任务** | 保护NPC或物资 | 战斗力、忠诚度 | 灵石、声望 |
| **征战任务** | 参与战斗 | 战斗力、修为 | 军功、战利品 |
| **外交任务** | 出使其他势力 | 特长、忠诚度 | 外交关系、情报 |
| **潜入任务** | 刺探情报、破坏 | 特长、修为 | 情报、特殊物品 |
| **修炼任务** | 闭关修炼 | 潜力、环境 | 修为提升 |

### 6.2 任务成功率公式

```
任务成功率 = 基础成功率(60%)
            + 心腹修为适配度 × 15%
            + 忠诚度加成（忠诚+10%，死忠+25%）
            + 特长匹配度 × 20%
            + 装备加成 × 10%
            - 疲劳度惩罚 × 0.3%
            - 任务难度系数 × 10%
```

### 6.3 任务结果

| 结果 | 概率 | 影响 |
|:---|:---|:---|
| **大成功** | 5% | 超额完成任务，获得额外奖励 |
| **成功** | 根据成功率 | 正常完成任务 |
| **勉强完成** | 10% | 任务完成但心腹受伤 |
| **失败** | 根据失败率 | 任务失败，心腹可能受伤或死亡 |
| **大失败** | 5% | 任务失败，心腹死亡或叛逃 |

## 7. 心腹交互系统

### 7.1 日常交互

| 交互方式 | 效果 | 冷却 |
|:---|:---|:---|
| **谈心** | 忠诚度+2，了解心腹状态 | 1天 |
| **赏赐** | 忠诚度+5至+20 | 无 |
| **共同修炼** | 忠诚度+1，双方修为微增 | 1天 |
| **指派任务** | 见任务系统 | 根据任务 |
| **授予功法** | 忠诚度+10，提升能力 | 无限制 |
| **晋升职位** | 忠诚度+15，解锁新权限 | 需满足条件 |

### 7.2 特殊事件

| 事件类型 | 触发条件 | 玩家选择 | 影响 |
|:---|:---|:---|:---|
| **心腹请求** | 随机触发 | 帮助/拒绝 | 忠诚度±20 |
| **心腹突破** | 心腹修为达到瓶颈 | 协助/旁观 | 心腹境界提升 |
| **心腹遇险** | 任务中触发 | 救援/放弃 | 忠诚度±40 |
| **心腹背叛** | 忠诚度极低 | 处决/宽恕 | 声望、忠诚度变化 |
| **心腹牺牲** | 战斗中为保护玩家 | 纪念/复活尝试 | 情感、因果 |

## 8. 心腹团容量（统一）

### 8.1 容量规则

| 项目 | 规则 |
|:---|:---|
| **初始容量** | 3名（含人类心腹+妖兽化形心腹） |
| **扩容方式** | 每突破一个大境界+1名额；使用"神魂玉"道具+1名额 |
| **最大容量** | 10名 |
| **妖兽上限** | 最多6名为妖兽化形（保留人类心腹空间） |

### 8.2 容量管理策略

```
玩家需权衡：
- 人类心腹：获取快、培养灵活、社交无障碍
- 妖兽心腹：战力更强、忠诚度更高、有独特神通

建议搭配：
- 前期：2人类 + 1妖兽（快速成型）
- 中期：2人类 + 3妖兽（战力为主）
- 后期：根据需求灵活调整
```

## 9. 真灵相随：跨纪元保留机制

### 9.1 真灵保留条件

纪元重启时，心腹的真灵能否保留取决于：

| 因素 | 权重 | 说明 |
|:---|:---|:---|
| **忠诚度** | 40% | 忠诚度越高，保留概率越大 |
| **相随时间** | 20% | 跟随玩家时间越长，羁绊越深 |
| **共同经历** | 20% | 共同完成的重大事件数量 |
| **玩家修为** | 10% | 玩家境界越高，保留能力越强 |
| **特殊道具** | 10% | 使用"轮回引"等道具可提升保留率 |

### 9.2 保留概率公式

```
保留概率 = 忠诚度 × 0.4%
         + min(相随天数/100, 20)%
         + min(共同经历事件数 × 2, 20)%
         + 玩家境界系数 × 10%
         + 道具加成

最低保留概率：5%（忠诚度>80时）
最高保留概率：95%
```

### 9.4 真灵唤醒

新纪元开始后，玩家可以消耗资源唤醒真灵空间中的心腹：

| 唤醒方式 | 消耗 | 效果 |
|:---|:---|:---|
| **普通唤醒** | 1000灵石 | 心腹以初始状态重生，保留50%记忆 |
| **完美唤醒** | 5000灵石 + "轮回引"×1 | 心腹以巅峰状态重生，保留80%记忆 |
| **天道唤醒** | 10000灵石 + "天道石"×1 | 心腹以强化状态重生，保留全部记忆 |

### 9.5 真灵进化

心腹跟随玩家跨越的纪元越多，真灵越强大：

| 相随纪元数 | 称号 | 加成效果 |
|:---|:---|:---|
| 2个纪元 | **轮回旧部** | 初始忠诚度+10，全属性+5%，化形稳固+15（妖兽） |
| 3个纪元 | **百战英魂** | 解锁专属"英魂技"，真身恢复CD-50%（妖兽） |
| 5个纪元 | **不灭道兵** | 可替玩家抵挡一次致命伤害，真身恢复保留化形加成（妖兽） |
| 7个纪元 | **混元道侣** | 与玩家心意相通，可一同飞升，妖兽本体独立修炼双形态（妖兽） |

## 10. 心腹死亡与纪念

### 10.1 死亡机制

心腹在以下情况可能死亡：
- 任务大失败
- 战斗中为保护玩家
- 被敌对势力暗杀
- 寿元耗尽（NPC有寿命限制）

### 10.2 死亡处理

| 处理方式 | 效果 | 代价 |
|:---|:---|:---|
| **安葬** | 获得功德值，可能触发纪念任务 | 无 |
| **招魂** | 尝试保留真灵（成功率50%） | 大量灵石 |
| **复活** | 使用"九转还魂丹"复活 | 传说级丹药 |
| **纪念** | 建立祠堂，获得永久Buff | 资源 |
