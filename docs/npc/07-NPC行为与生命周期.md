# AI Agent系统与三层级AI架构

## 1. 系统概述

《太古纪元：霸业》采用**三层级AI架构**，分别负责战略、战术和角色层面的决策。每个AI Agent都是独立的智能体，拥有记忆、情感和决策能力，能够自主制定计划并执行。

### 1.1 核心设计理念

- **分层决策**：战略、战术、角色三个层级各司其职
- **自主智能**：每个AI Agent都是独立的智能体
- **记忆系统**：AI会记住历史事件并据此决策
- **情感系统**：AI有情感状态，影响决策风格
- **涌现叙事**：没有预设剧本，故事由AI互动自然产生

## 2. 三层级AI架构

│  - 国家决策、外交关系、世界格局           │
│  - 调用频率：游戏月/次                    │
│  - 模型：gemini-3.1-pro（强推理）         │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│           战术AI层（Tactical AI）         │
│  - 战场指挥、军团调度、功法搭配           │
│  - 调用频率：游戏周/次                    │
│  - 模型：gemini-2.5-flash（平衡）         │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐

## 3. AI记忆系统

### 3.1 记忆类型

| 记忆类型 | 说明 | 容量 | 衰减速度 |
|:---|:---|:---|:---|
| **短期记忆** | 近期事件 | 10条 | 快（1天） |
| **中期记忆** | 重要事件 | 50条 | 中（1周） |
| **长期记忆** | 重大事件 | 100条 | 慢（1月） |
| **情感记忆** | 情感体验 | 20条 | 极慢（1年） |
| **知识记忆** | 学习和经验 | 无限制 | 不衰减 |

### 3.2 记忆数据结构

```json
{
  "memory": {
    "memory_id": "MEM_001",
    "type": "长期记忆",
    "event": "十年前与楚国大战",
    "impact": "失去南部三城",
    "emotion": "愤怒",
    "importance": 0.9,
    "timestamp": "太古纪元110年",
    "participants": ["秦国", "楚国"],
    "consequences": ["国力下降", "边境紧张"]
  }
}
```

### 3.3 记忆影响决策

AI会根据记忆调整决策：

| 记忆类型 | 决策影响 |
|:---|:---|
| **胜利记忆** | 增加自信，提高冒险倾向 |
| **失败记忆** | 增加谨慎，降低冒险倾向 |
| **背叛记忆** | 降低信任，提高警惕 |
| **恩情记忆** | 增加忠诚，提高回报倾向 |
| **仇恨记忆** | 增加攻击性，提高报复倾向 |

## 4. AI情感系统

### 4.1 情感状态

| 情感 | 说明 | 对决策的影响 |
|:---|:---|:---|
| **自信** | 对自身能力的信心 | 提高冒险倾向 |
| **恐惧** | 对威胁的恐惧 | 提高防御倾向 |
| **愤怒** | 对不公的愤怒 | 提高攻击倾向 |
| **希望** | 对未来的希望 | 提高扩张倾向 |
| **悲伤** | 对损失的悲伤 | 降低行动倾向 |
| **喜悦** | 对成功的喜悦 | 提高社交倾向 |

### 4.2 情感变化

```json
{
  "emotional_state": {
    "confidence": 0.80,
    "fear": 0.20,
    "anger": 0.30,
    "hope": 0.70,
    "sadness": 0.10,
    "joy": 0.60
  }
}
```

### 4.3 情感与决策

| 情感状态 | 决策倾向 |
|:---|:---|
| **高自信+低恐惧** | 主动进攻、扩张 |
| **低自信+高恐惧** | 防御、求和 |
| **高愤怒+低恐惧** | 报复、攻击 |
| **高希望+高自信** | 大胆计划、创新 |
| **高悲伤+低希望** | 保守、退缩 |

## 6. AI生命周期

### 6.1 生命周期阶段

| 阶段 | 说明 | 持续时间 |
|:---|:---|:---|
| **诞生** | AI创建，初始人格形成 | 即时 |
| **成长** | 积累经验，人格演化 | 游戏时间1-10年 |
| **成熟** | 人格稳定，经验丰富 | 游戏时间10-50年 |
| **衰老** | 能力衰退，记忆模糊 | 游戏时间50-100年 |
| **死亡** | AI消亡，记忆传承 | 即时 |

## 8. AI性能优化

### 8.1 调用优化

| 优化策略 | 说明 | 效果 |
|:---|:---|:---|
| **缓存复用** | 缓存相同情境的决策 | 减少50%调用 |
| **批量处理** | 批量处理多个AI请求 | 减少30%调用 |
| **降级机制** | 模型不可用时降级 | 保证可用性 |
| **异步处理** | 异步生成决策 | 减少延迟 |

### 8.2 成本控制

| 控制策略 | 说明 | 效果 |
|:---|:---|:---|
| **分层模型** | 不同层级使用不同模型 | 降低70%成本 |
| **频率控制** | 控制调用频率 | 降低50%成本 |
| **结果缓存** | 缓存决策结果 | 降低30%成本 |
| **批量折扣** | 批量调用获得折扣 | 降低20%成本 |

---

通过以上设计，AI Agent系统成为游戏的核心驱动力。每个AI都是独立的智能体，拥有记忆、情感和决策能力，能够自主制定计划并执行。三层级架构确保不同层面的决策都能得到妥善处理，为玩家提供丰富多样的游戏体验。
