# NPC行为与生命周期

## 1. 系统概述

游戏内拥有大量独立NPC，他们在后台通过**四层优先级行为树**进行每秒一次的动态演化，构建了一个动态、真实的修仙世界生态。

NPC从诞生到死亡经历完整的生命周期，其行为模式受境界、职位、人格参数和国家特质影响。

## 2. NPC基础属性

### 2.1 核心属性

| 属性 | 说明 | 取值范围 |
|------|------|----------|
| id | 唯一标识符 | - |
| name | 姓名（随机生成） | - |
| clanId | 所属家族 | - |
| role | 职位身份 | 家主/长老/核心子弟/内门子弟/支脉子弟/执法堂长老 |
| realm | 境界 | 凡人→练气→筑基→金丹→元婴→化神（受层级限制） |
| power | 战斗力 | 500~10000+（受灵气倍率影响） |
| hp/maxHp | 生命值 | 基于power计算 |
| mp/maxMp | 灵力值 | 基于power计算 |
| activity | 当前状态 | 见状态列表 |
| position | 坐标位置 | {x, y} |

### 2.2 层级对NPC属性的影响

NPC的基础属性受世界层级灵气倍率影响：

| 世界层级 | 名称 | 灵气倍率 | NPC战力范围 | NPC境界上限 |
|:---|:---|:---|:---|:---|
| 第9层 | 凡界·新生地 | ×1.0 | 500~10000 | 化神 |
| 第8层 | 灵界·汇聚地 | ×1.5 | 750~15000 | 炼虚 |
| 第7层 | 灵界·争锋地 | ×2.0 | 1000~20000 | 合体 |
| 第6层 | 灵界·霸业地 | ×3.0 | 1500~30000 | 大乘 |
| 第5-1层 | 太虚境/仙界 | ×4.0~20.0 | 2000+ | 渡劫 |

战力计算公式：`基础战力 × 灵气倍率`

### 2.3 人格参数

每个NPC拥有4项独立的人格参数（0-100），影响其行为倾向：

| 参数 | 说明 | 行为影响 |
|------|------|----------|
| 野心（Ambition） | 追求变强的渴望 | 增加闭关/探索权重 |
| 谨慎（Caution） | 自我保护倾向 | 增加闭关/降低探索 |
| 忠诚（Loyalty） | 对家族的忠诚度 | 增加巡逻/后勤权重 |
| 贪婪（Greed） | 对资源的渴望 | 增加探索/跑商/打工权重 |

### 2.4 国家特质对人格的影响

NPC出生时，国家特质会影响其基础人格倾向：

| 国家 | 人格影响 |
|------|----------|
| 秦国 | 野心+20，忠诚+20（好战忠诚） |
| 楚国 | 谨慎+20（保守稳重） |
| 齐国 | 谨慎+10，野心+10（学术谨慎） |
| 燕国 | 谨慎+20，贪婪-10（苦修寡欲） |
| 赵国 | 野心+10，贪婪+10（游侠逐利） |
| 魏国 | 忠诚+20（正统忠义） |
| 韩国 | 贪婪+20，谨慎+10（纵横逐利） |

### 3.2 诞生方式

| 诞生方式 | 触发概率 | 初始状态 | 资源消耗 |
|:---|:---|:---|:---|
| **自然诞生** | 60% | 凡体，16岁，随机分配到某家族支脉 | 家族库房支付"养育费"100灵石 |
| **战争遗孤** | 20% | 继承父母部分修为（父母境界越高，起点越高） | 消耗父母遗留的遗产 |
| **散修投靠** | 15% | 已有练气/筑基修为，随机投靠某家族 | 无需家族养育费，自带少量资源 |
| **妖兽化形** | 5% | 金丹期以上妖兽渡劫化形，加入某国 | 自带妖兽材料，但初始好感度低 |

### 3.3 人格生成规则

新NPC诞生时，系统根据**当前世界状态**和**家族现状**，动态生成其人格参数：

| 人格参数 | 生成逻辑 |
|:---|:---|
| **野心** | 家族处于弱势时+20%；家族强盛时-10% |
| **谨慎** | 国家处于战争时+30%；和平时期-15% |
| **忠诚** | 诞生于嫡系+25%；支脉-10%；散修投靠-20% |
| **贪婪** | 家族资源匮乏时+20%；富裕时-10% |

> 这使得NPC的人格会**自适应世界局势**，例如战乱时代出生的NPC更谨慎，贫困家族出身的NPC更贪婪。

## 4. 行为树架构

行为树采用**自上而下优先级评估**机制，每秒执行一次。

### 4.1 行为树流程图

```
行为树评估（每秒执行）
  ↓
优先级1：生存应急
  ├─ 条件：HP < 30%
  └─ 行为：重伤逃遁，远离危险源，缓慢回血
  ↓
优先级2：家族职责
  ├─ 家主/长老：闭关突破 / 巡逻边界 / 坊市跑商
  ├─ 核心/内门：探索机缘 / 巡逻
  └─ 支脉子弟：坊市打工 / 后勤维护
  ↓
优先级3：机缘竞争
  ├─ 条件：附近有资源点
  └─ 行为：向资源点移动并采集
  ↓
优先级4：日常自主
  ├─ 打坐吐纳
  └─ 随机游走
```

## 5. 优先级详细说明

### 5.1 优先级1 - 生存应急

**触发条件**: NPC生命值 < 30%

**行为表现**:
- 状态切换为"重伤逃遁"
- 远离玩家方向移动
- 每秒恢复5%最大生命值
- 随机选择逃跑方向（如果无法判断危险源）

### 5.2 优先级2 - 家族职责

根据不同职位分配不同的行为权重：

#### 家主/长老

| 行为 | 触发条件 | 权重影响 |
|------|----------|----------|
| 闭关突破 | 野心>70，20%概率 | retreat +30 |
| 巡逻边界 | 忠诚>60，30%概率 | patrol +10 |
| 坊市跑商 | 贪婪>70，10%概率 | trade +30 |

#### 核心/内门子弟

| 行为 | 权重影响 |
|------|----------|
| 探索机缘 | explore +20 |
| 巡逻 | patrol +10 |

#### 支脉子弟

| 行为 | 权重影响 |
|------|----------|
| 坊市打工 | work +20 |
| 后勤维护 | logistics +20 |

### 5.3 优先级3 - 机缘竞争

**触发条件**: 附近（3格内）刷新了无主资源点

**行为表现**:
- 探索权重 +50
- 向资源点移动
- 到达后采集资源
- 野心/贪婪值高的NPC更容易被吸引

### 5.4 优先级4 - 日常自主

**触发条件**: 无以上紧急事务

**行为表现**:
- 打坐吐纳（rest）
- 随机游走

## 6. 行为权重计算

### 6.1 基础权重

```
初始权重:
  patrol: 10    (巡逻)
  retreat: 10   (闭关)
  logistics: 10 (后勤)
  explore: 10   (探索/采集)
  work: 10      (打工)
  rest: 10      (打坐)
  trade: 0      (跑商)
```

### 6.2 权重调整公式

```
最终权重 = 基础权重 + 职位修正 + 国家修正 + 人格修正 + 环境修正

职位修正:
  家主/长老: retreat +30, patrol +10, trade +30
  核心/内门: explore +20, patrol +10
  支脉子弟: work +20, logistics +20

国家修正:
  秦国: patrol +20
  楚国: logistics +20
  齐国: retreat +20
  燕国: rest +20
  赵国: explore +20
  魏国: patrol +10, retreat +10
  韩国: work +20

人格修正:
  explore += 野心 × 0.2
  work += 贪婪 × 0.2
  retreat += 谨慎 × 0.2
  logistics += 忠诚 × 0.2

环境修正:
  附近有资源点: explore +50
  灵石 < 20: work +30
```

### 6.3 行为选择算法

采用**轮盘赌选择法**：

```
总权重 = Σ(所有行为权重)
随机数 = random(0, 总权重)
依次减去各行为权重，直到随机数 <= 0
选择对应的行为
```

## 8. 执法堂长老系统

### 8.1 触发条件

- 家族好感度降至0以下
- 随机概率生成（70%概率）

### 8.2 属性特征

| 属性 | 值 |
|------|-----|
| 职位 | 执法堂长老 |
| 境界 | 化神（固定） |
| 战力 | 玩家战力的3倍 |
| 人格 | 忠诚100，贪婪10，野心50，谨慎50 |
| 灵石 | 500 |

### 8.3 行为逻辑

```
while (目标玩家存在) {
  计算与玩家的距离
  if (距离 <= 1格) {
    触发强制战斗
  } else {
    向玩家位置移动（追踪寻路）
  }
}
```

## 10. NPC跑商系统

### 10.1 跑商触发

- 家主/长老专属行为
- 贪婪值 > 70
- 10%概率触发

### 10.2 跑商流程

1. 选择随机外国都城作为贸易目标
2. 向目标都城移动（直线寻路）
3. 到达后获得利润（500+灵石×资源倍率）
4. 状态变更为"巡逻边界"
5. 部分利润上缴家族库房

### 10.3 经济影响

- 平衡各国物价
- 增加家族资金（受层级倍率影响）
- 击杀跑商NPC可获得额外收益

## 11. NPC生成机制

### 11.1 生成数量

- 玩家视野内生成约20个NPC
- 视野半径：15格

### 11.2 生成规则

- 随机分布在玩家周围（±5格）
- 职位随机分配
- 战力根据职位基础值×灵气倍率+随机浮动
- 境界根据战力推算（受层级限制）

### 11.3 姓名生成

- 使用预定义姓氏库：赢、芈、姜、姬、赵、魏、韩、李、王、白、蒙、项、田、林
- 名字格式：姓氏+某某（简化处理）

## 12. 层级差异化NPC行为

### 12.1 凡界NPC（第9层）

- 行为模式相对简单
- 境界：凡人~化神
- 主要活动：巡逻、采集、跑商
- 执法长老境界：化神

### 12.2 灵界NPC（第8-6层）

- 竞争更加激烈
- 境界：炼虚~大乘
- 家族兼并战频繁
- 探索与资源争夺行为增多

### 12.3 太虚境NPC（第5-3层）

- 战略行为更复杂
- 境界：渡劫为主
- 可能形成跨家族联盟
- 证道战相关行为

### 12.4 仙界NPC（第2-1层）

- 仙门体系
- 仙族为主
- 合道相关行为
- 影响下层世界规则

### 13.5 行为树优先级与LLM任务的映射

| 行为树优先级 | 行为类型 | LLM action_type |
|:---|:---|:---|
| 优先级1 | 生存应急 | `RETREAT` |
| 优先级2 | 家族职责 | `PATROL`, `TRADE`, `CULTIVATE` |

LLM生成的`action_type`会被翻译为行为树节点，注入到对应的优先级层执行。
