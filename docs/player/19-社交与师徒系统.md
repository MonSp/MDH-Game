# 社交与师徒系统设计

## 1. 设计理念：仙途漫漫，道友同行

修仙并非 solitary journey。大道独行虽可成仙，但若有道侣双修、师徒传承、挚友并肩，不仅仙途更有趣，更能在关键时刻互相扶持。本系统构建一个立体的社交网络，让玩家的关系从"陌生人"逐步发展为"生死之交"，甚至"万古道侣"。

**核心循环**：
```
结识 → 互动 → 建立关系 → 共同成长 → 深度羁绊 → 跨纪元保留
```

### 2.1 玩家间关系等级

| 等级 | 名称 | 亲密度要求 | 解锁功能 | 每日互动上限 |
|:---|:---|:---|:---|:---|
| 0 | **陌生人** | 0 | 无 | - |
| 1 | **相识** | 1-50 | 私聊、组队 | 3次 |
| 2 | **熟悉** | 51-150 | 交易、切磋 | 5次 |

| 4 | **挚友** | 301-600 | 结拜、共享仓库 | 10次 |
| 5 | **生死之交** | 601-1000 | 生死契约、复活互助 | 15次 |
| 特殊 | **道侣** | 1000+ | 双修、同心技能 | 20次 |

## 3. 师徒系统

### 3.1 拜师条件

| 条件 | 要求 |
|:---|:---|
| **徒弟境界** | 低于师父至少1个大境界 |
| **师父境界** | 元婴期以上 |
| **师父资格** | 已完成出师任务或从未收徒 |
| **数量限制** | 师父最多同时收3名徒弟 |
| **冷却期** | 叛师后30天内不可再拜师 |

### 3.2 拜师流程

```
玩家A（师父）发布收徒信息
  ↓
玩家B（徒弟）申请拜师
  ↓
师父同意
  ↓
举行拜师仪式（可选，消耗少量灵石）
  ↓
师徒关系确立
```

### 3.3 师徒权益

#### 3.3.1 徒弟权益

| 权益 | 说明 |
|:---|:---|
| **经验加成** | 与师父组队时修为获取+20% |
| **功法传授** | 师父可传授已修炼的功法（消耗传道值） |
| **装备赞助** | 师父可赠送装备给徒弟（无等级限制） |
| **求助传送** | 每日可传送至师父位置1次 |
| **师父庇护** | 被恶意PK时可呼叫师父助战 |
| **出师奖励** | 达到指定境界后出师，获得丰厚奖励 |

#### 3.3.2 师父权益

| 权益 | 说明 |
|:---|:---|
| **传道奖励** | 徒弟升级时，师父获得传道值 |
| **名师称号** | 出师徒弟越多，称号越高级 |
| **名师商店** | 用传道值兑换稀有道具 |
| **师徒任务** | 专属师徒任务，奖励丰厚 |
| **传承奖励** | 徒弟出师时，师父获得大量奖励 |

### 3.4 境界传承机制

**核心设计：师徒传承的核心价值在于境界差距带来的额外收益。**

#### 3.4.1 境界差距与传道效果

```
传道效果加成 = 基础传道效果 × 境界差距系数 × 师父心境系数

境界差距系数：
  师父比徒弟高1个大境界 → 1.0
  师父比徒弟高2个大境界 → 1.5
  师父比徒弟高3个大境界 → 2.0
  师父比徒弟高4个大境界 → 2.5

师父心境系数：
  师父心境等级1 → 1.0
  师父心境等级2 → 1.2
  师父心境等级3 → 1.5
```

#### 3.4.2 境界传承详细表

| 境界差距 | 徒弟修为加成 | 传道值获取 | 额外效果 |
|:---|:---|:---|:---|
| 1个大境界 | +20% | 1.0倍 | 无 |
| 2个大境界 | +35% | 1.5倍 | 突破成功率+5% |
| 3个大境界 | +50% | 2.0倍 | 突破成功率+10%，功法领悟+20% |
| 4个大境界 | +70% | 2.5倍 | 突破成功率+15%，功法领悟+30%，道心+5 |

#### 3.4.3 师父心境系统

师父的心境等级影响传道效果：

| 心境等级 | 称号 | 解锁条件 | 传道加成 |
|:---|:---|:---|:---|
| 1级 | **初入道途** | 成为师父即解锁 | 1.0倍 |
| 2级 | **桃李满园** | 累计培养10位出师徒弟 | 1.2倍 |
| 3级 | **传道宗师** | 累计培养50位出师徒弟 | 1.5倍 |
| 4级 | **万世师表** | 累计培养100位出师徒弟 | 2.0倍 |

#### 3.4.4 师徒修为共享

高境界师父可与徒弟共享部分修为：

```
修为共享 = 师父每日修为 × 共享比例 × 境界差距系数

共享比例（师父消耗）：
  每日可共享修为的10%
  师父境界每提升1级，额外解锁5%共享上限

境界差距系数：
  1个大境界 → 0.5（徒弟获得师父修为的5%）
  2个大境界 → 0.7（徒弟获得师父修为的7%）
  3个大境界 → 1.0（徒弟获得师父修为的10%）
  4个大境界 → 1.5（徒弟获得师父修为的15%）
```

### 3.5 出师系统

| 出师条件 | 奖励（徒弟） | 奖励（师父） |
|:---|:---|:---|
| **达到金丹期** | 灵石×10000 + 玄阶功法×1 | 传道值×1000 |
| **达到元婴期** | 灵石×50000 + 地阶功法×1 | 传道值×5000 + 名师点×1 |
| **达到化神期** | 灵石×200000 + 天阶功法×1 | 传道值×20000 + 名师点×5 |
| **飞升成功** | 飞升令×1 + 特殊称号 | 传道值×50000 + 名师点×10 |

### 3.6 境界与师徒任务联动

师徒任务会根据境界差距进行动态调整：

```
任务难度 = 基础难度 × (1 - 境界适应系数)

境界适应系数：
  徒弟境界=任务推荐境界 → 0（标准难度）
  徒弟境界>推荐境界1级 → -20%（更容易）
  徒弟境界>推荐境界2级 → -40%（碾压）
  徒弟境界<推荐境界1级 → +20%（挑战）
```

| 境界层级 | 推荐师徒任务类型 | 任务奖励加成 |
|:---|:---|:---|
| 练气期 | 采集、跑腿 | 基础 |
| 筑基期 | 采集、战斗、护送 | +10% |
| 金丹期 | 秘境探索、势力对抗 | +20% |
| 元婴期 | 高级秘境、国家任务 | +30% |
| 化神期 | 仙府探索、伐周战争 | +40% |

### 3.7 叛师与逐徒

| 行为 | 条件 | 惩罚 |
|:---|:---|:---|
| **徒弟叛师** | 主动解除关系 | 30天内不可拜师，扣除50%亲密度 |
| **师父逐徒** | 徒弟7天未上线或恶意行为 | 无惩罚，但消耗名师点 |
| **自动解除** | 徒弟境界超过师父 | 和平解除，保留亲密度 |

## 4. 结拜系统

### 4.1 结拜条件

| 条件 | 要求 |
|:---|:---|
| **人数** | 2-5人 |
| **关系** | 所有人间亲密度≥300（挚友） |
| **境界** | 所有人境界差≤2个大境界 |
| **费用** | 每人10000灵石 |
| **冷却** | 解除结拜后30天内不可再结拜 |

### 4.2 结拜流程

```
发起人邀请结拜成员
  ↓
所有成员同意
  ↓
选择结拜类型
  ├─ 金兰结义：通用型
  ├─ 生死同盟：战斗加成型
  └─ 道途同行：修炼加成型
  ↓
举行结拜仪式
  ↓
结拜关系确立，获得结拜技能
```

### 4.3 结拜技能

| 结拜类型 | 技能名称 | 效果 |
|:---|:---|:---|
| **金兰结义** | 同气连枝 | 结拜成员同地图时，全属性+5% |
| | 守望相助 | 可瞬间传送至任一结拜成员身边（CD 1小时） |
| **生死同盟** | 并肩作战 | 结拜成员组队时，伤害+10% |
| | 舍身相救 | 可为结拜成员抵挡一次致命伤害（CD 1天） |
| **道途同行** | 道法共鸣 | 结拜成员同地图修炼时，速度+15% |
| | 心得共享 | 可共享一本已修炼功法的心得 |

### 4.4 结拜排行

| 排行依据 | 奖励 |
|:---|:---|
| **结拜天数** | 纪念日特殊奖励 |
| **共同战斗次数** | 战斗加成提升 |
| **共同完成任务** | 任务奖励提升 |

## 5. 道侣系统

### 5.1 结成道侣条件

| 条件 | 要求 |
|:---|:---|
| **亲密度** | 1000以上 |
| **共同经历** | 共同完成特定剧情任务"红尘劫" |
| **境界** | 金丹期以上 |
| **费用** | 纪元精华×100 + 灵石×100000 |
| **唯一性** | 每人只能有1位道侣 |

### 5.2 结成流程

```
双方亲密度达到1000
  ↓
共同完成"红尘劫"剧情任务
  ↓
一方发起结成请求
  ↓
另一方同意
  ↓
举行双修大典（全服公告）
  ↓
道侣关系确立
```

### 5.3 道侣特权

| 特权 | 说明 |
|:---|:---|
| **双修** | 共同修炼时，双方修为获取+50% |
| **同心技能** | 解锁专属合击技能 |
| **生命链接** | 一方HP归零时，另一方可牺牲30%HP为其续命 |
| **传送无CD** | 传送至道侣位置无冷却 |
| **共享仓库** | 拥有100格共享仓库空间 |
| **道侣任务** | 专属双人任务，奖励丰厚 |
| **同心印记** | 特殊外观标识 |

### 5.4 双修机制

```
双修条件：
- 双方在线且同地图
- 双方HP/MP满值
- 每日限1次，每次30分钟

双修效果：
- 双方修为获取+50%
- 有概率触发"顿悟"（修为额外+100%）
- 有概率领悟"同心技能"
- 亲密度+10/次
```

### 5.5 同心技能

| 技能名称 | 效果 | 触发条件 |
|:---|:---|:---|
| **比翼双飞** | 双方速度+50%，持续10秒 | 同时释放遁术 |
| **琴瑟和鸣** | 双方攻击力+30%，持续15秒 | 同时释放攻击技能 |
| **相濡以沫** | 双方恢复50%HP | 一方HP<20% |
| **天作之合** | 合体释放超强一击 | 双方亲密度满值时 |

### 5.6 解除道侣

| 方式 | 条件 | 惩罚 |
|:---|:---|:---|
| **和平解除** | 双方同意 | 亲密度清零，30天内不可结成新道侣 |
| **单方面解除** | 一方强制解除 | 扣除50000灵石，90天内不可结成新道侣 |
| **生死相隔** | 一方真灵转世 | 保留50%亲密度，转世后可重新结缘 |

## 6. 社交互动玩法

### 6.1 洞府拜访

| 功能 | 说明 |
|:---|:---|
| **参观洞府** | 可参观好友/道侣的洞府 |
| **留言** | 在洞府留言板留言 |
| **赠送礼物** | 赠送洞府装饰品或实用道具 |
| **共同修炼** | 在对方洞府中共同修炼 |

### 6.2 仙缘事件

| 事件类型 | 触发条件 | 效果 |
|:---|:---|:---|
| **偶遇** | 随机在地图遇到好友 | 亲密度+5 |
| **求助** | 好友战斗中HP<30% | 可前往救援 |
| **论道** | 与好友在同一地点修炼 | 双方修为+10% |
| **共饮** | 在酒楼组队消费 | 亲密度+10，获得Buff |
| **探险** | 组队探索未知区域 | 发现率+20% |

### 6.3 社交称号

| 称号 | 获取条件 | 效果 |
|:---|:---|:---|
| **广结善缘** | 拥有10位以上好友 | 亲密度获取+10% |
| **名师高徒** | 有3位以上徒弟出师 | 传道值获取+20% |
| **生死之交** | 拥有5位以上生死之交 | 组队全属性+5% |
| **神仙眷侣** | 与道侣共同游戏30天 | 双修效果+20% |
| **独行侠** | 无好友达到友好 | 单人修炼+10% |

## 7. 跨纪元社交保留

### 7.1 保留规则

| 关系类型 | 保留内容 | 保留条件 |
|:---|:---|:---|
| **师徒** | 师徒名分、传道值 | 双方均选择保留 |
| **结拜** | 结拜关系、结拜天数 | 半数以上成员选择保留 |
| **道侣** | 道侣关系、亲密度50% | 双方均选择保留 |
| **好友** | 亲密度20% | 单方选择保留 |

### 7.2 转世重逢

```
真灵转世后：
- 保留的关系会显示"前世羁绊"标记
- 重新相遇时触发特殊剧情
- 恢复关系速度+50%
- 可能解锁前世记忆任务
```

## 8. 与现有系统的联动

### 8.1 与家族系统的联动

- 师徒、结拜、道侣关系不影响家族归属
- 但同一家族内建立关系有额外加成
- 家族战时可呼叫关系网中的外援

### 8.2 与战斗系统的联动

- 组队战斗有属性加成
- 道侣可释放合击技
- 结拜成员可触发舍身相救

### 8.3 与经济系统的联动

- 好友间交易无关税
- 师徒间可赠送装备
- 道侣共享仓库降低存储成本
