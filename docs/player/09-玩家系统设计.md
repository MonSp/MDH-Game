# 指挥官系统设计

## 1. 系统概述

在《太古纪元：霸业》中，玩家不再是简单的角色扮演者，而是**指挥官**——可以指挥军队、制定战略、管理国家的决策者。玩家的境界不仅代表个人实力，更代表指挥权限和战略影响力。

### 1.1 核心设计理念

- **指挥官为核心**：玩家是指挥官，不是普通士兵
- **境界即权限**：境界决定可指挥的军团规模
- **战略优先**：战略决策比个人战斗更重要
- **AI辅助**：AI Agent辅助玩家决策和执行

## 2. 玩家角色类型

### 2.1 角色类型选择

| 角色类型 | 说明 | 核心玩法 | 推荐玩家 |
|:---|:---|:---|:---|
| **国君** | 国家最高统治者 | 国家战略、外交决策 | 喜欢宏观战略的玩家 |
| **将军** | 军队最高指挥官 | 战场指挥、军团管理 | 喜欢战术指挥的玩家 |
| **谋士** | 战略顾问 | 情报分析、策略制定 | 喜欢策略规划的玩家 |
| **掌门** | 门派领袖 | 门派管理、功法研发 | 喜欢养成建设的玩家 |
| **散修** | 独立修仙者 | 自由探索、个人成长 | 喜欢自由玩法的玩家 |

## 3. 指挥系统

### 3.1 指挥层级

| 指挥层级 | 境界要求 | 可指挥规模 | 指挥范围 |
|:---|:---|:---|:---|
| **小队指挥** | 练气期 | 10人 | 战术 |
| **中队指挥** | 筑基期 | 100人 | 战术 |
| **大队指挥** | 金丹期 | 1000人 | 战术 |
| **师团指挥** | 元婴期 | 10000人 | 战术/战役 |
| **军团指挥** | 化神期 | 50000人 | 战役 |
| **集团军指挥** | 炼虚期 | 100000人 | 战略 |
| **全国统帅** | 合体期 | 无限制 | 战略 |

## 4. 战略决策系统

### 4.1 战略决策类型

| 决策类型 | 说明 | 影响范围 | 决策时间 |
|:---|:---|:---|:---|
| **宣战** | 对其他国家宣战 | 全国 | 即时 |
| **结盟** | 与其他国家结盟 | 全国 | 即时 |
| **迁都** | 迁移国家首都 | 全国 | 1月 |
| **改革** | 进行国家改革 | 全国 | 1季度 |
| **科技研发** | 投入科技研发 | 全国 | 1年 |

### 4.2 战略AI辅助

玩家可以启用AI辅助决策：

```json
{
  "ai_assistance": {
    "enabled": true,
    "assistance_level": "建议",  // 建议/辅助/自动
    "ai_recommendations": [
      {
        "type": "战略建议",
        "content": "建议先与魏国结盟，再对楚国开战",
        "confidence": 0.85,
        "reason": "魏国与楚国有历史恩怨，结盟成功率高"
      }
    ]
  }
}
```

### 4.3 决策执行

| 执行方式 | 说明 | 适用场景 |
|:---|:---|:---|
| **手动执行** | 玩家亲自执行 | 关键决策 |
| **AI辅助** | AI提供建议 | 复杂决策 |
| **AI代理** | AI全权代理 | 日常决策 |
| **混合模式** | 玩家决策+AI执行 | 一般决策 |
