# 玩家系统设计

## 1. 系统概述

玩家系统是游戏的核心，涵盖角色创建、属性成长、体质突破、境界提升、九重天飞升、轮回转生等全方位修仙体验。玩家从凡界开始，通过不断修炼和冒险，从散修逆袭至天子，经历九重天劫，最终飞升混元仙界。

## 2. 角色创建

### 2.1 出生机制

1. 玩家选择服务器（各层级分区，上限100-1000人/服）
2. 输入道号（角色名）
3. 选择出生国家（七选一）
4. 选择出生家族
   - **预组家族**：输入邀请码直接加入（仅限三级家族）
   - **散人玩家**：系统随机分配至一至二级家族
   - **皇族禁止选择**，皇族为NPC专属
5. 初始身份：支脉子弟/客卿
6. 初始体质：凡体
7. 初始世界：第9层天（凡界·新生地）

### 2.2 预组家族创建（游戏外）

- **条件**：至少5名玩家，缴纳100灵石创建费（系统回收）
- **等级限制**：只能创建三级家族
- **流程**：族长在官网/启动器创建家族档案，生成唯一邀请码，成员创角时输入邀请码即可加入

### 2.3 初始属性

| 属性 | 初始值 | 说明 |
|------|--------|------|
| 气血（HP） | 100 | 生命值（受灵气倍率影响） |
| 灵力（MP） | 20（魏国22） | 灵力值（受灵气倍率影响） |
| 战力（Attack） | 5 | 攻击力量（受灵气倍率影响） |
| 修为（Exp） | 0 | 修为经验 |
| 最大修为 | 100 | 当前境界修为上限 |

初始属性受世界层级灵气倍率影响。

### 2.4 国家特质加成

玩家所在国家提供不同特质的修仙加成：

| 国家 | 特质 | 加成效果 |
|------|------|----------|
| 秦国 | 兵甲修仙 | 战力计算+10%，杀人夺宝修为+10% |
| 楚国 | 巫祝修仙 | 炼丹成功率+15% |
| 齐国 | 学术修仙 | 打坐领悟速度+20% |
| 燕国 | 苦修之士 | 打坐灵气吸收效率+10% |
| 赵国 | 游侠修仙 | 20%概率移动距离翻倍 |
| 韩国 | 奇技修仙 | 制作成本-10% |
| 魏国 | 王道修仙 | 灵力上限+10% |

## 3. 客卿系统

### 3.1 客卿定义

客卿是散人玩家发展的重要助力，玩家可向其他玩家或特定NPC发出客卿邀请。

### 3.2 客卿邀请流程

1. 玩家A向玩家B发出客卿邀请
2. B同意后成为A的客卿
3. 双方建立主从关系

### 3.3 客卿机制

- 玩家A的客卿B与A**共享家族任务收益加成10%**
- 客卿拥有独立的家族贡献值，可用于兑换家族资源
- 客卿**无权参与家族科技投票**
- 家主可任命客卿为"供奉"，享有更高俸禄

### 3.4 逼宫条件

当玩家满足以下条件时，可解锁"逼宫"选项：
- 客卿数量≥5人
- 个人家族贡献排名家族前3

### 3.5 逼宫流程

1. 满足逼宫条件后，发起对现任家主的挑战
2. 可选择PVE战斗或家族投票
3. 成功则成为新任家主，失败则维持原状

### 3.6 散人晋升通道

| 阶段 | 行为 | 效果 |
|:---|:---|:---|
| **结交** | 与其他散人玩家或友好NPC互动 | 形成小团体 |
| **招揽** | 邀请其他散人成为自己的客卿 | 客卿与主家共享资源，并肩作战 |
| **积累** | 客卿数量≥5人，且贡献排名前3 | 解锁逼宫条件 |
| **逼宫** | 发起对现任家主的挑战 | 成功则成为新任家主 |
| **晋升** | 成为家主后完成晋升任务 | 二级家族→一级家族→皇族 |

## 4. 潜质觉醒系统

### 4.1 潜质类型

玩家出生均为"凡体"，但通过日常游戏行为会暗中累积隐藏计数器，最终触发相应的潜质觉醒：

| 潜质 | 触发条件 | 隐藏计数器 |
|------|----------|------------|
| 剑心潜质 | 累计击杀/攻击NPC满5次 | killCount >= 5 |
| 雷灵潜质 | 累计打坐修炼满10次 | cultivateCount >= 10 |
| 丹道潜质 | 累计采集资源满5次 | gatherCount >= 5 |

### 4.2 觉醒机制

- 觉醒后，UI面板会展示当前潜质
- 潜质为后续洗髓突破指明方向
- 潜质一旦觉醒不可更改

## 5. 体质突破系统

### 5.1 突破条件

1. 获得道具【洗髓丹】
2. 当前体质为"凡体"
3. 气血充足（需承受80%最大生命值扣除）

### 5.2 突破流程

```
使用洗髓丹
  ↓
扣除当前 80% 最大生命值
  ↓
判断气血是否充足？
  ├─ 否 → 突破失败，保留1滴血
  └─ 是 → 突破成功
  ↓
根据潜质决定进阶方向：
  ├─ 剑心潜质 → 剑体
  ├─ 雷灵潜质 → 雷灵体
  ├─ 丹道潜质 → 药王体
  └─ 无潜质 → 随机进阶
```

### 5.3 体质特性

| 体质 | 描述 | 属性加成 |
|------|------|----------|
| 凡体 | 芸芸众生，资质平平 | 无特殊加成 |
| 剑体 | 天生剑骨，杀伐果断 | 战力计算+25%，御剑飞行+15% |
| 战体 | 百战不殆，肉身成圣 | 生命上限+30%，受击硬直减免 |
| 雷灵体 | 亲和雷电，法法狂暴 | 雷系伤害+30%，施法速度+15% |
| 药王体 | 草木皆兵，丹心长存 | 采集灵草双倍，炼丹成功率+20% |
| 仙体 | 飘飘欲仙，超凡脱俗 | 全属性+10% |
| 神体 | 天神下凡，万法不侵 | 全属性+20% |

### 5.4 获取洗髓丹的途径

| 途径 | 概率 | 说明 |
|------|------|------|
| 采集遗迹 | 30% | 高概率掉落 |
| 击杀NPC | 20% | 随机掉落 |
| 坊市购买 | - | 价格约500灵石 |
| 击杀跑商NPC | 高 | 额外掉落100-300灵石 |
| **天工商肆** | - | 第9层大周皇城限购购买，500灵石/个 |

## 6. 境界系统

### 6.1 各层世界最高境界

| 世界层级 | 名称 | 最高境界 |
|:---|:---|:---|
| 第9层 | 凡界·新生地 | 化神 |
| 第8层 | 灵界·汇聚地 | 炼虚 |
| 第7层 | 灵界·争锋地 | 合体 |
| 第6层 | 灵界·霸业地 | 大乘 |
| 第5-1层 | 太虚境/仙界 | 渡劫 |

### 6.2 境界突破灵石消耗

| 境界 | 突破灵石消耗 | 突破后属性变化 |
|------|--------------|----------------|
| 凡人→练气 | 100 | 全属性×2 |
| 练气→筑基 | 300 | 全属性×2 |
| 筑基→金丹 | 1000 | 全属性×2 |
| 金丹→元婴 | 3000 | 全属性×2 |
| 元婴→化神 | 10000 | 全属性×2 |
| 化神→炼虚 | 30000 | 全属性×2 |
| 炼虚→合体 | 100000 | 全属性×2 |
| 合体→大乘 | 300000 | 全属性×2 |
| 大乘→渡劫 | 1000000 | 全属性×2 |

### 6.3 修为获取途径

| 途径 | 修为收益 | 国家特质影响 |
|------|----------|--------------|
| 打坐修炼 | 10×灵气倍率/次 | 齐国+20%，燕国+10% |
| 采集灵田 | 30×灵气倍率/次 | - |
| 击杀NPC | 50×灵气倍率/次 | 秦国+10% |

### 6.4 突破规则

1. 修为达到当前境界上限后，可尝试突破至下一境界
2. 境界突破需要消耗对应数量的灵石
3. 突破成功后：
   - 进入下一境界，血量、灵力、战力翻倍（受灵气倍率影响）
4. 灵石不足时境界突破失败，修为保留
5. 达到当前世界最高境界后，需飞升才能继续突破

## 7. 飞升系统

### 7.1 飞升条件

| 条件类型 | 具体要求 | 设计意图 |
|:---|:---|:---|
| 境界要求 | 达到当前世界最高境界 | 硬性门槛 |
| 战力要求 | 战力值达到当前世界前10%均值 | 防止速成号飞升 |
| 功德要求 | 完成至少3次"天道任务" | 确保玩家体验过核心玩法 |
| 资源要求 | 缴纳飞升令×1 + 灵石×100000 | 经济回收 |
| 渡劫要求 | 成功渡过九重天劫（90%成功率） | 仪式感+风险 |

### 7.2 飞升流程

```
达到当前世界最高境界
         │
         ▼
前往本国皇城"飞升台"
         │
         ▼
验证飞升条件
  ├─ 飞升令 ×1
  ├─ 灵石 ×100000
  └─ 天道任务完成
         │
         ▼
渡劫判定（90%成功率）
  ├─ 成功 → 进入目标世界
  └─ 失败 → 重伤，损耗30%修为
         │
         ▼
角色数据迁出 → 分配至目标世界
         │
         ▼
重置为化神境界，属性×0.5
```

### 7.3 飞升效果

- 境界重置为化神
- 属性大幅提升（受目标层灵气倍率影响）
- 可在新世界继续修炼至该层最高境界
- 飞升次数记录

### 7.4 第8层飞升家族创建

飞升至第八层时，玩家可选择：

1. **加入现有家族**：选择一个已存在的家族加入
2. **创建飞升家族**：消耗飞升令×1 + 灵石×50000，创建属于自己的二级飞升家族
   - 创建者自动成为家主
   - 可生成家族邀请码供同伴加入

### 7.5 天道任务

| 任务 | 描述 |
|------|------|
| 完成3次天道任务 | 参与国家战争、守护家族、探索遗迹等 |
| 达到当前世界最高境界 | 境界达到该层上限 |
| 积累足够功德 | 完成善举，提升功德值 |

## 8. 轮回转生系统

高天层的玩家（第6层及以上），可选择主动转生至低层世界：

| 转生类型 | 条件 | 效果 |
|:---|:---|:---|
| **神念投影** | 消耗"分神秘法"，CD 7天 | 在当前所在的下层世界创建一个临时分身，存在2小时 |
| **真灵转世** | 放弃当前角色大部分修为 | 在第9层新建角色，保留称号/外观/部分记忆，获得"转世灵童"天赋 |
| **道统传承** | 飞升时选择"留下道统" | 在原家族留下传承石碑，后人参悟可获得功法 |

### 8.1 转世灵童天赋

真灵转世后的新角色获得特殊天赋：

| 天赋名称 | 效果 |
|:---|:---|
| **宿慧** | 功法领悟速度+50% |
| **轮回印** | 每提升一个大境界，解锁一段前世记忆（获得资源/功法） |
| **因果缠身** | 与前世的仇敌/挚友产生特殊交互选项 |

### 8.2 降维打击的平衡

为防止高天层玩家无限碾压低层：
- **神念投影**有严格的CD和时长限制
- **真灵转世**需要放弃原角色，是重大决策
- 低层世界有境界压制：高境界转生者前期战力优势会被压缩

## 9. 交互系统

### 9.1 NPC交互

点击NPC后弹出交互菜单：

| 操作 | 效果 | 风险 |
|------|------|------|
| 交谈 | 获取信息/对话 | 无 |
| 交易 | 换取低级丹药 | 无 |
| 攻击 | 触发战斗 | 高 |

### 9.2 战斗系统

```
发起攻击
  ↓
计算胜率 = 玩家战力 / (玩家战力 + NPC战力/10)
胜率限制在 10% ~ 90%
  ↓
随机判定
  ├─ 胜利 → 获得修为+灵石+可能掉落道具
  └─ 失败 → 损失30点气血
```

#### 战斗胜利奖励

- 修为：50点×灵气倍率（秦国+10%）
- 灵石：继承NPC携带的全部灵石
- 洗髓丹：20%概率掉落
- 击杀跑商NPC：额外100-300灵石

#### 战斗失败惩罚

- 损失30点气血
- 最低保留1点气血

### 9.3 资源点交互

| 资源类型 | 距离限制 | 采集收益 |
|----------|----------|----------|
| 灵田 | 1格内 | 30修为×灵气倍率 |
| 矿脉 | 1格内 | 50灵石×资源倍率 |
| 遗迹 | 1格内 | 100灵石×资源倍率 + 30%洗髓丹 |

## 12. 赛季与重置机制

### 12.1 第9层赛季制

| 项目 | 设计 |
|:---|:---|
| **赛季周期** | 3个月 |
| **赛季结算** | 根据飞升人数、国家版图、家族排名发放奖励 |
| **赛季重置** | 重置七国版图、家族好感度、NPC状态（保留玩家个人数据） |
| **新生名额** | 赛季初释放大量新生名额，鼓励新玩家涌入 |

### 12.2 高层的永恒性

- **第6层及以上**：不参与赛季重置，是"永恒的战场"
- **第1层混元仙界**：唯一、永恒，所有飞升者的最终归宿

这形成了"**下层轮回，上层永恒**"的宇宙观。

## 13. LLM决策入口：玩家交互增强

### 13.1 LLM适用场景

在玩家交互层面，LLM可用于增强NPC的对话智能和交互体验：

| 场景 | LLM决策对象 | 触发方式 | 影响范围 |
|:---|:---|:---|:---|
| **智能对话生成** | T1/T2级NPC | 玩家交谈 | 对话内容、语气、人格一致性 |
| **个性化响应** | 所有LLM启用NPC | 玩家交互 | 基于玩家历史行为调整态度 |
| **动态任务生成** | T1/T2级NPC | 玩家交互 | 生成个性化任务/挑战 |
| **事件叙事生成** | 系统级 | 世界事件 | 生成事件描述文本 |

### 13.2 LLM输入数据结构（玩家交互）

```json
{
  "npc_id": "QIN_WANG_001",
  "name": "嬴稷",
  "position": "秦王",
  "cultivation": "元婴后期",

    "ambition": 0.95,
    "caution": 0.60,
    "loyalty": 0.90,
    "greed": 0.30
  },
  "player_interaction_history": {
    "total_interactions": 5,
    "gift_count": 2,
    "attack_count": 0,
    "trade_count": 3,

  },

    "at_war_with": ["楚国"],

  },

```

### 13.4 与LLM规划系统的衔接

玩家交互LLM增强与[NPC的AI决策系统](../npc/12-NPC的AI决策.md)的衔接方式：
- 对话内容生成 → 基于NPC当前LLM计划中的`primary_goal`调整语气和内容
- 个性化任务生成 → 可触发NPC临时添加任务到LLM计划
- 玩家关系影响 → 修改NPC的`personality`权重或`family_status`
