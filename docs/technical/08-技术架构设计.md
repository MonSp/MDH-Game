# 技术架构设计

## 1. 系统概述

《太古纪元：霸业》采用**AI原生架构**，核心特点是三层级AI系统驱动游戏世界。技术架构需要支持大规模AI Agent并发、实时战略战斗、以及复杂的战略模拟。

### 1.1 核心设计原则

- **AI原生**：AI Agent是游戏的核心驱动力
- **分层架构**：战略、战术、角色三层级分离
- **模块化设计**：各系统独立，便于扩展和维护
- **性能优先**：支持500+单位同屏战斗
- **成本可控**：AI调用成本可预测、可控制

## 3. 客户端架构

### 3.1 渲染引擎

采用**Phaser 3**作为2.5D渲染引擎：

| 功能 | 技术方案 | 说明 |
|:---|:---|:---|
| **2.5D渲染** | Phaser 3 + 自定义着色器 | 实现2.5D像素风格 |
| **大规模单位** | 对象池 + LOD系统 | 支持500+单位同屏 |
| **特效系统** | WebGL粒子系统 | 法术、爆炸等特效 |
| **UI系统** | React + Phaser UI | 复杂的战略界面 |

### 3.2 战斗系统

| 功能 | 技术方案 | 说明 |
|:---|:---|:---|
| **实时战斗** | 自定义逻辑 + Phaser物理 | 60FPS实时计算 |
| **单位AI** | 行为树 + 状态机 | 单位自主行为 |
| **路径寻找** | A*算法 + 流场 | 大规模单位寻路 |
| **碰撞检测** | 空间分割 + 四叉树 | 高效碰撞检测 |

### 3.3 地图系统

| 功能 | 技术方案 | 说明 |
|:---|:---|:---|

class StrategicAI {

#### 4.2.2 批量处理

```typescript
class AIBatchProcessor {
  private batch: AIRequest[] = [];
  private batchSize: number = 10;
  private batchInterval: number = 1000; // 1秒
  
  addRequest(request: AIRequest): void {
    this.batch.push(request);
    if (this.batch.length >= this.batchSize) {
      this.processBatch();
    }
  }
  
  private async processBatch(): Promise<void> {
    const requests = this.batch.splice(0, this.batchSize);
    const responses = await this.callLLMBatch(requests);
    this.distributeResponses(responses);
  }
}
```

#### 4.2.3 异步处理

```typescript
class AIAsyncProcessor {
  private queue: AIRequest[] = [];
  private workers: number = 5;
  
  async processQueue(): Promise<void> {
    const promises = [];
    for (let i = 0; i < this.workers; i++) {
      promises.push(this.worker());
    }
    await Promise.all(promises);
  }
  
  private async worker(): Promise<void> {
    while (this.queue.length > 0) {
      const request = this.queue.shift();
      if (request) {
        await this.processRequest(request);
      }
    }
  }
}
```

class AICostController {
  private monthlyBudget: number = 1000; // 月度预算
  private currentCost: number = 0;
  
  canMakeRequest(request: AIRequest): boolean {
    const estimatedCost = this.estimateCost(request);
    if (this.currentCost + estimatedCost > this.monthlyBudget) {
      // 超出预算，降级处理
      return this.handleBudgetExceeded(request);
    }
    return true;
  }
  
  private handleBudgetExceeded(request: AIRequest): boolean {
    // 降级到更便宜的模型
    request.model = this.getCheaperModel(request.model);
    return true;
  }
}

### 5.2 核心表结构

```sql
-- 国家表
CREATE TABLE countries (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  ai_profile JSONB,           -- AI人格参数
  territory_size INTEGER,
  population INTEGER,
  military_strength INTEGER,
  economy_power INTEGER,
  created_at TIMESTAMP DEFAULT NOW()
);

-- AI Agent表
CREATE TABLE ai_agents (
  id SERIAL PRIMARY KEY,
  ai_id VARCHAR(50) UNIQUE NOT NULL,
  type VARCHAR(20) NOT NULL,  -- strategic/tactical/character
  personality JSONB,          -- 人格参数
  memory JSONB,               -- 记忆数据
  emotional_state JSONB,      -- 情感状态
  created_at TIMESTAMP DEFAULT NOW()
);

-- 军团表
CREATE TABLE legions (
  id SERIAL PRIMARY KEY,
  legion_id VARCHAR(50) UNIQUE NOT NULL,
  country_id INTEGER REFERENCES countries(id),
  commander_ai_id VARCHAR(50) REFERENCES ai_agents(ai_id),
  type VARCHAR(20),
  total_strength INTEGER,
  current_strength INTEGER,
  morale DECIMAL(3,2),
  position JSONB,             -- 位置信息
  created_at TIMESTAMP DEFAULT NOW()
);

-- 战斗记录表
CREATE TABLE battles (
  id SERIAL PRIMARY KEY,
  battle_id VARCHAR(50) UNIQUE NOT NULL,
  attacker_id INTEGER REFERENCES countries(id),
  defender_id INTEGER REFERENCES countries(id),
  battlefield JSONB,          -- 战场信息
  result VARCHAR(20),         -- 战斗结果
  casualties JSONB,           -- 伤亡数据
  created_at TIMESTAMP DEFAULT NOW()
);
```
