# 地图资源系统

## 1. 资源点类型

| 资源类型 | 外观颜色 | 采集收益（受层级倍率影响） | 特殊掉落 |
|----------|----------|---------------------------|----------|
| 灵田 | 绿色 | 30修为 × 灵气倍率 | - |
| 矿脉 | 灰色 | 50灵石 × 资源倍率 | - |
| 遗迹 | 紫色 | 100灵石 × 资源倍率 | 30%概率掉落洗髓丹 |

## 3. 资源刷新机制

- 地图上会定期随机刷新资源点
- 玩家或NPC采集后资源点消失
- 采集后有70%概率在附近生成新的资源点
- NPC也会争夺附近的资源点
- 新生成的资源点受当前世界层级影响

## 4. 跨层资源流动

资源会随玩家飞升向上层汇聚：

```
第9层（产出基础资源）──→ 飞升者携带部分资源 ──→ 第8层
                              │
                              ▼
第8层（产出中级资源）──→ 飞升者携带部分资源 ──→ 第7层
                              │
                              ▼
                            ...
                              │
                              ▼
第1层（产出顶级资源）──→ 合道者化为世界规则 ──→ 反哺所有下层世界
```

## 5. 天道反哺

当高层玩家完成特定事件时，下层世界资源会获得增益：

| 高层事件 | 下层资源影响 |
|:---|:---|
| 玩家飞升 | 该玩家出身的区服资源刷新率+10% |
| 仙门成立 | 对应下层国家资源点数量+5% |
| 合道者出现 | 全服资源丰度+5% |

## 6. LLM决策入口：资源战略层

### 6.1 LLM适用场景

在资源系统层面，以下决策场景适合引入LLM进行战略规划：

| 场景 | LLM决策对象 | 规划周期 | 影响范围 |
|:---|:---|:---|:---|
| **资源点争夺策略** | T1/T2级NPC（家主/长老） | 日/次 | 资源点控制、采集路线 |
| **资源储备规划** | T1级NPC（家主） | 周/次 | 家族库房、丹药/法器储备 |
| **跨区资源调度** | T0级NPC（皇帝/君主） | 月/次 | 国家资源分配 |
| **遗迹探索计划** | T2级NPC（长老） | 日/次 | 遗迹优先级、探索队伍 |

### 6.4 与LLM规划系统的衔接

资源战略LLM规划与[NPC的AI决策系统](12-NPC的AI决策.md)的衔接方式：
- 资源战略计划中的`CAPTURE_RESOURCE_POINT` → 注入到执行NPC的行为树，触发资源争夺行为
- 资源战略计划中的`RESOURCE_PURCHASE` → 触发市场交易事件，影响经济系统
- 资源战略计划中的`INTELLIGENCE_SCOUT` → 注入到情报NPC行为树
