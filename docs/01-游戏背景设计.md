# 游戏背景设计

## 1. 世界观概述

《太古纪元：战国修仙传》是一款基于Web的 2.5D 像素风玄幻修仙多人在线网络游戏（MMORPG）。游戏将"战国七雄"的宏观国家博弈、中层"修仙家族"的竞争与微观的"个人修仙"相结合，构建了一个动态、真实的修仙世界。

### 1.1 核心设定

- **时代背景**: 架空的战国修仙世界，融合中国战国时期历史与修仙文化
- **地理版图**: 七国并立（秦、楚、齐、燕、赵、魏、韩），各国拥有独特的修仙文化
- **核心目标**: 玩家从凡人开始，通过修炼突破最终飞升上界
- **服务器容量**: 每个区服上限 100 人，满员后自动开启新区

## 3. 核心玩法流程

```
开始游戏
  ↓
分配服务器（<100人）
  ↓
随机出生（七国某家族支脉）
  ↓
探索与养成
  ├─ 打坐修炼 → 获取修为
  ├─ 采集资源 → 获取灵石/修为
  └─ 与NPC交互 → 交谈/交易/攻击
  ↓
与NPC交互
  ├─ 交易/结交 → 提升家族好感与自身实力
  └─ 杀人夺宝 → 降低好感，面临家族围剿
  ↓
境界提升
  ↓
是否达到飞升条件？
  ├─ 是 → 飞升上界（跨服大区）
  └─ 否 → 继续探索与养成
```
