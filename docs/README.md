# 太古纪元：霸业 - 游戏设计文档

## 项目概述

《太古纪元：霸业》是一款**类全战三国的2.5D像素风修仙战争AI原生游戏**。游戏将"战国七雄"的宏观国家博弈、"修仙境界"的个体成长体系与"AI原生"的智能世界演化相结合，构建了一个动态、真实的修仙战争世界。

### 核心特色

- **AI原生世界**：三层级AI系统（战略AI、战术AI、角色AI）驱动游戏世界
- **全战式战争**：2.5D像素风格战略地图 + 实时战斗系统
- **修仙与战争融合**：境界决定指挥权限，功法影响战术
- **涌现叙事**：没有预设剧本，所有故事由AI互动自然产生

## 快速开始

### 核心玩法流程

```
开始游戏
  ↓
选择游戏模式（单人/多人/观战）
  ↓
选择出生国家（七选一）或随机分配
  ↓
AI生成世界格局（战略AI）
  ↓
制定国家战略 → 指挥军团作战 → 个人修炼突破
  ↓
统一天下 → 挑战大周 → 飞升上界
  ↓
继续修炼 → 仙域争霸 → 合道成仙
```

## 技术栈

- **客户端**: Phaser 3 + React + TypeScript
- **服务端**: Node.js + Express + WebSocket
- **AI系统**: Gemini API (三层级模型)
- **数据库**: PostgreSQL + MongoDB + Redis
- **部署**: Docker + AWS/Azure

## 商业模式

- **基础买断**: 98元，包含完整游戏和40小时AI算力
- **Token内购**: 快速模式1.5元/小时，专家模式4.5元/小时
- **DLC扩展**: 国家包、功法包、战役包等
