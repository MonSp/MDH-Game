# 设计文档目录结构

## 目录说明

| 目录 | 内容 |
|------|------|
| `world/` | 世界观与背景设定 |
| `factions/` | 势力体系（国家、家族等） |
| `cultivation/` | 修仙体系与境界设定 |
| `map/` | 地图与资源系统 |
| `economy/` | 经济系统设计 |
| `npc/` | NPC行为、AI、生死轮回 |
| `player/` | 玩家系统设计 |
| `technical/` | 技术架构设计 |
