# 太古纪元：霸业 - 游戏设计文档

## 项目概述

《太古纪元：霸业》是一款**类全战三国的2.5D像素风修仙战争AI原生游戏**。游戏将"战国七雄"的宏观国家博弈、"修仙境界"的个体成长体系与"AI原生"的智能世界演化相结合，构建了一个动态、真实的修仙战争世界。

### 核心特色

- **AI原生世界**：三层级AI系统（战略AI、战术AI、角色AI）驱动游戏世界
- **全战式战争**：2.5D像素风格战略地图 + 实时战斗系统
- **修仙与战争融合**：境界决定指挥权限，功法影响战术
- **涌现叙事**：没有预设剧本，所有故事由AI互动自然产生

## 快速开始

### 核心玩法流程

```
开始游戏
  ↓
选择游戏模式（单人/多人/观战）
  ↓
选择出生国家（七选一）或随机分配
  ↓
AI生成世界格局（战略AI）
  ↓
制定国家战略 → 指挥军团作战 → 个人修炼突破
  ↓
统一天下 → 挑战大周 → 飞升上界
  ↓
继续修炼 → 仙域争霸 → 合道成仙
```

## 技术栈

- **客户端**: Three.js (react-three-fiber) + React 19 + TypeScript + Tailwind CSS v4
- **服务端**: Node.js + Express + Socket.IO + Vitest (653项测试)
- **AI系统**: LLMHttpClient (OpenAI兼容/Gemini), PlanParser, NPCMemory (Phase 1b)
- **C++引擎**: CMake + C++17 ECS (benchmark only, Unix Socket IPC)
- **数据库**: better-sqlite3 (轻量, 大部分数据在内存中)
- **状态管理**: Zustand (gameStore.ts)
- **部署**: Docker + AWS/Azure

## 商业模式

- **基础买断**: 98元，包含完整游戏和40小时AI算力
- **Token内购**: 快速模式1.5元/小时，专家模式4.5元/小时
- **DLC扩展**: 国家包、功法包、战役包等

## 开发路线图

已完成的基础设施不再单独列出，详细路线图见 [22-开发路线图](22-开发路线图.md)。

### Phase 0 — 当前版本 (v1.11.0.0)
- 2.5D 像素渲染引擎
- 玩家修仙系统（境界/突破/天赋/体质）
- 世界自动战斗系统（怪物生成/玩家/NPC 战斗/掉落）
- 场景叙事系统（分支剧情/NPC 对话）
- 存档/读档系统

### Phase 1 — 个人声望 + 小队系统 (规划中)
- **P0 个人声望**：全局声望数值、等级称号、作为所有后续系统的门槛
- **P1 小队系统**：NPC 招募、队伍管理、队员定位/养成/永久死亡

### Phase 2 — 势力系统 (规划中)
- 三条路径：功高盖主 / 自立门户 / 篡位吞并
- 领地与建筑系统
- 势力管理、财政、外交

### Phase 3 — 外交与战争 (规划中)
- 国家间宣战/结盟/停战/臣服
- 兵力派遣、攻城战
- 冲突递进链：摩擦 → 局部冲突 → 全面战争

### Phase 4 — 统一天下 (规划中)
- 灭国机制、称帝结局
- 统计回顾、飞升仙界继承气运
