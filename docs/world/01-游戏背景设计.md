# 游戏背景设计

## 1. 世界观概述

《太古纪元：霸业》是一款**类全战三国的2.5D像素风修仙战争AI原生游戏**。游戏将"战国七雄"的宏观国家博弈、"修仙境界"的个体成长体系与"AI原生"的智能世界演化相结合，构建了一个动态、真实的修仙战争世界。

游戏核心特色在于**AI驱动的战略博弈**：每个国家、每个家族、每个修仙者都由独立的AI Agent驱动，他们自主制定战略、建立外交关系、发动战争、修炼突破，形成一个真正"活"的修仙世界。玩家作为其中一员，可以选择成为统御千军的大将、运筹帷幄的谋士、独来独往的散修，或是开宗立派的祖师——在这个AI驱动的世界中书写自己的霸业。

### 1.1 核心设定

- **游戏类型**: 类全战三国的2.5D像素风修仙战争AI原生游戏（单人/多人）
- **时代背景**: 架空的战国修仙世界，融合中国战国时期历史与修仙文化
- **地理版图**: 七国并立（秦、楚、齐、燕、赵、魏、韩），各国拥有独特的修仙文化和军事传统
- **核心目标**: 玩家从凡人开始，通过修炼突破、建立势力、统一天下，最终飞升上界
- **AI原生**: 世界由三层级AI系统驱动（战略AI、战术AI、角色AI），NPC具有真实的记忆、情感和决策能力
- **平台**: Steam（PC），支持单人战役和多人联机

### 1.2 游戏模式

| 模式 | 说明 | 玩家数量 | AI作用 |
|:---|:---|:---|:---|
| **单人战役** | 玩家选择一国，从凡人开始统一天下 | 1人 | 其他国家由AI完全控制 |
| **多人联机** | 多名玩家分别控制不同国家 | 2-7人 | 未选国家由AI控制 |
| **观战模式** | 纯AI对战，玩家观察世界演化 | 0-1人 | 全部国家由AI控制 |
| **自定义模式** | 玩家自定义世界参数和初始条件 | 1-7人 | 可调整AI难度和数量 |

## 3. 核心玩法流程（从凡人到天下霸主）

```
开始游戏
  ↓
选择游戏模式（单人/多人/观战）
  ↓
选择出生国家（七选一）或随机分配
  ↓
AI生成世界格局（战略AI）
  ↓
┌─ 战略层面 ─┐
│ 制定国家战略  │ ← 玩家/AI决策
│ 外交结盟      │
│ 资源争夺      │
└─────────────┘
  ↓
┌─ 战术层面 ─┐
│ 军团组建      │ ← 玩家/AI决策
│ 战场指挥      │
│ 功法搭配      │
└─────────────┘
  ↓
┌─ 角色层面 ─┐
│ 个人修炼      │ ← 玩家/AI决策
│ 功法突破      │
│ 人际关系      │
└─────────────┘
  ↓
战争触发 → 进入战场实例 → 实时战斗
  ↓
战争结果 → 改变世界格局 → 影响AI决策
  ↓
统一天下 → 挑战大周 → 飞升上界
  ↓
继续修炼 → 仙域争霸 → 合道成仙
```

## 4. 核心特色：AI驱动的修仙战争世界

### 4.1 三层级AI系统

游戏采用**三层级AI架构**，分别负责不同层面的决策：

| AI层级 | 职责 | 决策对象 | 调用频率 | 模型要求 |
|:---|:---|:---|:---|:---|
| **战略AI** | 国家战略、外交关系、世界格局 | 国君、大将军 | 游戏月/次 | 强推理模型（gemini-3.1-pro） |
| **战术AI** | 战场指挥、军团调度、功法搭配 | 将军、阵法师 | 游戏周/次 | 平衡模型（gemini-2.5-flash） |
| **角色AI** | 个人修炼、社交关系、日常行为 | 所有修仙者 | 游戏日/次 | 经济模型（轻量模型） |

### 4.2 AI原生世界演化

- **自主决策**：每个AI Agent根据自身记忆、情感和目标做出独立决策
- **动态关系**：AI之间会建立真实的联盟、敌对、师徒、仇敌关系
- **历史记忆**：AI会记住过去的事件，并据此调整未来行为
- **涌现叙事**：没有预设剧本，所有故事由AI互动自然产生

### 4.3 全战式战争系统

- **战略地图**：2.5D像素风格战略地图，显示国家边界、军队位置、资源分布
- **实时战斗**：进入战场实例后，支持500+单位同屏战斗
- **地形改造**：法术和器械可改变地形，影响战局
- **军团系统**：基于境界和功法的军团编制，不同军团有不同特性

### 4.4 修仙与战争的深度融合

- **境界决定权限**：境界越高，可指挥的军团规模越大，可使用的战略法术越强
- **功法影响战术**：不同功法搭配产生不同的军团特性（如剑修军团高攻击、丹修军团高恢复）
- **阵法改变战局**：高阶阵法师可布置覆盖整个战场的阵法，改变战斗规则
- **天命系统**：类似全战三国的天命机制，影响国家气运和重大事件

## 6. 技术实现要点

### 6.1 AI架构

借鉴WorldX的多模型协作架构：

```
玩家输入/世界状态
  ↓
战略AI（编排引擎）→ 生成国家战略、外交关系
  ↓
战术AI（模拟引擎）→ 生成战场指挥、军团调度
  ↓
角色AI（Agent系统）→ 生成个人行为、修炼计划
  ↓
游戏世界更新
```

### 6.2 性能优化

- **战场实例化**：大规模战斗在独立进程运算
- **LOD系统**：远处单位简化渲染
- **AI缓存**：战略决策结果可缓存复用
- **批量处理**：战术AI批量处理多个战场请求

### 6.3 网络同步

- **单人模式**：本地运行，无需联网（除AI API调用）
- **多人模式**：主机-客户端架构，战略层状态同步
- **观战模式**：服务器运行AI对战，客户端接收状态更新

## 7. 商业模式

### 7.1 核心模式：买断+Token内购

- **基础买断**：98元，包含完整游戏和40小时AI算力
- **Token内购**：
  - 快速模式：1.5元/小时（标准AI模型）
  - 专家模式：4.5元/小时（高级AI模型，3倍消耗）
  - 经济模式：0.8元/小时（轻量AI模型）
- **DLC扩展**：
  - 国家包：新增可玩国家（29-49元）
  - 功法包：新增功法体系（19-39元）
  - 战役包：历史著名战役（39-69元）

### 7.2 成本透明

- 实时显示Token消耗速率
- 挂机状态不消耗Token
- 提供AI成本计算器，帮助玩家预估花费
