# 游戏背景设计

## 1. 世界观概述

《太古纪元：战国修仙传》是一款基于Web的 2.5D 像素风玄幻修仙多人在线网络游戏（MMORPG）。游戏将"战国七雄"的宏观国家博弈、中层"修仙家族"的竞争与微观的"个人修仙"相结合，构建了一个动态、真实的修仙世界。

游戏核心特色在于**皇族禁生、天命可夺**的设计理念：玩家从散修起步，通过客卿体系积累实力，篡夺家位，颠覆皇权，统合七国，最终剑指大周——这是一条从棋子到棋手的完整逆袭之路。

### 1.1 核心设定

- **时代背景**: 架空的战国修仙世界，融合中国战国时期历史与修仙文化
- **地理版图**: 七国并立（秦、楚、齐、燕、赵、魏、韩），各国拥有独特的修仙文化
- **核心目标**: 玩家从凡人开始，通过修炼突破最终飞升上界，最终可挑战大周、登基天子
- **服务器容量**: 每个区服上限 100 人，满员后自动开启新区

## 3. 核心玩法流程（散修到天子）

```
开始游戏
  ↓
选择出生国家（七选一）
  ↓
加入预组家族（输入邀请码）或散人随机分配（一/二级家族）
  ↓
┌─ 修炼循环 ─┐
│ 打坐修炼    │
│ 采集资源    │ ← 日常活动
│ 与NPC交互   │
│ 交易买卖    │
└────────────┘
  ↓
┌─ 客卿发展 ─┐
│ 结交散人    │
│ 招揽客卿    │ ← 积累实力
│ 积累贡献    │
└────────────┘
  ↓
逼宫条件达成 → 发起逼宫 → 成为家主
  ↓
┌─ 家族晋升 ─┐
│ 提升战力    │
│ 积累资源    │ ← 三级→二级→一级
│ 挑战皇族    │
└────────────┘
  ↓
篡位成功 → 成为皇族
  ↓
继续修炼与突破（第9层：凡人→...→化神）
  ↓
达到化神大圆满（第9层巅峰）
  ↓
渡劫飞升（第9层→第8层）
  ↓
加入/创建飞升家族
  ↓
继续修炼（第8层：化神→...→炼虚）
  ↓
...（重复飞升循环至更高层级）
  ↓
成为皇族 → 统一六国 → 挑战大周
  ↓
伐周成功 → 登基为天子
  ↓
最终目标：飞升至第1层混元仙界
  ↓
合道（成为世界规则的一部分）
```

## 4. 核心特色：皇族禁生，天命可夺

游戏确立一条铁律：**皇族不可选，周室不可犯（第9层），然天命可夺，王座可覆**。

| 特色 | 说明 |
|:---|:---|
| **皇族禁生** | 皇族为NPC专属，玩家不可直接出身，必须通过篡位获取皇族地位 |
| **客卿逆袭** | 散人玩家可通过招揽客卿、积累贡献，发起逼宫成为家主 |
| **家族晋升** | 三级→二级→一级→皇族的完整晋升路径 |
| **大周分层** | 第9层为绝对中立安全区；第8层及以上可征服，天子权柄可夺 |
| **统一与伐周** | 统一七国后可挑战大周，登基为新天子获得世界权柄 |
