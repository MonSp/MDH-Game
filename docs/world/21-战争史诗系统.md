# 实时战略战斗系统

## 1. 系统概述

《太古纪元：霸业》的战斗系统采用**实时战略（RTS）模式**，结合修仙元素和全战三国的战术深度。玩家可以指挥数百个单位进行实时战斗，同时运用修仙功法、阵法和地形优势来取得胜利。

### 1.1 核心设计理念

- **实时指挥**：玩家实时指挥军队，体验战场紧张感
- **修仙元素**：功法、阵法、法术融入战斗
- **地形影响**：地形对战斗有实质性影响
- **AI辅助**：AI Agent辅助战术决策
- **规模感**：支持500+单位同屏战斗

## 2. 战斗触发与进入

### 2.1 战斗触发方式

| 触发方式 | 说明 | 战斗规模 |
|:---|:---|:---|
| **战略地图接触** | 两军在战略地图相遇 | 取决于军队规模 |
| **攻城战** | 攻击敌方城市 | 城市防御规模 |
| **伏击战** | 遭遇伏击或伏击敌人 | 伏击方优势 |
| **遭遇战** | 巡逻队相遇 | 小规模 |
| **任务战斗** | 特定任务触发 | 任务设定 |

### 2.2 战场实例化

```
战斗触发
  ↓
生成战场实例（200×200格）
  ↓
根据地形生成战场环境
  ↓
双方部署军队
  ↓
进入实时战斗
  ↓
战斗结束
  ↓
计算战果
  ↓
返回战略地图
```

### 2.3 战场规模

| 战斗类型 | 战场大小 | 最大单位数 | 战斗时长 |
|:---|:---|:---|:---|
| **小规模** | 100×100格 | 1000人 | 5-10分钟 |
| **中规模** | 150×150格 | 5000人 | 10-20分钟 |
| **大规模** | 200×200格 | 20000人 | 20-40分钟 |
| **超大规模** | 300×300格 | 50000人 | 40-60分钟 |

## 7. 战斗结算

### 7.1 战果计算

| 因素 | 影响 | 权重 |
|:---|:---|:---|
| **击杀数** | 直接战果 | 30% |
| **占领目标** | 战略成果 | 25% |
| **保存实力** | 持续作战能力 | 20% |
| **资源获取** | 经济收益 | 15% |
| **士气影响** | 长期影响 | 10% |

### 7.2 战斗结果

| 结果 | 条件 | 影响 |
|:---|:---|:---|
| **大胜** | 击杀>80%，占领目标 | 士气+50%，获得大量资源 |
| **胜利** | 击杀>50%，占领目标 | 士气+30%，获得资源 |
| **惨胜** | 击杀>50%，损失>70% | 士气-10%，资源消耗大 |
| **平局** | 双方撤退 | 士气-5%，无资源变化 |
| **失败** | 被击杀>50% | 士气-30%，损失资源 |
| **惨败** | 被全歼 | 士气-50%，重大损失 |
