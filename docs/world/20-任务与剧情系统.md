# 任务与剧情系统设计

## 1. 设计理念：缘起缘灭，皆是修行

修仙世界并非只有打打杀杀。每一个NPC都有自己的故事，每一片土地都承载着历史。任务与剧情系统为这个世界注入灵魂，让玩家在修炼之余，能体验到一个个动人的故事，并在故事中成长、抉择、悟道。

**核心循环**：
```
触发任务 → 了解剧情 → 做出选择 → 完成任务 → 影响世界 → 获得奖励
```

## 2. 任务类型体系

### 2.1 任务分类

| 任务类型 | 说明 | 典型内容 | 奖励偏向 |
|:---|:---|:---|:---|
| **主线任务** | 推动核心剧情 | 国家兴衰、家族恩怨 | 大量修为、关键道具 |
| **支线任务** | 丰富世界故事 | NPC个人故事、地区传说 | 灵石、材料、好感度 |
| **日常任务** | 每日可重复 | 采集、巡逻、送信 | 稳定资源收入 |
| **周常任务** | 每周可重复 | 秘境挑战、家族任务 | 中等奖励 |
| **机缘任务** | 随机触发 | 偶遇、奇遇、突发事件 | 随机丰厚奖励 |
| **天道任务** | 飞升必需 | 功德积累、世界影响 | 功德值、飞升资格 |
| **传承任务** | 功法/法器传承 | 寻找传人、完成遗愿 | 稀有功法/法器 |
| **因果任务** | 跨纪元延续 | 前世恩怨、轮回纠葛 | 特殊称号、因果点 |

### 2.2 任务品质

| 品质 | 颜色 | 难度 | 奖励 | 说明 |
|:---|:---|:---|:---|:---|
| **普通** | 白色 | 低 | 基础 | 日常、简单支线 |
| **优秀** | 绿色 | 中 | 1.5倍 | 重要支线 |
| **稀有** | 蓝色 | 较高 | 2倍 | 机缘、传承 |
| **史诗** | 紫色 | 高 | 3倍 | 主线、重大事件 |
| **传说** | 橙色 | 极高 | 5倍 | 天道、跨纪元 |
| **神话** | 金色 | 传说 | 10倍 | 唯一、改变世界 |

## 3. 主线剧情架构

### 3.1 国家主线

每个国家有独立的主线剧情，玩家选择国家后逐步解锁：

#### 3.1.1 秦国主线：《铁血修仙》

```
第一章：入伍
- 背景：秦国边境妖兽肆虐
- 任务：加入边防军，抵御妖兽
- 抉择：忠于军令 vs 救助平民

第二章：朝堂
- 背景：军功晋升，进入朝堂
- 任务：参与政治斗争
- 抉择：支持改革派 vs 保守派

第三章：东出
- 背景：秦国准备统一战争
- 任务：作为先锋，攻略他国
- 抉择：仁慈收降 vs 铁血镇压

第四章：天下
- 背景：统一六国，面对大周
- 任务：参与伐周战争
- 抉择：拥立新君 vs 自己称王
```

#### 3.1.2 楚国主线：《巫祝之秘》

```
第一章：觉醒
- 背景：发现自身巫族血脉
- 任务：寻找巫族遗迹
- 抉择：接受血脉 vs 抗拒命运

第二章：传承
- 背景：获得上古巫术传承
- 任务：学习巫术，平衡正邪
- 抉择：正道修行 vs 巫术速成

第三章：祭祀
- 背景：楚国大祭，需要祭品
- 任务：准备祭祀，面对道德困境
- 抉择：人道祭祀 vs 传统血祭

第四章：封神
- 背景：巫术大成，可沟通天地
- 任务：面对封神诱惑
- 抉择：封神长生 vs 凡间守护
```

## 4. 机缘任务系统

### 4.1 触发机制

| 触发方式 | 概率 | 说明 |
|:---|:---|:---|
| **地图探索** | 低 | 进入特定地点触发 |
| **NPC交互** | 中 | 与特定NPC对话触发 |
| **时间触发** | 低 | 特定时间/天气触发 |
| **行为触发** | 中 | 特定行为累积触发 |
| **物品触发** | 高 | 获得特定物品触发 |
| **境界触发** | 必发 | 突破境界时触发 |

### 4.2 机缘类型

#### 4.2.1 古修遗泽

```
触发：探索遗迹时发现古修遗骸
内容：
- 选择：安葬遗骸 / 搜刮遗物 / 接受传承
- 结果：
  - 安葬：获得功德值，可能获得遗骸守护
  - 搜刮：获得物品，可能触发诅咒
  - 传承：接受遗愿任务，完成后获传承
```

#### 4.2.2 妖兽报恩

```
触发：曾放过某妖兽，或救助过妖兽
内容：
- 妖兽化形前来报恩
- 选择：接受报恩 / 婉拒 / 要求更多
- 结果影响妖兽后续态度
```

#### 4.2.3 天道启示

```
触发：修炼时顿悟，或特殊天象
内容：
- 获得天道信息碎片
- 指向某个秘境或事件
- 完成后获得天道奖励
```

#### 4.2.4 红尘劫

```
触发：与NPC深度交互后
内容：
- 陷入情感纠葛
- 选择：斩断情丝 / 沉沦红尘 / 带着牵挂修行
- 不同选择影响道心属性
```

### 4.3 机缘奖励

| 机缘等级 | 奖励范围 | 说明 |
|:---|:---|:---|
| **小机缘** | 灵石、材料 | 日常偶遇 |
| **中机缘** | 功法残卷、法器 | 需要一定条件 |
| **大机缘** | 完整功法、稀有法器 | 重大抉择 |
| **天缘** | 改变体质、特殊能力 | 可遇不可求 |

## 5. 因果任务系统

### 5.1 因果机制

```
因果积累：
- 善行 → 善因 → 未来获得帮助/机缘
- 恶行 → 恶因 → 未来遭遇阻碍/心魔
- 承诺 → 必须完成，否则道心受损
- 恩怨 → 必须了结，否则影响突破
```

### 5.2 跨纪元因果

真灵转世后，前世的因果会延续：

| 因果类型 | 表现 | 处理方式 |
|:---|:---|:---|
| **未完成的承诺** | NPC提及前世约定 | 完成或补偿 |
| **未报的恩情** | 遇到前世恩人或其后人 | 报恩 |
| **未了的恩怨** | 遇到前世仇敌或其传人 | 化解或了结 |
| **遗留的传承** | 发现前世留下的道统 | 继承或处置 |

### 5.3 因果点系统

| 因果点 | 效果 |
|:---|:---|
| **善因点** | 触发善缘事件概率+1%/点 |
| **恶因点** | 触发恶缘事件概率+1%/点 |
| **功德点** | 突破成功率+0.1%/点 |
| **业力点** | 心魔出现概率+1%/点 |

### 5.4 境界突破因果关联

**核心设计：因果任务与境界突破深度绑定，形成"修行即修心"的体验。**

每个大境界突破前，必须处理相关因果：

#### 5.4.1 因果了结任务

| 境界突破 | 因果要求 | 典型因果任务 |
|:---|:---|:---|
| **筑基→金丹** | 至少完成3个善因任务 | 救助之恩、师徒传承、家族恩怨 |
| **金丹→元婴** | 善因≥恶因 | 前世仇怨、欠债还情、誓言了结 |
| **元婴→化神** | 业力点<50 | 心魔试炼、化解执念、放下牵挂 |
| **化神→炼虚** | 因果点数>0 | 因果了结、功德圆满、超脱轮回 |
| **炼虚→合体** | 天道认可 | 天道任务、功德积累、世界贡献 |
| **合体→大乘** | 无重大恶因 | 恶缘化解、历史评价、重塑因果 |
| **大乘→渡劫** | 功德圆满 | 天道考验因果、渡劫因果 |

#### 5.4.2 因果共鸣效果

完成与当前境界相关的因果任务，可获得境界共鸣加成：

```
因果共鸣 = Σ(相关因果任务完成数) × 因果点加成

| 因果共鸣等级 | 解锁效果 |
|:---|:---|
| 无共鸣 | 突破成功率×1.0 |
| 初步共鸣 | 突破成功率×1.1，心魔抵抗+5% |
| 中度共鸣 | 突破成功率×1.2，心魔抵抗+10%，突破后属性+5% |
| 深度共鸣 | 突破成功率×1.3，心魔抵抗+15%，突破后属性+10% |
| 因果圆满 | 突破成功率×1.5，心魔免疫，突破后属性+20% |
```

## 6. 境界专属任务体系

### 6.1 设计理念

**核心循环：境界驱动任务，任务反哺境界。**

每个境界有专属的任务体系，玩家必须完成境界任务才能更好地突破：

```
境界提升 → 解锁新任务 → 完成任务获得境界相关奖励 → 加深境界理解 → 更容易突破
```

### 6.2 境界任务分类

| 任务类型 | 说明 | 与境界的关联 |
|:---|:---|:---|
| **道心任务** | 考验心性，稳固道基 | 直接影响突破成功率 |
| **感悟任务** | 领悟天道，积累感悟 | 积累感悟值，加速突破 |
| **资源任务** | 收集突破所需资源 | 确保突破道具齐全 |
| **因果任务** | 处理前世今生因果 | 消除突破障碍 |
| **传承任务** | 接受或传承功法 | 功法修炼加速 |
| **心境任务** | 提升心境圆满度 | 影响突破后属性 |

### 6.4 境界任务与经济系统联动

境界专属任务与经济系统深度绑定：

```
任务奖励 → 道韵值/灵石/资源
    ↓
完成任务 → 解锁经济特权
    ↓
经济特权 → 加速资源获取
    ↓
更多资源 → 更快完成任务 → 形成良性循环
```

| 任务完成数 | 解锁经济特权 |
|:---|:---|
| 完成筑基期全部任务 | 解锁坊市贵宾（交易税-10%） |
| 完成金丹期全部任务 | 解锁道韵商店购物权 |

| 完成炼虚期全部任务 | 解锁经济制裁权 |

## 7. 任务叙事设计

### 6.1 叙事分支

```
典型任务结构：

任务开始
  ↓
了解背景
  ↓
做出选择A / 选择B / 选择C
  ↓
    ├─ 选择A → 路线A → 结局A1 / A2
    ├─ 选择B → 路线B → 结局B1 / B2
    └─ 选择C → 路线C → 结局C1 / C2
  ↓
任务完成，影响世界状态
```

### 6.2 道德抉择

| 抉择类型 | 示例 | 影响 |
|:---|:---|:---|
| **义利之辨** | 救助平民 vs 追击敌人 | 声望/军功 |
| **情法之争** | 包庇亲友 vs 秉公执法 | 关系/正义值 |
| **正邪之分** | 正道修行 vs 魔道速成 | 道心/实力 |
| **生死之择** | 牺牲自己 vs 牺牲他人 | 因果/生存 |
| **取舍之道** | 保全多数 vs 保护少数 | 功德/业力 |

### 6.3 世界影响

玩家的选择会影响世界状态：

| 影响维度 | 说明 |
|:---|:---|
| **NPC命运** | 某些NPC可能因玩家选择而存活或死亡 |
| **家族关系** | 选择可能改变家族间的好感度 |
| **国家走向** | 重大选择可能影响国家剧情走向 |
| **个人属性** | 选择影响道心、功德、业力等隐藏属性 |
| **后续剧情** | 选择解锁或关闭某些后续任务 |
