# 开发路线图 v2：AI原生 · 世界觉醒 · 骑砍修仙

> 最后更新: 2026-05-04 | 版本: 2.0.0

---

## 核心理念

**不是给修仙游戏加 AI 对话，而是让 AI 驱动整个修仙世界。**

类 Mount & Blade 的自由身份转变（个人→小队→势力→国家→天下），叠加 **AI 原生 NPC**——每个 NPC 都有自己的记忆、欲望、关系和自主行为。玩家是这个活世界中的一个角色，而非唯一能动者。

```
NPC 苏醒 → 世界具象 → 修仙深化 → 战争升级 → 跨天统一 → 多人联机
   ↑ 核心差异化壁垒       ↑ 骑砍体验核心        ↑ 终局     ↑ 远期
```

## 当前瓶颈：NPC 会说话，但不会行动

```
当前状态:
  LLM 对话 ✅  →  NPC 记忆 ✅  →  行为执行 ❌ (stub)
  LLM 网关 🏗️  →  行为规划 🏗️  →  游戏循环 ❌ (未接入)

目标状态:
  LLM 决策 → 行为规划 → 行为执行 → 世界状态更新 → 记忆写入 → 影响下次决策
```

**两个并行的 NPC 系统：**
- 服务端 `NPCService.ts` — BehaviorExecutor 9 个方法中 6 个是空 stub，且从未被游戏循环调用
- 客户端 `evaluateNPCBehavior()` — 实际运行的 NPC AI，逻辑完整但只是加权随机，无 LLM 驱动

**LLM 三件套（`LLMGatewayService` / `LLMPlanningService` / `LLMIntegrationManager`）** 全部实现了 HTTP 调用、计划管理、行为树评估，但**从未接入游戏主循环**。行为树始终返回 `IDLE`。

## Phase 1：NPC 觉醒 — AI 原生交互闭环 🔥

> **优先级: ★★★★★ | 工期: ~5 天 | 这是整个项目的核心差异化壁垒**

### 1.1 打通 LLM → 行为规划 → 行为执行 闭环

**目标:** 每个 NPC 周期性由 LLM 生成行动计划 → 行为树执行 → 结果反馈记忆

**具体任务：**

| # | 任务 | 文件 | 说明 |
|---|------|------|------|
| 1.1a | 填满 `BehaviorExecutor.execute*` | `src/server/services/NPCService.ts` | `executePatrol`（移动到巡逻目标）、`executeChase`（追击敌对目标）、`executeTrade`（与指定 NPC/玩家交易）、`executeCompete`（争夺资源点）、`executeLogistics`（采集资源）|
| 1.1b | 接入 LLM 规划周期 | `src/server/game/services/LLMIntegrationManager.ts` | 每 N tick 为一批 NPC 调用 LLM 生成 plan，写入 `LLMPlanningService.activePlans` |
| 1.1c | 修复 `NPCBehaviorTree` | `src/server/game/services/NPCBehaviorTree.ts` | `LLMPlanNode` 实际调用 `planningService.getPlan()` 并返回具体 ActionType，而非始终返回 IDLE |
| 1.1d | 同步服务端行为到客户端 | `src/server/index.ts` | 通过 Socket.IO 将 NPC 行为结果推送到客户端 `gameStore` |
| 1.1e | 行为→记忆反馈 | `src/server/services/NPCWorldService.ts` | NPC 行为结果（交易成功/战斗胜负/资源获取）写入 `NPCMemory`，影响后续 LLM 决策 |

**交付物:**
- NPC 在游戏世界中自主移动、采集、交易、战斗
- 玩家能看到 NPC 在做具体的事情，而非随机游荡
- LLM 冷却管理：低优先级 NPC 用确定性 fallback，高优先级 NPC 用 LLM

## 设计原则

1. **NPC 是世界的主角，玩家是 NPC 世界中的一员。** 每个 NPC 有自己的记忆、欲望、关系和行为闭环。玩家可以影响但不控制这个世界。

2. **不要线性推着玩家走。** 每个阶段都是选项，不是必须。玩家可以在小队阶段停留 100 小时，也可以直接冲刺统一。

3. **声望是货币，不是枷锁。** 声望决定可能性，但不阻止尝试。

4. **每一层复用上一层的资产。** 小队队员 → 势力部属 → 国家将军，层层递进。

5. **世界是活的。** NPC 之间自主组队、创建势力、发动战争。玩家上线时世界可能已经改变。

6. **LLM 是增强，不是替代。** 低优先级 NPC 使用确定性 fallback，高优先级/与玩家交互的 NPC 使用 LLM。确保性能和成本可控。
