# 开发路线图：个人→小队→势力→国家→天下

## 核心理念

类 Mount & Blade 式的自由身份转变。玩家不是被剧情推着走，而是自己选择何时从散修变成领袖、何时从领袖变成君主。**每一个阶段都是上一个阶段的自然延续与扩展，但玩家可以选择在任何阶段停留。**

```
个人积累 → 组建小队 → 创建/接管势力 → 争霸天下 → 飞升/统一
   ↑           ↑            ↑              ↑           ↑
 新手期     中期核心    中后期目标     大后期玩法    终局内容
```

---

## P0：个人声望系统

**依赖：** 无（可独立开发）
**工期：** ~2 天
**优先级：** ★★★★★ — 所有后续系统依赖声望

### 核心数值

- **声望**：0~∞ 全局数值，非百分比
- **等级划分**：
  | 范围 | 称号 | 权限 |
  |------|------|------|
  | 0-49 | 无名小卒 | 可被任何 NPC 无视 |
  | 50-199 | 小有名气 | 可接家族任务、进入坊市上层 |
  | 200-499 | 声名鹊起 | 可招募第一个 NPC 队员 |
  | 500-999 | 名动一方 | 可被宗门/势力主动接触 |
  | 1000-4999 | 威震四海 | 可自立门户、参与外交 |
  | 5000+ | 天下皆知 | 可争霸天下 |

### 声望来源

- 击杀怪物/敌对 NPC (+1~+50 视强度)
- 击败/击杀其他势力首领 (+100~+500)
- 完成家族/宗门任务 (+10~+50)
- 比武获胜 (+20~+100)
- 修炼突破 (+5~+30)
- 采集稀有资源首次 (+5~+20)
- 战争获胜 (+200~+1000)

|------|------|

| `src/components/HUD.tsx` | HUD 显示声望和称号 |

## P1：小队系统

**依赖：** P0（声望决定可招募人数和品质）
**工期：** ~4 天
**优先级：** ★★★★★ — 骑砍式体验的核心

### NPC 招募

- **条件组合**：声望门槛 + 灵石 + NPC 好感度（帮对方做过事/送礼）
- **招募上限**：随声望等级递增（小有名气=1人 → 声名鹊起=3人 → 名动一方=7人 → 天下皆知=15人）
- **NPC 定位**：
  | 类型 | 作用 |
  |------|------|
  | 战斗型 | 正面战力，近战/远程/法术 |
  | 斥候型 | 探索发现资源点/敌对势力/地图迷雾 |
  | 军师型 | 提供战术加成、突破辅助、情报分析 |
  | 后勤型 | 自动采集、炼丹、打理驻地 |
- **队员永久死亡**：战斗中 HP 归零则死亡，不可复活

### 队伍管理界面

- 队伍列表：查看队员状态、装备、定位
- 任命系统：斥候/军需官/战斗队长（影响队伍整体行为）
- 装备分配：从背包中将装备/丹药分配给队员
- 队员经验：随战斗获取，可升级提升属性

### 队伍行为

- 地图上显示队伍图标而非单人
- 玩家移动时队伍跟随
- 战斗中队员按定位自动行动
- 队内对话/事件（队员之间有互动，可能产生矛盾或羁绊）

### 数据结构

```typescript
interface TeamMember {
  npcId: string;
  role: 'combat' | 'scout' | 'strategist' | 'logistics';
  equipment: string[];
  joinTime: number;
  loyalty: number;      // 忠诚度，低于阈值可能叛逃
}

// Player 新增字段
team: TeamMember[];
```

## P2：势力系统

**依赖：** P1（需要队员才能自立门户）
**工期：** ~5 天
**优先级：** ★★★★☆ — 中后期核心

### 三条路径

**路径A：功高盖主**（和平继承）
- 条件：当前家族贡献 > 阈值 + 声望 ≥ 500 + 境界 ≥ 金丹
- 流程：老家族主主动让位，玩家接手整个家族
- 代价：需要处理其他继承人的关系（可能分裂）

**路径B：自立门户**（白手起家）
- 条件：声望 ≥ 500 + 灵石 ≥ 100000 + 至少 3 名队员
- 流程：选择领地 → 命名 → 建立驻地
- 后果：原家族关系恶化（叛逃惩罚，-30 好感）

**路径C：篡位吞并**（武力夺取）
- 条件：战力 > 对方家主 + 已收买 ≥ 1 个内部长老
- 流程：挑战家主 → 决斗 → 胜者接管
- 后果：部分成员可能不服离开，短期忠诚度下降

### 领地与建筑

- **领地类型**：村庄 → 城镇 → 郡城 → 都城
- **建筑**：
  | 建筑 | 功能 |
  |------|------|
  | 议事厅 | 势力决策、外交、任命 |
  | 练功房 | 队员修炼速度 +20% |
  | 丹房 | 可炼丹，产出归势力 |
  | 藏经阁 | 存储功法，队员可学习 |
  | 库房 | 存储势力共有资源 |
  | 哨塔 | 扩大视野，发现入侵 |

### 势力管理

- **部属任命**：任命长老、分封领地、下达势力级指令
- **财政**：税收 + 产业收入 - 军费 - 建设维护
- **外交关系**：与其它势力/国家的关系值（-100~+100）
- **势力等级**：3级（村庄）→ 2级（城镇）→ 1级（郡城）→ 皇族（国家级）

## P3：外交与战争系统

**依赖：** P2（需要有势力才能宣战）
**工期：** ~5 天
**优先级：** ★★★★☆ — 大后期核心

### 外交

- **宣战**：消耗声望，双方进入战争状态
- **结盟**：需要关系 ≥ +60，共同对敌
- **停战**：消耗灵石/资源作为赔款
- **臣服**：战败方成为附庸，定期进贡
- **中立**：默认状态

### 战争

- **战争目标**：攻占领地 → 削弱敌方经济 → 迫使臣服
- **兵力系统**：不再是玩家一个人打，而是派遣队伍/下属势力出战
- **攻城战**：需要准备攻城器械（消耗资源和时间）
- **战后处理**：占领/掠夺/摧毁/归还

### 冲突递进链

```
小摩擦 → 局部冲突 → 全面战争
  宗门任务遭遇敌对
  → 护送达不成，损失资源
  → 发布复仇任务
  → 对方反击，冲突升级
  → 背后国家势力介入
  → 全面国战
```

## P4：统一天下

**依赖：** P3（战争系统）
**工期：** ~3 天
**优先级：** ★★★☆☆ — 终局内容

- **灭国机制**：攻占首都 + 占领 ≥ 80% 领地，国家灭亡
- **称帝**：统一后加冕，触发结局动画
- **收尾方式**：
  - 守成——作为统一王朝继续治理
  - 对外扩张——征伐其他层天
  - 飞升仙界——带着统一气运飞升，获得特殊仙体
- **统计回顾**：战争统计、时间线、关键事件回顾

## 设计原则

1. **不要线性推着玩家走。** 每个阶段都是选项，不是必须。玩家可以在小队阶段停留 100 小时，也可以直接冲刺统一。
2. **声望是货币，不是枷锁。** 声望决定可能性，但不阻止尝试。声望不够时招募/宣战会更难/更贵，但不是灰色不可点击。
3. **每一层都复用上一层的资产。** 小队队员 = 可招募的 NPC，势力部属 = 忠诚度更高的小队成员，国家将军 = 部属的升级版。
4. **世界是活的。** NPC 之间也会自己组队、创建势力、发动战争。玩家不是唯一能动的人。
